NO.01 · 前沿模型 · 编码与安全

Google 发布 Gemini 4 Carbon，独立榜单登顶，先给网络安全防御方

前沿模型AI coding网络安全受限开放
事件简述

10 月 28 日，Google DeepMind 发布 Gemini 4 Carbon，定位为在网络安全与长周期任务上最强的一代，距 Gemini 4 Argon 扩大开放仅两周。在独立评测机构 Artificial Analysis 更新后的智能指数 v5.0 上，Carbon 以 59 分排名第一，高于 Claude Opus 5.5 的 58 分、GPT-6 Astra 的 57 分与 Argon 的 50 分；在该机构的编码 agent 指数上 Carbon 得 59 分，比 Claude Code 搭配 Opus 5.5 低 3 分。

官方给出的提升集中在编码、agent 任务、科研任务、全栈网页开发与多模态理解。全栈网页开发在 WebDev Arena 上升 89 elo 至 1769 分、排名第 4；安全侧 SEC-bench Pro 漏洞发现 88.2%、ExploitGym 利用验证 54.8%、CWE-bench 补丁修复 71.0%。Google 另称 Carbon 生成安全代码的成功率比 Argon 提高一倍以上，内部编码工作里的高严重度失准告警减少近八成，在 Gray Swan 的间接提示注入基准上抵御了全部攻击。

可用性与价格：本周起先向部分网络安全防御者开放，之后通过 Fairwind 计划逐步扩大到受信任合作方，普遍可用时间尚未公布。定价与 Argon 相同，每百万 token 输入 2 美元、输出 10 美元，缓存输入享 95% 折扣，介绍期后升至 4 美元与 20 美元。Google 未发布技术报告与参数规模，Ars Technica 认为 Carbon 可能是 Argon 的后训练升级。

关注理由

编码与 agent 任务的分数已经挤在 2 到 3 分的区间里，单看榜单难以支撑选型，价格、访问权限与单项任务的通过率权重上升。漏洞发现、利用验证、补丁修复三段基准一起公布，首发对象限定为防御方，说明安全能力正被当作进入企业编码流程的准入条件。

对多数开发者，短期内能用到的仍是同价位的 Argon；Carbon 的实际差异要等 Fairwind 计划放开，或第三方在自有代码库上复现后才可判断。

NO.02 · AI coding · 计价单位

GitHub 推出 Copilot Fusion，按任务在多个模型之间分派与互评

AI coding模型路由成本Octoverse
事件简述

10 月 28 日，GitHub 在 Universe 2026 发布 Copilot Fusion，一个按任务计价的编排层。它先判断任务属于推理、代码生成、调试还是工具调用，再决定交给单个模型还是多个模型协作；三种执行模式为 Single（直接派给最合适的模型）、Cascade（先用低成本模型，不够再升级）、Critique（一个模型起草、另一个评审、原模型据此修订）。开发者只选 Standard、High、Max 三档投入强度，不再逐次挑模型。

独立评测机构 Artificial Analysis 的测试显示，Fusion Max 在编码 agent 指数上与 Claude Opus 5.5 Max 相差 2 分以内，单任务成本 5.59 美元对 11.42 美元，速度快 40%；微软内部评估给出的节省比例最高到 77%。

同期发布的 Octoverse 2026 给出规模侧的数字：截至 9 月，超过 40% 的拉取请求由 agent 起草，3 月时是 17%，9 月由 agent 发起的拉取请求约 1.1 亿个；9 月单月提交 74 亿次，为去年同期的 5 倍。GitHub 为此增加 400 万个 CPU 核、160PB 高速存储与 50Tb/s 网络容量，并把计算与存储拆开部署，目标是把吞吐提高到 35 倍；年内多次宕机中，90 天可用性一度降到约 84%。

关注理由

计价单位从每百万 token 变成每个完成的任务，成本控制的位置随之从「选哪个模型」移到「设哪档投入、失败后重试几次」。路由加互评把模型选择交给平台，团队的比价对象变成任务完成率与单任务成本。

Octoverse 的 40% 说明 agent 起草已是主流入口，平台容量与可用性因此成为编码流程的真实约束——提交量涨 5 倍带来的宕机，代价由所有使用者分摊。任务级成本的数字来自第三方评测，测试任务集与样本量未公开，横向比较仍需自测。

NO.03 · 具身智能 · 部署后学习

智元发布具身 Agent 框架 Genie Master，门店里的机器人自己改策略

具身智能具身 Agent真实场景经验回流
事件简述

10 月 27 日，智元在 AI WAVE 活动发布具身 Agent 框架 Genie Master，是这场活动里的第四项发布。核心是一套具身执行协议 EEP，把能力、引导、反馈、连续性四类接口统一起来：agent 能查到当前机器人有哪些动作能力可调用、这一步应如何引导执行、实际结果是否达到要求、还有哪些任务待完成。任务中途失败时系统保留已完成的进展，agent 从断点重新规划；多台机器人协作时，agent 跟踪分工与任务依赖，支持动态调度。

经验沉淀走两条路。Harness RSI 把每次成功与失败的案例随做随记，每日任务结束后由模型总结，可复用的部分写进长期记忆，下次遇到同类场景直接调用；Policy RSI 把 agent 介入执行、接管与恢复过程中产生的数据回流训练动作策略，让改进保留在模型参数里。官方举的例子是挂货：头部相机分辨率不足、挂钩被标签牌遮住，agent 回溯失败记录后改为左手先用腕部相机近距离定位，再由右手完成挂货。

搭载该框架的精灵 G2 已在真实便利店上岗，官方称熟食打包、取货、补货等精细任务无需人工示范与调参即持续改进，并把这一结果描述为首次脱离仿真与实验室环境验证 Physical RSI（具身递归自进化）。11 月 2 日，智元将让 6 台 G2 连续 24 小时直播作业，覆盖午间高峰、晚高峰、深夜值守与清晨四个班次。

关注理由

把部署后继续变好拆成记忆层与参数层两条可以分别实现的路，比笼统讲端到端模型更接近工程现实：记忆层当天就能生效，参数层需要数据回流与训练闭环，两者的投入与风险完全不同。若同一套能力能随门店数量复制，边际成本下降是零售场景规模化的关键变量。

目前公开的是单一门店、单一零售业态的自述结果，没有任务成功率、人工干预次数、单次任务耗时这类可比较指标；24 小时直播能证明短时稳定性，不等于长期无人值守。

NO.04 · 终端智能 · 人机接管

腾讯 WorkBuddy 上线远程控制，手机可直接接管电脑上的 agent

终端智能桌面 agent远程接管权限
事件简述

10 月 28 日，腾讯 WorkBuddy 上线「远程控制」，由腾讯 Edge One 团队提供技术支持。手机 App 一键连上同账号的电脑后可看到桌面实时画面，连接建立后画面以小窗悬浮在首页或会话页顶部，下方输入框照常可用，发现任务跑偏可直接发指令纠正。

切到全屏横屏即可用小屏操作大屏，手指点按对应电脑上的同一位置；右侧有操作、键盘、鼠标三个按钮，可平铺查看所有窗口、回到桌面、切换清晰度，键盘可调用手机输入法或电脑键盘与常用快捷键，虚拟鼠标用于点击过小的按钮。使用门槛是手机端 App v2.7.0 及以上、macOS 桌面端 v5.9.3 及以上，首次需在电脑的设置 → 设备连接里开启「允许同账号设备远程连接」、安装远程遥控组件并授予屏幕录制与系统录音、辅助功能两项系统权限。

官方给出的约束是：一台电脑同一时间只允许一部已认证手机连接，画面与操作走加密通道，不记录用户输入内容，也不保存远程控制画面，远程控制只消耗数据流量、不消耗 Token。

关注理由

agent 的任务时长已经越过「人坐在电脑前」的边界，远程接管的实质是把监督权搬到手机上：能看每一步、能在中途纠偏，比只接收结果更贴近值守场景。对长任务与需要临场判断的桌面操作，这是使用频率很高的需求。

代价在权限。屏幕录制与辅助功能属于系统级授权，一台电脑只绑一部手机的限制说明厂商把同一时刻只有一个操作者当作安全前提。企业环境里这类授权能否通过合规审查、远程通道的审计记录如何留存，会决定它能否进入办公流程。

NO.05 · Agent 安全 · 攻防

44 个 agent 分工完成入侵，TrendAI 披露三起针对日本目标的案件

Agent 安全多 agent 编排攻击自动化取证
事件简述

10 月 27 日，Trend Micro 旗下企业安全部门 TrendAI 发布分析，研究者 Bakuei Matsukawa 与 Joseph C. Chen 复盘了三个暴露在互联网上的攻击者服务器环境，其中存放着侦察与攻击工具、脚本、目标清单、结果、日志与命令历史。

第一起案件使用开源渗透测试平台 CyberStrikeAI，把侦察、漏洞发现与验证、利用、命令控制、持久化、数据窃取与自动报告串成一条可重复的工作流，由 44 个 agent 分担不同环节，并能生成日语表单与仿冒登录页。短期内至少 19 家可识别组织被验证扫描，其中至少 16 家在日本，每家都拿到同格式报告与证据索引。另两起案件中，一起由人主导、用大语言模型加速攻击规划与工具开发，另一起里模型只用于编写脚本。研究者表示目前没有证据显示三起案件出自同一操作者，所用模型也未确认。

关注理由

这次披露有价值的地方在证据形态：同格式报告加证据索引，说明攻击方已经把多 agent 编排当成生产线使用，防御方可以据此做指纹识别与检测规则；只看单个恶意样本会漏掉整条流程。

对 agent 平台的含义是，攻防两侧用的是同一类开源编排框架，差距更多落在流程设计与并行程度上；模型来源不明也意味着按模型封禁的办法作用有限。同一批 agent 能自动生成目标国语言的仿冒页面，把社工环节也纳入流水线，这是此前的自动化工具较少覆盖的部分。
