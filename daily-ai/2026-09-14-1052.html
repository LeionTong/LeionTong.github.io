01 / 04

OpenAI 把 Codex 运行 harness 封装为 Agents API，公开测试版上线

AI Agent 托管基建 沙箱 MCP
事件

9 月 10 日，OpenAI 将 Agents API 面向全部开发者开放公开测试版，把支撑 Codex 与 ChatGPT for Work 的同一套运行 harness（会话编排、上下文压缩、工具调度、子代理委派与失败恢复）封装为托管 API。开发者自带任务、模型、工具与执行环境，可在 OpenAI 托管沙箱、自建沙箱或 Cloudflare / Vercel / Oracle 等伙伴沙箱中运行；内置代码沙箱执行、文件编辑、MCP 连接、产物生成与多代理委派。无额外费用，按 token 与工具用量计费；数据仅存美国，暂不支持零数据保留（ZDR）。

关注理由

这次产品化的对象是「长时运行 agent 所需的基础设施」，而不是模型本身。OpenAI 等于把 Codex 从一个命令行工具变成一个可被调用的托管服务，沙箱、MCP、子代理与恢复都成了 API 的一等能力，开发者构建生产级 agent 的门槛将从「自建 harness」降为「拼接托管能力」。对 Agent 与 AI coding 的含义是：执行环境选择、数据驻留与可观测性正在成为模型能力之外的下一个竞争层。

来源 · OpenAI 官方博客 Introducing the Agents API；The Decoder · OpenAI’s new Agents API

02 / 04

中国移动云发布国产 GPU + 类脑芯片异构混合推理系统

AI Coding 推理算力 多智能体 国产化
事件

9 月 13 日，2026 中国算力大会（廊坊）「算力首创首发」专场上，移动云联合中国电子科技南湖研究院、北京灵汐科技、上海天数智芯、清华大学、北京大学发布国内首个 国产 GPU + 类脑芯片大模型异构混合推理系统。思路是对 Transformer 做 PD/AF 拆分：Prefill 与 Attention 交给国产 GPU，延时敏感的 FFN/MoE 交给存算一体、片上大容量 SRAM 的类脑芯片，再以自研编译器、高速互联协议与统一推理引擎协同调度，对标英伟达 Vera Rubin + Groq 架构。在 DeepSeek V4 Flash 上实测，相较同等投入的国产 GPU 集群，推理输出与能效提升 1 倍以上、业务运营成本下降 40% 以上，已进入小批量试产。

关注理由

在先进制程供给受限的背景下，这条路线从「堆单卡算力」转向「混合架构分工」，为国产推理算力提供了不依赖制程红利的系统创新路径。系统明确把目标打在 Token 工厂、AI 代码生成、多智能体协同等高并发推理场景，说明 agent 与 coding 工作负载已是国产算力对标的靶点；若推理成本结构性下降成立，它可能成为国产大模型在 coding / agent 场景规模化落地的成本杠杆。

03 / 04

Rokid 在 IFA 2026 发布 AIUI Studio，面向 AI 眼镜的智能体创作平台

终端智能 AI 眼镜 智能体开发 生态
事件

9 月上旬，Rokid 在德国柏林 IFA 2026 面向全球发布一站式智能体创作平台 AIUI Studio，专为 Rokid 系列 AI 眼镜打造。平台整合 AIUI Skills Library 框架与 AIUI Code 辅助编程工具，开发者可在浏览器内完成智能体的设计、编码、实时调试与发布全流程；内置眼镜模拟环境，无需实体设备即可开发测试，并支持自然语言生成应用原型，系统自动针对硬件做延迟、内存与功耗优化。目前 Rokid 全球开发者社区约 3.5 万注册开发者，Agent Store 已上线 500 余款智能体。

关注理由

AI 眼镜的竞争正从硬件参数转向开发生态。Rokid 把「面向眼镜的智能体开发」做成了浏览器内的一站式平台并开放 Agent Store，实质是在争夺无屏 / 小屏设备上智能体应用的创作入口，降低开发者上手的门槛。这与蚂蚁「灵影」的可穿戴 agent 底座属同一主线：终端智能的胜负手，正从设备本身转移到「谁能最快把智能体生态长出来」。

来源 · PR Newswire · Rokid Launches AIUI Studio at IFA Berlin 2026；中国电子报《AI 眼镜悄然开启下一程》

04 / 04

Weave Robotics 发布家用人形机器人 Isaac 1，定价 7999 美元

具身智能 家用机器人 消费定价
事件

美国旧金山初创 Weave Robotics（YC 系）发布首款家用移动人形机器人 Isaac 1：轮式底盘 + 双臂 + 双爪（无腿、无手指），可承担折叠衣物、整理房间、铺床、收纳玩具等家务；机身可自 0.9 米伸展到 1.7 米，具备自主导航、任务间回充与 App 远程调度。定价 7999 美元整机或每月 449 美元订阅，9 月起先在加州交付，全美计划 2027 年铺开。

关注理由

家用机器人第一次把「能干活」与「可负担」放到同一价位，比双足人形竞品低一半以上。设计上刻意砍掉腿与手指，把工程资源集中在躯干与上肢，说明消费具身智能的竞争正从「更像人」转向「更便宜地完成任务」。随之而来的还有远程操控兜底与家庭数据训练两条争议线，隐私与自主性的边界会成为家用机器人进入客厅前的核心议题。
