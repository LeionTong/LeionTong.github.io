信号 01 / 终端智能 · 本地 Agent 运行时

Perplexity Portable Computer：把整套 Agent 运行时压到本地 DGX Spark，离云前先过 PII 分类器与用户授权

Agent Locality本地零 token 费85.4% LKWB本地优先

事件

8 月 25 日 Perplexity 发布 Portable Computer——其自主 Agent 平台 Computer 的完全本地版：

  • 运行时全本地：编排器 LLM、子代理 LLM、Agent harness 全部跑在用户自己的硬件上，默认无云端依赖。首发支持 Nvidia DGX Spark（GB10 superchip / 128GB / 1TB）与装有 RTX ≥24GB 的 Linux 机器。
  • 本地任务零费用：凡是本机可处理的任务，不产生任何 per-token 计费；模型可选阿里 Qwen3.8-27B 或 Perplexity 自训的 PPLX 27B，Nvidia Nemotron 3.5 Lightning 随后接入，并支持自带模型与推理服务器。
  • 离云前的护栏：仅当任务需要联网或超出本地模型推理能力时，orchestrator 才暂停并请求用户授权；上云前先经 PII 分类器筛选上下文、只共享必要片段，云模型仅返回指导、不直接触碰本地文件/工具/对话其余部分。
  • 系统级沙箱：代码与工具调用在 OS 强制沙箱内执行（限制进程、文件路径、网络）；沙箱不可用时直接禁用工具执行，而非放行。
  • 实测：PPLX 27B 在 DGX Spark 上跑自家 53 任务 Local Knowledge Work Bench 得 85.4%，高于同硬件开源替代；混合任务开云升级后大幅收窄与顶级云模型的差距，成本仅为零头。
  • 生态连接：演示中 agent 把数据分析结果直接发到用户 Slack 频道，并支持经本地 orchestrator 连 Google Drive / Gmail / GitHub。Windows 9 月、macOS 暂不在路线。
为什么值得关注

这是「Agent Locality」（智能在本地设备与云之间按需分布，而非集中于远端数据中心）从概念到可装产品的标志——Agent 不再默认住在数据中心，而是住在用户自己的硬件里，且隐私护栏是架构而非提示词。

可核验数据点 · 8/25 发布 · DGX Spark GB10/128GB/1TB · RTX ≥24GB · 本地零 token 费 · PII 分类器 + 用户授权离云 · Local Knowledge Work Bench 85.4%（53 任务） · Qwen3.8-27B / PPLX 27B / Nemotron 3.5 Lightning · Windows 9 月 / macOS 暂无 | 冷静点：仅 Nvidia Linux 桌面，Apple Silicon 缺席；85.4% 为 Perplexity 自测 53 任务基准；重推理仍需云端升级，本地优先 ≠ 本地唯一
信号 02 / AI Agent · 机器经济基础设施

Cloudflare Kitesurf + Wallets + x402：给 Agent 配齐「浏览器 + 钱包 + 支付轨」，20+ 公司已跑通 agent 发起支付

Agent 经济无人在环付费稳定币结算20+ 公司

事件

Cloudflare 在跨三周的三次发布里，给出 Agent 自主经济的完整套件（8/24 被多家媒体作为「Agent 首次能无人在环地浏览与付费」合并同类项）：

  • Kitesurf：用 Rust 写、跑在 Workers V8 isolates 上的无 Chromium 无头浏览器，截图与 HTML 抽取比传统方案省 3–7× CPU 与内存；讲 Chrome DevTools Protocol，故现有 Playwright / Puppeteer 客户端可直接用。免费 beta。
  • Wallets：人类注资账户、把封顶额度委托给 Agent，让机器在额度内自主支配。
  • x402 协议：让任意站点 / API 按请求向 Agent 收稳定币，在边缘节点即时结算，无需传统支付对账。
  • 采用度：已有 20+ 家公司进入 agent 发起支付的真实流程。
为什么值得关注

Agent 第一次同时拿到「浏览器（感知外部世界）+ 钱包（支配资金）+ 支付轨（结算）」三项组合，能无人在环地浏览与付费——这是「机器管钱 / 签字」长期主线的工程兑现（此前 08-05 仅为架构设想）。对 AI coding / Agent 赛道，这意味着 agent 不只是「写代码」，而是能「自己采购依赖、自己付 API 费、自己结算任务」。

风险面也正是治理面：谁来为 Agent 的采购签字、封顶额度能否在网络层真正硬约束、稳定币收付费的责权框架，目前仍缺位——这与本期信号 05 的治理化互为表里。

可核验数据点 · 8/24 三周连发被合并报道 · Kitesurf Rust/Workers V8/省 3–7× 资源/讲 CDP · Wallets 注资 + 封顶委托 · x402 稳定币按请求边缘结算 · 20+ 公司 agent 支付流 | 冷静点：支付闭环依赖稳定币与边缘结算生态成熟度；「无人在环付费」的责权法律框架仍空白，属高价值但高风险的基础设施
信号 03 / 终端智能 · 三重跃迁与密度定律

面壁智能周树峰：终端智能进入「三重跃迁」，底层是「密度定律」——能力密度约每 3.5 个月翻一番

密度定律每 3.5 月翻倍去屏幕化全模态闭环

事件

8 月 26 日人民网财经研究院金台圆桌，面壁智能商业化副总裁周树峰系统表述终端智能的新阶段：

  • 密度定律：大模型最大能力密度约每 3.5 个月翻一番，同等性能所需算力与资源呈指数级下降——这意味着高效模型可部署到手机、汽车、PC 与各类物联网设备承载真实应用。
  • 三重跃迁：① 交互从屏幕操作转向语音 / 无界面，由被动响应转主动服务；② 能力从单模态走向全模态（语音 + 视觉 + 用户状态）感知-决策-执行闭环；③ 终端呈现「快思考（实时追踪/意图）/ 中思考（感知理解精度）/ 慢思考（深度规划）」协同。
  • 硬门槛：芯片、算法、操作系统与传感器的软硬件磨合；与真实用户场景一致的评测基准；发挥端侧独有的数据主权、长期记忆与常驻智能体优势，让个性化服务在数据不出设备下完成。
为什么值得关注

这是终端智能从「共识（密度定律）」到「路径（三重跃迁）」的系统表述，且明确点出端侧独有优势——数据主权、长期记忆、常驻 Agent。端侧模型下沉速度（3.5 月翻倍）意味着「端云协同」闭环的工程窗口也在快速前移。

与信号 01 形成互补：Perplexity 给出本地运行的「产品实例」，面壁给出终端智能的「演进规律」——两者共同把「终端 Agent 可行」从口号推进到可规划。

可核验数据点 · 8/26 人民网金台圆桌 · 密度定律（能力密度约每 3.5 月翻倍） · 三重跃迁（去屏幕化/全模态/快中慢协同） · 硬门槛（软硬件磨合/评测/数据主权） | 冷静点：密度为厂商表述的经验规律而非物理定律；「快中慢思考」协同尚无统一实现标准，需看后续产品落地
信号 04 / 具身智能 · 从演示者到工作者（作业模式）

具身智能跨进工信部「作业模式」：年底百个以上高价值场景、万台级规模落地能力，近 10 家车企已产线验证

WRC 2026 余波万台级百个场景实景实训

事件
  • WRC 2026（8/19–23）余波：机器人从「演示者」加速走向「工作者」。优必选携 Cruzr Y1 / S2 工业人形实景作业（汽车钣金与机加件上下料、拆码垛、分拣）；乐聚 Taskor 部署方案把单机部署从数月缩至数小时，已获汽车、通信、家电、物流等 10 余行业头部客户认购；星动纪元物流方案携手顺丰、中国邮政在 5 省十余中心常态运营；魔法原子以轮式双臂作柔性工作站。
  • 政策锚点（光明日报 8/27）：工信部、国资委 6 月《2026 年度人形机器人与具身智能实景实训专项行动》明确——到 2026 年底，人形机器人在一批代表性场景率先完成应用验证与常态部署，凝练形成百个以上高价值应用场景，带动形成万台级规模落地能力。
  • 产业底盘：小米、比亚迪等近 10 家主流汽车生产商已在实际产线开展具身智能部署验证（物料搬运、上下料等）；2025 年机器人产业规上企业营收突破 3000 亿元，今年上半年 1655 亿元、同比 +24.5%。
  • 口径：本届 WRC 参展企业 300+（同比 +36%）、展品 2000+（+27%）、首发新品 150+（+21%）；专家共识是具身正从「小批量试用」转向「大规模落地」关键拐点。
为什么值得关注

具身智能的拐点从「会动」进入「真干活、可计量。万台级落地能力 + 百个高价值场景，意味着具身从样机采购转向「按场景交付」政策 + 产业双面背书。

可核验数据点 · WRC 2026（300+企业/+36% · 2000+展品/+27% · 150+首发/+21%） · 优必选/乐聚/星动纪元/魔法原子工业落地 · 乐聚 Taskor 部署 数月→数小时 · 工信部实景实训：年底百个+高价值场景 / 万台级 · 近 10 家车企产线验证 · 上半年营收 1655 亿/+24.5% | 冷静点：医院/家庭等深度场景仍试点；工信部专家直陈「各自为战/标准滞后」是系统性挑战；落地速度取决于数据闭环而非单点硬件
信号 05 / AI Agent · 规模化治理与企业化

Agent 规模化之后，治理成刚需：Copilot 进 Slack/Teams、Gartner 45% FTSE100 关键职能由多智能体管理、Agent 身份与注册表 GA

身份治理45% FTSE100Agent Identity进团队工作流

事件
  • GitHub Copilot 进 Slack / Teams（8/21 公开预览）：在任意频道 @GitHub 即可起云 agent，答代码问题、分诊 bug、在沙箱查故障并开 PR 回流对话；专用 Code 频道隔离工作；仓库管理员可要求 agent-authored PR 额外审批才合并，人类监督保留。
  • Gartner 8 月报告：45% 的 FTSE 100 公司已至少有一项关键业务职能由多智能体系统管理，年初仅 18%——从试点到生产的跨越正在加速（物流、金融、专业服务最密集）。
  • Google Cloud Agent Identity 认证管理 + API 达 GA：集中式 agent 凭证 / 鉴权 broker，使多厂商 agent 拓扑与每-agent 身份在规模上可行。

为什么值得关注

Agent 规模化后，稀缺资源从「能力」变成「身份 / 权限 / 审计 / 团队边界」——agent 从 IDE 走向组织工作流，治理从可选项变刚需。这与本期信号 01（本地化）、02（货币化）形成闭环：本地化与货币化解决了「能跑 / 能付」，治理化解决「跑得可控、付得有责」。
