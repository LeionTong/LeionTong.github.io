智能体手机三强同台，端侧 AI 走向"规模化落地元年"

事件

WAIC 期间，荣耀 RobotPhone、阶跃星辰 STEPX Neo、努比亚 NaviX Ultra 三款智能体手机同台亮相。荣耀主打"硬件具身智能 + 机械云台"，可手势唤醒自动追踪运镜；阶跃 STEPX Neo 深入操作系统层，以个人智能体 Amoo 统筹跨应用任务（机酒行程规划、规避冲突日程）；努比亚二代豆包手机以实体 AI 键 + 系统级 GUI Agent（MCP/A2A 直连）实现跨 App 闭环。中国信通院将端侧 OS 演进分为 OS+AI → AI 平台型 OS → AI 原生 OS 三阶段；面壁智能发布《端侧智能 2026——规模化落地元年》报告，称 2026 为端侧 AI 落地元年；工信部等《人工智能终端智能化分级》首批测试中，17 家企业 66 款产品达 L3 辅助级。

为什么值得关注
  • 交互范式从"以应用为中心"转向"以意图为中心"，系统级 Agent 引擎开始取代 App 列表成为手机 AI 中枢，或驱动新一轮换机潮。
  • 苹果、华为、OPPO、vivo、小米、三星、努比亚等 7 款手机端侧生成式 AI 服务集体完成备案，端侧模型从概念走进合规落地，融合进程有望提速。
客观提示：信通院姜春宇指出，OSWorld 评测中 500 步以上任务成功率仅 18%、部分完成率 54%，"智能体一多、目标一大，效果显著下降"；隐私与端侧硬件（NPU / 大内存 / 功耗）仍是普及门槛，短期主要定位旗舰产品。
AI Agent 环球网 / 阿里云 · 2026-07-18

阿里云发布 Agent Native Cloud，把 Agent 变成"企业原生能力"

事件

阿里云在 WAIC 发布 Agent Native Cloud（智能体原生的云），并推出 AgentTeams（多智能体治理协作）、AgentLoop（全栈观测优化）、Agentic Computer 等。Infra 层提供面向 Agent 场景重设计的 Sandbox（MicroVM/VM 级强隔离、可缩容到 0 的长会话低成本、高并发弹性）；平台层覆盖构建、治理、评估、优化，Identity / Gateway / Policy / 可观测等模块让每次操作可归属、每份资产可复用、每次迭代像微服务一样可控。

为什么值得关注
  • 行业共识正从"谁拥有更多 Agent"转向"谁能把 Agents 变成可控、可复用、可协作、会进化的组织资产"——这是 Agent 从 Demo 走向生产的关键一跃。
  • 强隔离 + 可审计 + 钥匙集中托管（Agent 本身看不到密钥，用完即收），直击企业最敏感的安全合规诉求。
客观提示：工具链再完善，落地仍依赖企业内部的 API / MCP / CLI 成熟度与业务流程改造，并非"上云即解决"。
具身智能 环球网 / 新浪 · 2026-07-21

小米人形机器人进厂，螺柱上件成功率提升至 98%，开源 Xiaomi-Robotics-U0

事件

小米机器人仿生操控负责人游洋威在 WAIC 分享《进厂手记》：人形机器人已在小米自有汽车工厂多工站试点，螺柱上件工站成功率从 90% 提升至 98%；团队近期开源 Xiaomi-Robotics-U0 具身生成模型，用生成式方式扩充数据样本、以更低成本提升多样性。游洋威判断：整体处于类似自动驾驶 L2 早期，工厂场景因结构化、约束清晰，将先于家庭消费场景实现规模化落地。

为什么值得关注
  • 工业场景是具身"价值落地"最务实的试验场：人形机器人可直接适配为人工设计的工位、无需大规模改造产线，一台故障可快速替换，新工位只需少量数据微调即可上岗，更适配多品种、小批量柔性生产。
  • 开源数据集 / 模型被视为突破"高质量场景数据匮乏"瓶颈的重要路径，单家企业难以独撑全行业技术突破。
客观提示：游洋威坦言"大脑（认知决策）与小脑（精准执行）深度融合"仍是行业共性难题；高质量真实场景数据获取成本高，行业对"千万 Clips 催生关键突破"的预期偏乐观，数据量级临界阈值目前尚未明确。
具身智能 财联社 / 科创板日报 · 2026-07-20

WAIC 具身展区：触觉成今年最大变量，告别"花架子"进真实场景

事件

本届 WAIC 具身智能展区汇聚超 200 家企业、300 余台具身机器人，"触觉"与"大脑"被视为破局关键，触觉被认为是今年乃至明年最具突破潜力的技术维度。优艾智合"隙锋"人形机器人采用分级训练框架：出厂即具基础动作能力，最低 50 条数据小样本训练即达 90% 任务成功率；云深处 DR02 全天候人形机器人完成变电站实地测试、2026 年启动商用投放；远征 A3 Ultra 成为 WAIC 十件"镇馆之宝"中唯一具身智能产品。

为什么值得关注
  • 行业从"展台演示"推向"真实场景压力测试"（工厂、餐厅后厨、变电站），场景价值成为检验技术成色的核心标尺。
  • "一脑多态 / 多机协同"架构让统一大脑调度不同形态机器人，在同一目标下自动拆解、自动分工，实现全局效率最优，是工业规模化落地的关键能力。
客观提示：多数展示仍为定点 / 限定场景验证，"今天进厂第二天熟练工"依赖 24 小时周期持续数据循环；跨场景泛化与真实环境鲁棒性仍需长期积累。

逐际动力 LimX COSA 0.5：国内首次机器人一镜到底全自主干家务，提出"系统才是大脑"反共识

事件

逐际动力发布人形大脑系统 LimX COSA 0.5，全尺寸人形机器人 Oli 无遥操、无剪辑、一镜到底完成一屋子家务（收衣、取衣、收纳玩偶、搬箱摞箱、深弯腰拾物、清理垃圾、递物）。系统由 S2 认知层（~1Hz）、S1 技能层、S0 运控层三层协同。创始人张巍提出反共识：纯大模型像"躺在病床上的霍金"——极聪明却无法自主行动；"模型只是技能，系统才是大脑"。

为什么值得关注
  • 把行业叙事从"谁的端到端模型更大"拉回到"如何把能力组织成能在真实身体上运转的系统"，对长程移动操作（家庭非结构化场景）是实质性推进。
  • 全球唯二、中国首个能全自主完成长程移动操作家庭任务的全尺寸人形机器人（继 Figure 之后）。
客观提示：家庭场景长尾问题多、安全要求高，距真正日常可用仍有距离；Demo 的工程条件（光照、物体摆放、任务编排）与真实家庭的开放性不可等同，需防止把"一镜到底"误读为"全场景可用"。
