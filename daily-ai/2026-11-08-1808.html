NO.01 · AI Agent · 订阅产品

Perplexity 把常驻 Agent 做成个人订阅里的同事，每个都带独立桌面与浏览器

研究预览Max 200 美元/月原生接 Slack 与 GitHub跨会话记忆
事件简述

11 月 5 日，Perplexity 向个人 Max 订阅用户开放 Teammates 研究预览，月费 200 美元、年付 2000 美元，网页端与 iOS 可创建。每个 teammate 是一个有固定职责的 agent：用户交给它一项长期责任，例如分诊缺陷报告、跟踪指标或调研市场，它自行把目标拆成任务、并行分派给多个 agent，并在需要人决定时来找人。

按官方帮助中心，每个 teammate 拥有自己的桌面与浏览器，可以操作没有连接器的网站、把自家站点从头到尾走一遍，用户可以随时接管并改变方向；它会盯住用户接入的 Slack、GitHub、Linear，在拉取请求收到评审意见后自行跟进，跨对话保留记忆与既定职责。同一个 Project 内的 teammate 共享上下文、文件与指令，彼此可以互发消息；每个 teammate 用哪个模型可以单独指定。企业版 Enterprise Pro 与 Enterprise Max 不在本次范围内。

关注理由

常驻 agent 从演示项目变成按人头计费的订阅功能，评价标准随之从单轮回答质量转向「能不能连续几天守住一件事」。每条职责配独立桌面与浏览器，等于把隔离与权限边界做到 agent 粒度，运维形态更接近给每个同事发一台机器。

对做终端与本地 agent 的团队，这里的信号是记忆与职责的持久化已经进入产品定价，与模型能力并列成为卖点；每个 agent 独占环境也意味着常驻成本要按并发数估算，与账号数量关系不大。

NO.02 · 编码基础设施 · 版本控制

OpenAI 为 agent 并发重写自家 Git 后端，推送中位时延降近五倍

Pando每日近 1PB Git 数据兼容 Git 协议按分支独立协调
事件简述

11 月 2 日，OpenAI 在工程博客公开 Pando，一套与 Git 协议兼容的仓库后端，现已承载公司 monorepo 的全部开发，接入过程没有中断工程工作，也没有改变团队使用 Git 的方式。触发原因是 Codex 让单个工程师同时准备好几份改动，每次推送又会带起多个取代码、跑检查的任务；从去年年底起，原来的系统拉取与推送变慢、合并失败，可靠性一度掉到 90% 以下。

Pando 对每个分支的更新单独协调，不相关分支的推送可以并行进行；读取侧按打满客户端带宽设计，并把压缩与首字节时间单独优化。生产环境中推送中位时延降低近 5 倍，每天送出接近 1PB 的 Git 数据。团队保留了 Git 协议与客户端，把客户端侧的改动回馈给上游 Git 项目。

关注理由

编码 agent 把版本控制从「人按天提交」推到「agent 按分钟推送」，读写并发成为托管层的硬瓶颈，而这一层过去二十年几乎没有被重做过。按分支协调写入、读写资源分离这两条做法，对自建代码平台的团队可以直接借鉴。

同期的行业压力是共性的：GitHub 在 10 月 28 日披露今年新增 400 万个 CPU 核心与 160PB 高速存储，并把不同分支的写入改为并行；Anthropic 披露单日合并改动已超过 3 万项、改用自研系统。代码托管从通用服务变成需要按 agent 流量重新设计的专用基础设施。

NO.03 · 具身智能 · 媒体场景

新华社与优必选发布仿生人形主播，按 1:1 复刻并接入时政资讯智能体

新言 / 新语1:1 真人比例新华语典现场出镜播报
事件简述

11 月 5 日，第七届世界媒体峰会人工智能与中国式现代化论坛上，新华社与优必选联合研发的仿生人形机器人新闻主播「新言」「新语」亮相，导演张艺谋担任形象主创设计。两台机器人按 1:1 真人比例复刻，具备现场出镜播报能力。

内容侧接入新华社的 AI 时政资讯智能体「新华语典」，实时调取经过审核的时政资讯；技术侧由优必选提供仿生皮肤、具身智能硬件、操作系统、情感大模型到整机量产的全链条能力，构成「大脑—表达—控制」的技术链路。新华社新媒体中心称机器人主播是编辑部的新增工种，承担资讯播报、多语种输出与现场交互，后续规划进入研学基地、城市会客厅、海外文化交流与深空探索报道等场景。

关注理由

播报场景把口型、表情、语音与动作的同步压到镜头级别，要求远高于展厅演示；内容只从受控资讯库调取，是把生成式模型的不确定性挡在播报之外的一种工程做法，代价是表达能力受限于已有资讯。

仿生人形要进媒体与展厅，整机量产与仿生皮肤工艺仍是门槛，这类项目通常由整机厂全链条承接。对终端产品来说，可借鉴的组合是人形外观、受控知识源与现场交互，通用对话能力在这里只是底座，真正交付的是播出稳定性。

NO.04 · 具身智能 · 资本市场

Agility 在纳斯达克挂牌，称首家美国上市的纯人形机器人公司

AGLT约 4.65 亿美元募资Digit 5 逾 3 亿美元订单6.5 万小时运行
事件简述

11 月 5 日，Agility Robotics 与 Churchill Capital Corp XI 完成合并，普通股与认股权证在纳斯达克以 AGLT、AGLTW 交易。交易与相关融资合计募资约 4.65 亿美元，未扣交易费用。公司称自己是首家在美国上市、且在运行真实商业部署的纯人形机器人公司。

上市材料给出的底数是近三年部署经验、累计逾 6.5 万小时运行；Digit 5 已获得逾 3 亿美元多年订单，受合同里程碑、功能与规格约束。客户包括 GXO、舍弗勒与丰田加拿大工厂；GXO 佐治亚仓由 Digit 搬运逾 10 万个周转箱，2027 年初再进两处美国物流设施，AGCO 的付费试点也定在 2027 年启动。

关注理由

人形机器人第一次有了公开市场的定价参照，订单、运行小时与单机产出会被季度披露，行业叙事被迫换成可核对的数字，估值要跟着交付节奏走。

收入来源仍集中在物流与制造仓的搬运任务，手部灵巧操作与大范围移动还没有进入订单结构。对供应链厂家，客户的多年订单与产能承诺开始比演示视频更能说明采购节奏与备货时点。

NO.05 · 世界模型 · 端侧部署

MoWorld 2.0 把重力、柔体、流体放进同一个世界模型，昇腾上跑到 70 帧

4D 世界模型70 FPS推理成本约为 GPU 方案三成端侧 6 亿参数
事件简述

11 月 4 日，乌镇世界互联网大会期间，魔芯科技发布通用 4D 世界模型 MoWorld 2.0。训练时同时学习重力、弹力、柔体、流体等物理要素各自的作用与叠加之后的效果；实现上用物理高斯渲染器支持不同要素的交互与渲染，并以多专家预测分别输出物理、像素与高斯三类信息。生成的场景可保存为 3D/4D 高斯资产，继续编辑、渲染与反复调用，供游戏引擎、影视制作与机器人仿真训练平台使用。

速度与成本方面，模型在华为昇腾 NPU 上的实时视频推理从上一代最高 50 帧提升到约 70 帧，推理成本最低为同规模 GPU 方案的 30%。约 6 亿参数的端侧模型在昇腾平台完成训练后部署到搭载麒麟芯片的手机，负责渲染与交互；华为新款手机上的「摸小宠」用几张宠物照片建立宠物 4D 数字分身，高斯资产的渲染帧率可达 500 帧，手机端测试约 100 帧。

关注理由

世界模型能否用于机器人训练，取决于生成内容可否复用、物理是否自洽，以及单位算力能产出多少可训练场景。把产物存成高斯资产、把多类物理要素并入同一模型，解决的是复用与一致性；70 帧与三成成本解决的是仿真循环的吞吐，这决定它能否进入强化学习的训练闭环。

从昇腾训练到麒麟端侧推理，一条链路走通意味着这类模型不必绑定单一供应商；对做具身智能仿真的团队，可编辑的场景资产比一次性视频更有价值，因为同一环境可以换障碍物、天气与路面条件反复测试。
