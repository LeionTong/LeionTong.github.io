NO.01 · AI Agent · 常驻架构

DeepSeek 开放常驻型 agent 原型，把多个会话交给路由层管理

AI Agent多会话投机执行MIT 许可
事件简述

10 月 31 日，DeepSeek 在 GitHub 放出 dsh-superagent-prototype，采用 MIT 许可，仓库现有 73 个星标、7 次分叉。结构分两层：上层 Router 接收消息、分配任务并维护全局上下文，下层多个 Worker 会话并行执行；某个 Worker 接手一条 GitHub PR 后可直接订阅后续评论，意见经直通机制交给该 Worker，不再经 Router 逐层转发。

公开文档提出四个特征：连续（跨会话、跨工作平台保留任务上下文）、高效（耗时任务不阻塞新的交互）、主动（持续观察环境，必要时自行采取动作）、持久（长期在线，异常可自行恢复）。配套机制包括两级事件过滤（先由程序规则筛除无关消息，再由模型判断是否行动）、异步 ReAct 循环（已在 DeepSeek Harness 中实现，尚未默认开启）、计算与状态、执行环境分离（设备离线时云端维持任务状态），以及一个独立的 Watchdog，用于判断任务是否陷入无效循环或偏离目标并尝试介入。

实验环境为约 300 条消息、20 项工作请求的模拟协作场景，每种配置重复 5 次。任务完成时间中位数 12.4 分钟，95 分位 15.7 分钟；传统单会话方案在中性提示下 95 分位为 29.5 分钟。取消直通机制后，Router 决策次数增加约 30%，读取缓存 token 增加约 37%。

关注理由

这套做法要处理的问题是人的注意力上限：模型单任务能力变强之后，同时能跟进的工作条数成了瓶颈，公开文档给出的观察是多数人只能同时跟进 3 到 5 个活跃会话。把会话管理从人转移到系统，换来的是排队时间，付出的是路由判断与上下文读取的 token。

可直接借用的是三项与模型无关的结构：会话与任务解耦、按对象订阅消息、用独立的监督进程判定无效循环。数字来自自建模拟环境，任务类型与规模有限，接入真实 IM 与代码托管平台后的稳定性仍需观察。

NO.02 · AI coding · 分发链路

Cursor 扩展市场里被替换的 Claude Code 扩展装了 SSH 后门

AI coding供应链凭据外泄持久化
事件简述

10 月 29 日，Cursor 市场里的 Anthropic.claude-code 扩展 2.1.313 版本的 macOS 与 Windows 构建被第三方替换，暴露时间约从 09:27 到 20:35 UTC，Cursor 称最多影响 5,000 名用户。恶意代码收集主机名、用户名、操作系统、家目录路径与公网 IP，向目标机器的 SSH 公钥清单写入攻击者密钥，建立指向 134.209.82.225 的反向 SSH 隧道，并落下独立的持久化脚本；分析方指出因代码错误，多数 macOS 与 Windows 上的 SSH 常驻实际未成功。

处置过程：Cursor 下架该版本并关闭市场自查，轮换密钥后重建市场，联系托管服务商下线攻击者服务器，Anthropic 当晚发布 2.1.314。卸载扩展不足以清除后门，Cursor 的公告要求删除未经授权的 SSH 公钥、持久化项与隧道进程，并在可信设备上轮换受影响主机的凭据。安全公司 Socket 另指出，Open VSX 的公开记录里没有 2.1.313 的发布或撤除事件，早期把来源归于 Open VSX 的报道缺乏依据。

关注理由

编码助手的扩展市场正在成为新的分发通道：扩展装在有源码、云凭据与生产访问权限的开发机上，一旦被替换，获得的权限接近开发者本人。审核与签名环节没能拦住这次替换，暴露窗口接近 11 小时，说明第三方市场的准入检查不足以承担这类风险。

可执行的做法是把 IDE 扩展按供应链组件管理：固定版本、核对安装包哈希、维护装机清单，并单独排查 10 月 29 日是否装过 2.1.313。

NO.03 · AI coding · 用量与定价

Claude 订阅改名 Max 与 Ultra，Ultra 取消五小时窗口

AI coding订阅额度长程任务口径变更
事件简述

10 月 31 日，Anthropic 把 Claude 的 Max 5x 计划改名为 Max、Max 20x 改名为 Ultra，价格维持每月 100 美元与 200 美元。通过账号验证的 Ultra 用户可以在每周额度内连续使用，不再受五小时窗口限制，周额度仍为 Pro 的 10 倍，并保留新功能优先体验、Claude Code 与后台长程任务的可用权。

订阅产品负责人 Mike Overell 说明改名缘由：原先的「20 倍」指单个五小时窗口内为 Pro 的 20 倍，后来叠加的周额度只有 10 倍，两个口径并存造成误解，公司为此前的沟通致歉。现有 Ultra 用户陆续解除限制，新账号需先通过基于账号与支付历史的自动验证，界面上的五小时进度条消失即为生效。

关注理由

五小时窗口是长程 agent 任务的硬边界，跑测试、改多个仓库、做批量重构这类任务经常在窗口边界被截断。取消窗口后，连续数小时的工作可以在一个额度内完成，中断与重排的次数下降。

额度口径统一到周维度，会改变按订阅折算的单位任务成本。此前按窗口倍率估算容量、用多账号并行跑 agent 的方案，需要按新的周额度重算；改名也把长期存在的宣传与实际额度差异放到了明面上，采购与合规环节的说明材料应同步更新。

NO.04 · 终端智能 · 车规算力

新芯航途发布 700 TOPS 车规芯片，用世界模型做算力口径

终端智能端侧算力世界模型车规功能安全
事件简述

10 月 31 日，成立两年多的芯片公司新芯航途（XHEART）首次对外亮相，发布车规芯片 X7 Ultra：算力 700 TOPS，NPU 计算利用率 98.7%，量化模型输出与 FP32 基准模型的相似度超过 99.99%，对比行业旗舰产品内存带宽消耗降低 80%、能效提升 100%。NPU 采用超大核架构并提升核间互连带宽，为 LayerNorm、Softmax、Transpose 等高频算子配置专用计算引擎；处理子系统加入每秒 2000 万点的激光雷达加速器，摄像头链路处理稳定性提升 100%；CPU 采用 Arm v9 车规架构（该架构在中国首次上车），SoC 达到 ASIL-B、集成 MCU 达到 ASIL-D。上一代 X7 已在上汽大众的新车上量产。

评测口径被命名为「大模型算力」：在模型结构不改、精度不降、驾驶体验不打折的约束下，直接用 Momenta 的量产世界模型 R7 测整颗芯片，而不只看单项实验室基准。Momenta 首席执行官的判断是，端侧模型要达到 10B 甚至 100B 参数级别才支撑 L4 的大规模部署，芯片的算子类型、数据访问与并行关系需要在设计阶段就与模型架构一起考虑。

关注理由

端侧算力的可比性长期被 TOPS 数字掩盖，等数据、算子拖尾、调度损耗都不在单项基准里。用真实量产模型测整条流水线，能把这几项一起计入，所得数字更接近车上的实际表现。对做端侧推理选型的团队，这套口径可以搬到自己的模型上复核。

世界模型进入设计阶段之后，模型迭代会反过来改写硬件选型的周期：算子分布与数据搬运方式一变，专用加速单元的价值就变。这意味着端侧芯片的替换节奏开始跟随模型版本，硬件规划不能再按五年一代来排。

NO.05 · 具身智能 · 供应链政策

美国认定进口机器人威胁国家安全，转入 180 天谈判

具身智能232 条款供应链关税风险
事件简述

10 月 28 日，美国总统签署公告，商务部按 232 条款完成的调查认定机器人与工业机械及其零部件的进口数量与情形威胁美国国家安全。公告列出的依据包括：国防系统与 16 个关键基础设施门类依赖机器人与工业机械、2024 年相关设备产值约 860 亿美元、美国多数品类依赖进口且本土产能不足以满足需求、来自特定境外实体的产品存在网络安全风险。文中点名自主机器人、人形与四足机器人、无人地面车辆在侦察、排爆、伤员转运等军事情景中的用途。

采取的措施是先谈判：商务部长与贸易代表与贸易伙伴商谈协议，180 天内汇报进展；公告保留后续加征或修改关税、设定配额与费用的选项，并提出可设立鼓励本土投资的项目。公告同时要求商务部持续监测进口情况。

关注理由

人形机器人整机与关节、减速器、传感器等主要产能在东亚，这次认定把整机与零部件一起纳入 232 范围，出口美国的成本结构存在被改写的可能。人形与四足机器人被直接点名，说明审查对象已经从工业机械扩展到具身智能的整机品类。

180 天的谈判窗口给出明确时间表。做海外交付、海外建厂与供应链选型的团队，需要在报价、合同与备件计划里预留关税情形，并把原产地与关键零部件来源纳入可追溯清单。
