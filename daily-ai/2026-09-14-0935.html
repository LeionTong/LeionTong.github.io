AI 编程与智能体进入生产治理阶段

面向 AI Agent、AI Coding、终端智能与具身智能的每日要闻筛选 · 整理：Leion

NO.67 · 2026-09-14

本期聚焦 9 月 9–14 日 AI 编程与智能体的密集落地：国家级"人工智能+软件"专项把智能编程与智能体软件纳入政策红利；Cursor、GitHub、Claude Code 三条主线把编码智能体推向多代理编排、周期任务与企业治理；终端侧蚂蚁"灵影"把 agent 运行底座下沉到 AI 眼镜等新终端；具身智能则在服贸会与智博会展示从展台到车间的真实作业。

01 / 05

工信部印发"人工智能+软件"专项行动，智能编程与智能体软件上升为国家专项

AI Coding 政策 开源 智能体软件
事件

9 月 11 日，工业和信息化部印发《"人工智能+软件"专项行动实施方案》（工信部信发〔2026〕209号）。目标分两档：到 2028 年，培育一批高水平智能编程工具与智能开发平台，推广应用覆盖 2 万家规模以上软件企业，在重点行业打造 100 个智能体软件标杆应用，累计实施 100 项软件企业智能化技改，孵化 5 个以上优质开源项目；到 2030 年关键软件全面实现智能化升级，智能编程、智能体软件及智能服务成为产业新增长极。

配套开源方面，方案依托开放原子开源基金会与国家级人工智能开源社区 AtomGit 完善人形机器人开源生态。据工信部新闻发布会披露，截至 2026 年 8 月，AtomGit 已托管超 8 万个模型、37 万套数据集，注册用户超 1200 万。

关注理由

这是首次把"智能编程工具 + 智能体软件"作为独立专项行动部署，意味着 coding agent 与 agent software 进入政策红利窗口。自主工具链、开源社区与算力券等普惠支持，将直接降低中小企业用模用智门槛。行业背景是 2025 年全国软件业务收入 15.48 万亿元、2026 年 6 月日均词元调用量突破 500 万亿——软件生产正从人力驱动转向智能驱动，政策正在为这一转向提供确定性。

02 / 05

Cursor 上线 Projects，单人可调度数千编码子智能体

AI Coding 多智能体 编排
事件

9 月 10 日，Cursor 在 IDE 左侧导航推出 Projects（测试版，向全部用户逐步推送）。核心是常驻的协调智能体（coordinator）：本身不写代码，负责规划、拆解任务并委派给执行、测试、研究的子智能体，单个协调者可委派至 数千子代理。项目运行在专属云端机器，关闭笔记本不中断；维护跨月数月的共享上下文，新代理自动继承前人的测试与代码库经验；可订阅 Slack 频道、PR、CI 信号，按事件或定时自动行动。

关注理由

AI 编码从"单助手逐任务"跨入"个人指挥多智能体团队"的阶段。真正的竞争点落在协调层——谁负责派活、记住上下文、做评审与合并，谁就握住多代理工作流的入口。这与同期 GitHub Copilot 的周期性任务、Claude Code 的跨会话消息同属一条主线：编码智能体正在工程化、长期化，开发者的角色从"写代码"转向"管流程"。

03 / 05

GitHub Copilot 推出周期性 agent 任务，企业管理权限进入 GA

AI Coding Agent 治理 自动化
事件

9 月 10 日 GitHub 发布 Copilot 周更（对应 9 月 7 日版本）：VS Code 1.137 中"周期性 agent 任务"进入公开预览，支持按小时 / 日 / 周定时或按需触发；语音模式进入实验；Copilot App 接入 Jira，可将工单带入共享画布并贯穿调研、实现与 PR 准备。

9 月 9 日，面向 Business / Enterprise 的 Copilot agent 操作企业管理权限（deny / ask / allow 覆盖 shell 命令、文件系统、网络、macOS Keychain 等）正式 GA。CLI 侧 Project HydraFusion 进入 /experimental，按任务在本地、云端、混合模型间自动路由，官方称在 TerminalBench 2.1、DeepSWE、CheckpointBench 上持平或优于 Claude Opus 5，token 成本下降 36%–67%。

关注理由

agent 从"被召唤的对话助手"变为"后台常驻、可定时、可治理"的生产组件。企业落地的最大约束不再是模型能力，而是权限边界与可审计性——谁能在什么范围执行、何时需人工确认，正成为采购前提。多模型路由把成本压到单模型方案的半数以下，则说明生产级 agent 的胜负手正在从"更强模型"转向"更聪明的编排与更严的管控"。

04 / 05

蚂蚁外滩大会发布"灵影"，面向 AI 眼镜的 Agent 原生操作系统

终端智能 Agent OS AI 眼镜 开放平台
事件

9 月 11 日，在 Inclusion·外滩大会"AI 驱动新终端新服务"论坛上，蚂蚁集团将 GPASS 智能终端可信连接框架升级为"灵影"，定位为面向 AI 眼镜、耳机、戒指等新终端的 Agent 原生操作系统及开放平台。其构建交互、编排、策略、执行、工具、记忆六层 Agent 运行框架，向下连接多类终端；把拍照、显示、传感器、镜腿交互等硬件能力统一抽象，减少跨芯片跨机型的重复适配。

安全上从设备接入即做可信身份校验、敏感数据本地隔离、工具调用全程可追溯。蚂蚁明确不自研硬件，定位为开放基础设施，向芯片伙伴、硬件厂商与开发者开放。

关注理由

AI 终端的竞争焦点正从硬件参数转向"理解意图 + 连接服务"的软件底座。支付、身份、安全与端云协同被下沉为可复用能力，意味着终端厂商与开发者无需各自重建信任与连接层，行业可能更快走向多端协同的 agent 服务入口。对可穿戴终端而言，统一的能力接入层有望把"无屏 / 小屏设备上的复杂操作"降到最低，让服务随场景自然唤起。

05 / 05

具身智能密集落地：服贸会全产业链、智博会进厂打工

具身智能 人形机器人 进厂 数据闭环
事件

9 月 13 日服贸会闭幕日，具身智能全产业链集中亮相，涵盖整机运动、底层控制与数据采集；现场展示了融合空间与视觉摄像头的可穿戴采集设备，已沉淀超 150 万小时人类行为数据库，并已向全球开源超 10 万小时数据集、覆盖 1.5 万个场景。

9 月 11–13 日第十六届智博会上，人形机器人开始"进厂"：浙江人形机器人创新中心 WA1 完成布料抓取、裤袋对齐、缝纫配合等连贯动作；均普智能 6 台 G2 在 PLC 统一调度下完成扫码、加热铆接、视觉检测等 9 大核心工序。9 月 14 日人民日报评论指出"具身智能正褪去表演属性"。据 STCN 援引 Unitree 招股书与 Smart Analytics Global 数据，2026 上半年全球人形机器人出货约 1.91 万台、同比近 3 倍，中国厂商占 97% 以上；单台成本仍超 60 万元，是规模化进厂的主要阻力之一。

关注理由

行业正从"小批量试用"转向"大规模落地"的拐点，但真实工业交互数据缺口与成本仍是硬约束。多智能体协作、PLC 统一调度与开源数据集的出现，说明落地路径正从单点炫技收敛为"数据—训练—产线验证"的闭环。短期看，重复、高强度、危险的工序会率先被替代；中长期看，谁能打通真实场景数据与规模量产的飞轮，谁就握住具身智能的产业节奏。
