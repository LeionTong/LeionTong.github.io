NO.01 · AI 编码 · 凭据治理

Claude Code 的免打扰授权把整条命令写进项目文件，1,122 份公开副本里留着真密钥

Apiiro 研究104,185 份配置文件1,379 个不同密钥涉及 63 家机构
事件简述

11 月 6 日，软件安全公司 Apiiro 公开一项研究：在 GitHub 公开仓库里检索到 104,185 份 Claude Code 的项目配置文件 .claude/settings.local.json，其中 1,122 份至少含一个符合密钥特征的凭据，合计 1,379 个不同密钥。写入路径是用户在命令确认框里选择「Yes, and don't ask again」——当授权规则保存的是整条命令而非命令模式时，命令里输入的密码与令牌会以明文留在该文件中。

按类型分，超过三分之一可直接连上数据库，包括 379 个数据库密码、43 组公网服务器 SSH 登录、42 个 GitHub / GitLab / npm 令牌与 23 个 AWS 密钥。文件所有者涵盖 63 家机构，多为不同规模的软件公司，其中一例是数据库厂商自己的云管理密钥，另一例是医疗记录库的所有者密码。研究团队用当时最新的 Opus 5.5 与 Fable 5.1 复现了该写入行为。

Claude Code 首次在仓库写入该文件时会把它加入用户级 git 全局排除列表，但不会写进项目自身的 .gitignore，这层保护不随仓库走。被追踪的 1,105 个仓库里有 539 个的改动提交把 Claude 列为共同作者，说明文件常由 agent 自己提交。删除文件也无法掩盖：旧版本另有 734 个密钥散落在 509 个仓库，74 个仓库的 211 个分支副本带着同一批密钥；截至报道当天，所有含密钥的文件仍在默认分支上，半数已存在 217 天以上。

关注理由

agent 的授权状态一旦落盘，凭据治理的重心就从代码仓库挪到 agent 配置目录，而这一层通常不在密钥扫描、安全检查与 .gitignore 模板的覆盖范围内。授权规则保存整条命令的设计，把一次性的临时输入变成了长期留存。

处置顺序上，先轮换再清理是有效路径，因为 git 历史与分支副本会把删除动作抵消掉。把编码 agent 接进持续集成或终端设备的团队，配置文件的提交权限应当和凭据扫描一起纳入流水线。

NO.02 · AI Agent · 配置分发

微软把 agent 的技能与 MCP 服务器打包成依赖，一条命令装进九个编码客户端

APMMIT 许可哈希锁定内容默认阻断传递依赖
事件简述

微软在 GitHub 的 microsoft/apm 仓库公开 APM（Agent Package Manager），定位为 agent 上下文的依赖管理器，MIT 许可，最新版本 v0.35.0 于 10 月 22 日发布。项目在 apm.yml 里集中声明 skills、prompts、instructions、plugins 与 MCP 服务器，执行 apm install 后按各客户端支持的类型分别写入，覆盖 GitHub Copilot、Claude Code、Cursor、Codex、Gemini、Windsurf、OpenCode、Kiro 与 Grok Build 九个客户端。

工程约束集中在安装期：lockfile 固定版本与内容哈希，新机器克隆后解析出逐字节一致的内容；每次安装扫描隐藏 Unicode 字符；清单里未声明或未被信任的传递 MCP 服务器默认阻断。apm-policy.yml 在安装时强制执行，策略继承按企业、组织、仓库三级只允许收紧。依赖源除 GitHub 外支持 GitLab、Azure DevOps、Bitbucket、Gitea 等任意 git 服务，可指定路径与 ref。

关注理由

编码 agent 的配置已经变成需要版本管理与供应链审查的资产：技能文件与 MCP 服务器都带执行能力，一旦从个人目录文件变成组织级依赖，锁文件、哈希固定与策略继承就是必需品。

九个客户端共用一份清单，把多客户端并存从各自的目录约定问题变成一层分发问题。对同时维护多套 agent 环境的团队，这类工具通常在标准确定之前先出现，成为收敛点。

来源

Microsoft APM 文档 https://microsoft.github.io/apm/ ；仓库 https://github.com/microsoft/apm

NO.03 · 终端智能 · 语音助手

苹果内部推动 Siri 转向能自己盯住目标的常驻助手，最快明年交出

彭博社报道跨对话延续目标iOS 28 改为六周编码接口依赖 App Intents
事件简述

11 月 8 日，彭博社 Mark Gurman 在 Power On 通讯中称，苹果内部在讨论把 Siri 从逐句响应改成能自行跟踪目标、判断下一步、不必由用户逐步发起的助手形态，最早可能明年推出。对标的形态是 ChatGPT Dots、Meta Muse 与 xAI Grok Bot 这类拥有独立虚拟机、在后台持续执行任务的 agent。

同一条消息提到开发流程的调整：iOS 28 首个里程碑由编码四周加集成四周，改为编码与探索六周、收敛集成两周，参与员工反馈更喜欢这种安排；9to5Mac 认为这与编码 agent 近两年的产能提升有关。苹果 11 月 3 日刚在 iOS 27.3 上扩展了 Siri 在自家应用内的能力，个性化版本已经交付。

关注理由

手机助手转常驻 agent 的难点在权限与调度：应用内动作可以靠 App Intents 这类既有框架声明，省掉屏幕级操作，但跨天保持目标、后台唤醒与耗电控制都要在系统层解决。

开发节奏向编码倾斜，说明 agentic 编码工具已经在改变操作系统团队的排期方式。对做终端产品的团队，值得跟踪的是系统级 agent 的权限模型何时对外开放，那决定第三方应用能把多少任务交给它。

NO.04 · 具身智能 · 家用机器人

亚马逊把 Fauna 编入新的个人机器人部门，招聘指向一台面向家庭的新机型

Personal Robotics GroupFauna Sprout 约 107 厘米原 Astro 团队并入规格未公布
事件简述

11 月 8 日，CNBC 依据招聘信息与公开资料报道，亚马逊已把今年 3 月收购的 Fauna Robotics 归入新的个人机器人部门 Personal Robotics Group，成员包括原 Astro 团队的大部分人员，并从外部引入一位麻省理工学院的机器人研究者（报道未具名）。招聘启事描述的产品是一台「new-to-world」的机器人，能在动态家庭环境中导航、与家庭成员一起自主运行；用户体验设计岗位的表述是「定义与 Fauna 机器人共同生活的感受」。形态、价格与发布时间均未公布。

Fauna 此前做的是 3.5 英尺高的人形 Sprout，主要卖给开发者、商业与学术研究者。前代 Astro 售价 1,450 美元、仅向数千名用户发货，2023 年的企业版不到一年关停；曾任亚马逊消费机器人副总裁的 Ken Washington 说，他推动过双足方案，管理层未采纳。巴克莱 1 月的报告给出的判断是：人形机器人当前规模 20 至 30 亿美元，2035 年约 400 亿美元，最乐观情形 2,000 亿美元。

关注理由

家庭场景的门槛在长时间无人看管下的安全、续航与容错，单点操作只是入场条件；Astro 停在带轮平板形态，正说明这一步跨不过去。把仿人形态交给自己收购的团队、把系统工程交给 Lab126 出身的人，是用产品定义换风险控制。

大厂重开家用机器人，信号会先体现在供应链上：轮式底盘、双目深度、语音交互与本地算力的组合比全尺寸双足更容易量产。对做终端产品的团队，这类项目的形态选择比宣传口径更值得记录。

NO.05 · 算力 · 电力供应

Anthropic 花约 34 亿美元接手 1.7 吉瓦燃气发电机组，连生产排期一起买下

英国金融时报报道1.7 吉瓦OnePWR Solutions卡特彼勒订单队列
事件简述

11 月 8 日，英国《金融时报》报道 Anthropic 在 9 月底达成一笔约 34 亿美元的交易，从圣安东尼奥的设备供应商 OnePWR Solutions 手中接手 1.7 吉瓦重型燃气发电机组的订购承诺，同时获得安装所需的工程与施工能力；交易不含 OnePWR 公司本身，也没有员工随交易转入。这批机组是 OnePWR 约两年前向卡特彼勒下的订单，接手相当于买到生产队列中的位置。Piper Sandler 称这是某前沿 AI 实验室迄今对发电设备的最大单笔采购。Anthropic 与 OnePWR 均未回应置评，路透社表示无法立即核实。

背景是容量缺口。路透社 9 月报道 Anthropic 计划未来十年投入超过 5,000 亿美元建设 AI 基础设施，同期它在加拿大新斯科舍省的配套电源项目正遭遇当地抗议。

关注理由

电力采购从租用机柜走向自备发电，模型供给的交付周期就由发电机与并网排期决定，芯片不再是唯一瓶颈。买下生产队列中位置的做法，把供应链竞争提前到设备制造环节。

单位算力的电费与并网时间，会同时反映到推理单价与可用容量上；对终端与具身产品，这部分成本落在每一次调用里，与模型权重无关。

来源

CNBC 转述英国《金融时报》 https://www.cnbc.com/2026/11/08/anthropic-generator-deal-ai-data-centers.html

待跟踪

  1. Apiiro 统计中的密钥是否仍然有效，Anthropic 是否会把授权文件改为只保存命令模式。
  2. APM 在九个客户端上的实际兼容程度，策略继承在大型组织里的推行阻力。
  3. 苹果系统级 agent 的权限模型与第三方应用接入方式，明年是否进入开发者预览。
  4. 亚马逊新家用机器人的形态与定价，Fauna 现有开发者生态是否延续。
  5. Anthropic 这批机组的并网时间与总容量，是否反映到 Claude 的调用配额上。
