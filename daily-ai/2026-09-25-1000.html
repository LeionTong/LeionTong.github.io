NO.01 · 终端智能 / AI Agent

Meta Connect 发布首款纯音频 AI 眼镜，Muse 落地眼镜与随身硬件

终端智能 AI Agent 智能眼镜 随身硬件
事件简述

9 月 23-24 日的 Meta Connect 上，Zuckerberg 以「个人超级智能」Muse 为中心发布新款 AI 硬件：首款纯音频眼镜 Ray-Ban Meta Audio（Clubmaster、Burbank 两款，约 43 克、12 小时续航，起价 349 美元，10 月 13 日发货）；带摄像头的 Ray-Ban Meta Gen 3（起价 449 美元，六麦克风阵列、自定义动作键、9 小时续航）；Meta VR Glasses（1,299 美元，2027 年春，约 100 克分体设计、5K 微 OLED，可连 Mac/Windows 作虚拟外接屏）；钥匙扣形态的 Muse Charm；以及起价 249 美元的 Meta Adventurer 低价款。

软件侧，Muse 未来数月上线 AI 眼镜：喊名字即可免提唤醒，并可对眼前事物即问即答、直接采取行动；Mac 端开放 computer use，获授权后可代操作任意应用；Muse 获得专属邮箱地址，并新增 Walmart、Best Buy、Sephora、GitHub、Box 等连接器。官方称到年底全系 AI 眼镜将超过 100 款，并面向新加坡、韩国、墨西哥等新市场铺开。Meta 还推出 FDA 获批的听力增强软件功能（149.99 美元或 Meta One 订阅）。

关注理由

这把 Agent 从手机与桌面扩展到随身硬件：眼镜的免提唤醒与「对眼前事物采取行动」让 Agent 第一次能直接感知用户视野并据此执行，是比语音助手更贴近终端智能的交互形态。纯音频眼镜去掉了摄像头，既是对隐私质疑的回应，也把语音 Agent 的价格与门槛同时拉低，更像规模铺量而非旗舰演示。对做 Agent 应用与终端的团队，带屏、纯音频眼镜与 VR 眼镜构成了一条新的硬件分流，交互与权限模型也随之分化。

NO.02 · AI coding / AI Agent

JetBrains 发布 agentic 开发开放系统 Air，覆盖 IDE、团队与组织治理

AI coding AI Agent 开发者工具
事件简述

9 月 22 日，JetBrains 发布 JetBrains Air，一个横跨 IDE、团队交付与组织治理的开放系统，其 Junie 编码 agent 覆盖所有 Air 表面。系统含三件产品：Air（IDE 内编排与核验 agent 的开发体验，可同时开多个项目会话、直接对 diff 行内留言）；Air Teams（协调开发者与自主 agent 的软件交付工作流，共享云端环境、把代码审查等重复任务委托给 agent，MCP 连接一次全员共享）；Air Governance（原 JetBrains Central，负责企业策略、可见性、审计、成本管理与问责），另有 Air Context 语义索引与 Air Gateway 终端接入。

Air 可与 Claude Agent、Codex、Copilot、OpenCode 及任何走 Agent Client Protocol 的 agent 配合，横跨 IDE、Web、CLI 与移动端；模型可用自带订阅/密钥，也可走 JetBrains AI 按公开 API 价计费。

关注理由

老牌 IDE 厂商把 agent 化开发从「个人 IDE 助手」升级为「团队与组织级治理」三件套，说明 coding agent 正进入企业工程流程的制度化阶段——当生成不再是瓶颈，核验、归属、审计与成本分层就成为新的产品卖点。这也是 JetBrains 对 Cursor/Codex 一类挑战的回应：不拼单一端点，而是把整条 agent 交付链路做成可治理的平台。

NO.03 · 具身智能 / 产业数据

国际机器人联合会发布《2026 世界机器人报告》，物理 AI 被列为产业新方向

具身智能 物理 AI 产业数据
事件简述

9 月 24 日，位于法兰克福的国际机器人联合会发布《2026 世界机器人报告》：2025 年中国保持全球最大工业机器人市场，工业机器人安装量达 35.4 万台，约占全球总安装量的 59%，创历史新高。IFR 秘书长在专访中称，机器人正成为人工智能进入真实生产环境的重要载体，「物理人工智能」有望成为推动机器人产业下一步发展的重要方向；中国产业正从规模扩张转向技术创新、场景拓展与解决方案提升。

关注理由

工业机器人作为 AI 承载体的安装量与行业扩散度，是判断「物理 AI / 具身智能能否规模化落地」的先行指标——真实生产环境决定数据闭环与场景从哪来。IFR 把「物理 AI」点名为产业方向，与具身、终端智能当前的技术竞争点一致：谁能先在真实环境里持续运转并拿到数据，谁才谈得上从演示走向量产。

NO.04 · 具身智能 / 多机协同

世界技能大赛上海开幕，近 20 台人形机器人与舞者实时同台

具身智能 多机协同 实时演出
事件简述

9 月 22 日，第 48 届世界技能大赛在上海开幕。据宇树与多家媒体报道，19 台宇树人形机器人与 120 名舞者同台实时演出，另有宇树 H2、智元 A3 等机型参与，现场全程直播；机器人身着发光服装与面具，动作编排与人类舞者无缝衔接。

关注理由

20 台量级的人形机器人在直播场景下实时群舞，考验的是多机协同与外部干扰下的稳定调度，而非单机动作演示——这与此前世界人形机器人运动会上多机参赛暴露出的协调问题形成对照，规模化群体协调是人形机器人从「单台可用」走向「成建制定点」的工程分水岭。需要留意的是，这类表演主要证明编排与稳定性，与开放环境真实任务的泛化能力是两个不同量级的问题。
