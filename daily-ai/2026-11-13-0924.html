NO.01 · 公司治理 · 具身算力

黄仁勋辞去英伟达总裁与 CEO，财务长克雷斯临时接任

8-K 载明 11 月 11 日生效董事会启动遴选市值今年峰值超 5.5 万亿美元
事件简述

11 月 12 日，英伟达董事会宣布黄仁勋辞去总裁、首席执行官与董事职务，公司提交给美国证券交易委员会的 8-K 写明辞呈于 11 月 11 日生效。首席财务官 Colette Kress 出任临时首席执行官，董事会同时开始寻找下一任掌门人。

黄仁勋 1993 年创办英伟达，此后一直兼任总裁、首席执行官与董事，公司市值今年一度超过 5.5 万亿美元。辞职发生在董事会就其个人关系展开调查之后；美国官员怀疑与其有往来的人士所任职的公司曾协助向中国转运受管制芯片，中方否认相关指控。

关注理由

机器人方向的平台进度由 Isaac、GR00T 与 Jetson Thor 三条线共同决定，这些项目的预算与排期此刻在临时管理层手上，外部团队的排产与选型要按方向延续、节奏可能变化来准备。

董事会在遴选期内通常收紧大额资本承诺，对机器人生态的投资节奏、供货优先级与合作条款都可能后移，正在谈的平台授权需要留出重新确认的时间。

客户与合作伙伴的公开表态会集中在平台延续性上，接口与许可条款在过渡期内的变动值得逐条核对，尤其涉及长期供货与共同开发的约定。

NO.02 · AI 编码 · 模型供应

OpenAI 与 Cursor 的直连合同到期，Astra 始终没有进入 Cursor

11 月 12 日终止直供OpenAI 模型约占 Cursor 流量 5%自带 API Key 仍可用
事件简述

OpenAI 于 8 月 28 日公告的合同终止在 11 月 12 日生效，Cursor 不再获得 OpenAI 模型的官方直连；下一代模型 Astra 从一开始就不在供应范围内。触发点是 SpaceX 完成对 Cursor 的收购，OpenAI 援引合同中的控制权变更条款，并表示无法确认对方会按服务条款使用其技术。

Cursor 联合创始人 Michael Truell 回应称 OpenAI 模型约占其用户流量的 5%，双方仍在沟通解决方案。OpenAI 产品负责人 Tibo Sottiaux 补充，开发者自带 OpenAI API Key 继续可用，OpenAI 自家的 Cursor IDE 扩展也继续提供访问。Anthropic 联合创始人 Tom Brown 表示将增加算力，支撑 Claude 在 Cursor 上的部署。

关注理由

编码工具的模型来源从打包进订阅变成按 token 自行付费，成本结构、限流与稳定性责任一并转到使用方，预算与采购流程需要提前改。

模型供应商开始按控制权归属与合规判断挑选分发渠道，把编码 agent 绑在单一厂商上的团队在这一轮里承担了全部迁移成本。

多模型路由与可替换的接入层从效率优化项变成基础设施要求，团队需要能记录每个任务实际使用的模型与版本，避免自动路由带来的结果漂移。

NO.03 · 具身智能 · 量产交付

优必选 Walker S2 首批数百台开启量产交付

1.76 米 / 52 自由度15 公斤负载自主换电支持 7×24 作业
事件简述

11 月 12 日，优必选首批数百台全尺寸工业人形机器人 Walker S2 正式开启量产交付，将分批投入产业一线。整机身高 1.76 米、52 自由度，可在 0 至 1.8 米空间内搬运 15 公斤负载，腰部转动 ±162°；第四代工业级灵巧手采用类人尺寸设计，宣称亚毫米级精细操作、耐久测试超过 8 万次。

头部采用纯 RGB 双目视觉方案，配合双电池同充同放与标准化电池仓，实现自主换电与 7×24 小时连续作业。软件侧为群脑网络 2.0 与工业协作智能体 Co-Agent，承担意图理解、任务规划、工具调用与异常处理，依赖工业实训积累的数据持续迭代。Walker 系列人形机器人累计订单金额已超过 8 亿元。

关注理由

数百台级别的交付把验证重点从单机演示移到批量一致性，灵巧手耐久、换电机构与双目视觉在长班次下的故障率，会成为下一轮采购的硬指标。

自主换电把连续作业时长从电池容量问题转成换电节拍与电池周转问题，产线排产、人员配置与场地动线都要按这个节拍重算。

Co-Agent 这类把多模态推理模型、交互模型与技能小模型混编的架构，决定了本体厂商对外部模型供应的依赖程度，也决定了算法迭代的自主空间。

NO.04 · Agent · 企业运行环境

Databricks 把 Genie 改成常驻的自主 AI 同事

Genie Ontology 业务语义层Unity Gateway 管工具与花费邮件 / Slack / Teams 入口
事件简述

11 月 12 日 Databricks 发布新版 Genie，定位为常驻的自主 AI 同事，承接长时间运行的企业任务：跟踪进度、追问缺失的输入、在新信息到达时继续动作，遇到需要决策的节点向人请示。业务上下文来自 Genie Ontology，这层语义地图由 agent 构建、由人治理，覆盖指标定义、实体关系与组织知识；Genie Search 在湖仓与已连接的业务系统里检索。

Unity Gateway 与 Unity Catalog 负责权限、动作追踪与花费上限，管理员可以看到 agent 的动作、用量与成本。入口覆盖邮件、Slack 与 Microsoft Teams，可同时运行多个任务，在同一处监督、干预与停止，并按时间表或指标触发起跑。

关注理由

常驻 agent 的可用性取决于语义层质量，谁维护指标定义与组织知识，谁就掌握 agent 的行为边界，这项工作正在从数据团队的兼职变成独立职能。

动作追踪与花费上限写进管理面，企业才愿意把持续运行的任务交出去，审计口径会先于模型能力成为采购门槛。

多任务并行加上人工审批点的组合，把 agent 的作业范围推到流程责任层面，配套的岗位设置与考核方式需要同步调整。

NO.05 · AI 编码 · 验证环节

Expo 把 iOS 模拟器搬上云端，交给编码 agent 自己跑

每分钟 0.10 美元不需要 Mac适配 Cursor / Claude Code / Codex
事件简述

11 月 12 日 Expo 发布 Expo Simulators，提供面向编码 agent 的云端 iOS 模拟器与安卓模拟器。agent 可以复现上报的缺陷、改写代码、在模拟器上验证，并把屏幕录制、截图与日志挂到 pull request 上，团队成员通过链接直接打开运行中的构建，不必走 TestFlight。

iOS 模拟器可以跑在 Linux、Windows 的 WSL 或云沙箱里，多个 agent 并行不再受开发机内存限制。该服务已适配 Cursor、Claude Code 与 Codex，按模拟器分钟计费，每分钟 0.10 美元，Starter、Production、Enterprise 套餐每月含 60 分钟。Expo 计划在月底前公布 Agent Sessions，为从客户反馈等外部来源触发 agent 的流程加一层防提示注入的隔离。

关注理由

编码 agent 的瓶颈从写代码转到验证，能把跑起来看过这一步自动化的一方，直接决定 agent 交付的返工率与人工评审负担。

移动端验证长期依赖苹果硬件与本机资源，云端模拟器把它变成按分钟购买的服务，并行 agent 的数量不再由开发机配置决定。

后续的 Agent Sessions 指向输入来源的可信度，企业接入 agent 的下一道关口在触发入口的隔离与准入。
