NO.01 · 模型 · AI coding · Agent

MiniMax 发布 M3.1 Flash，agent 任务成本再降七成，但答错时几乎不认输

AI coding 模型定价 Flash
事件简述

10 月 19 日，MiniMax 上线新一代 Flash 模型 M3.1 Flash，官方称在复杂 agent 任务、编程、电脑操作与网络安全上全面提升，线上推理速度约为上一代三倍，agent 类任务整体使用成本降低 70%。定价为每百万 token 输入 0.15 美元、输出 0.60 美元、命中缓存的输入 0.015 美元，可通过自有 API、M Plan 订阅与桌面端 MiniMax Code 调用；模型权重称 10 月 23 日放出，许可证未公布。

官方自报成绩：DeepSWE v1.1 得 73.7%，OSWorld V2 得 61.7 分，Agents’ Last Exam 得 29.6 分，CyberGym 得 82%。第三方 Artificial Analysis 给它的智能指数为 42，比上一版 M3 高 13 分，单任务评测成本不到前代一半；但同一家的 AA-Omniscience 测试里它在答错时几乎不承认不知道（“不知道却硬答”比例 93%），综合分只有 16。官方还确认，此前在 OpenRouter 上匿名放量、9 月曾在 OpenCode 日用量榜登顶的 Space Bunny 就是它的早期版本。

关注理由

Flash 级模型把 agent 的单步成本压到旗舰的零头，把复杂流程交给便宜模型从“预算妥协”变成可选项，多轮工具调用的预算测算也随之宽松。真正要防的是自我校准：失败时它倾向于给一个错答案而不是承认不确定，接进会自动改记录、读写文档的 agent 前，最好外挂校验或人工复核。

NO.02 · AI Agent · 长程任务

四个 Gemini 4 Argon agent 自己写了 2783 个程序，27 小时通关 Minecraft

AI Agent 多智能体 论文
事件简述

Google DeepMind 的三名作者把四个 Gemini 4 Argon agent 放进随机生成的 Minecraft 生存世界，只给一个目标：打败末影龙。每个 agent 通过开源库 Mineflayer 写 JavaScript 程序控制自己的角色，用游戏内聊天和共享记忆协调，没有人分配角色或写游戏逻辑。27 小时 14 分后末影龙被击杀，期间写了 2,783 个程序、交换 229 条消息、死亡 605 次，消耗约 13.5 亿输入 token；含一个只负责旁观校验的第五个 agent，整场账单约 810 美元。论文 10 月 15 日上传 arXiv，Engadget 等媒体 10 月 19 至 20 日跟进报道。

关注理由

值得看的不是游戏，是上千步依赖链条里能维持一份连贯计划：分工、互报坐标与危险、捡回队友掉落的装备，都是 agent 自己谈出来的；对真实软件工程里的多 agent 长程协作，这是一次成本可承受的完整跑通。但只有一次运行、Easy 难度，而且吃的是 Mineflayer 给的结构化状态而非类人视觉，可靠性与迁移性都还没证明。

NO.03 · AI coding · 安全

GitHub 把代码扫描告警的修复交给 Copilot，同时给 AI 写码补上安全读数

AI coding 安全 平台
事件简述

10 月 15 日，GitHub 将 code scanning 告警的 agentic autofix 与 PR 上的 AI Scan 同时转为正式可用。前者把一条告警指派给 Copilot 后，它会跨仓库检索相关文件、生成补丁、重跑 CodeQL 确认告警关闭，再开一个草稿 PR 并附上验证步骤，一次最多可批处理 25 条告警；它消耗 Code Security 的 AI Credits 与 Actions 分钟数，仅限 GitHub Enterprise Cloud，且需企业管理员先开策略。AI Scan 补的是 CodeQL 覆盖不到的 PHP、Shell、Terraform、Dockerfile 等，但结论只是建议，不能阻断合并。

同期挂在 arXiv 上的 LSCBench 给了这个方向一个数字：六个前沿编码 agent 的功能通过率在 73.6% 至 91.3% 之间，而同时满足“能跑且安全”的最高只有 25.1%。

关注理由

在“AI 写的码快过人审”之后，平台开始让 agent 反过来承担修复，等于是把安全债在同一处 PR 里赔付，链条更短也更可追。边界同样清楚：autofix 的能力被 CodeQL 的规则覆盖度锁住，只跑默认查询套件，自定义查询与第三方告警的修复无法自证；advisory 的 AI Scan 挡不住合并，拿它当门槛会漏。

NO.04 · 具身智能 · 公司

Altman 确认 OpenAI 要做人形机器人，称 2027 年先给一个 demo

具身智能 人形机器人 OpenAI
事件简述

Sam Altman 在播客 Sources 上确认 OpenAI 会做人形机器人，理由是“这个世界是为人设计的”、匹配人的形态更省事，并说会同时做其他形态。他在接受《财富》采访时给出唯一时间点：2027 年会有一个“很酷的 demo”，但机器人上街还要再等几年。他反复强调难的不是身体而是“让机器人动起来的那颗大脑”。OpenAI 目前在招 27 个机器人相关岗位，覆盖运动控制、整机行为、执行器以及制造与供应链。10 月 17 至 19 日，Engadget 等媒体集中报道。

关注理由

路线与它一贯的模型优先一致：先解决从感知到动作的“大脑”，本体可以后置甚至外购。对人形赛道的含义是又一个前沿模型玩家从软件侧切进硬件，会把 VLA 与世界模型的竞争和人才战再抬一档；但形态、价格、量产均未定，2027 的 demo 是唯一锚点。

NO.05 · 终端智能 · 具身智能

UCLA 开源 400 美元手机人形：拿旧安卓机当相机、IMU 与算力

终端智能 开源硬件 低成本
事件简述

UCLA 的 RoMeLa 实验室开源了 PhoneBot：一台 48.3 厘米高、1.8 公斤、13 个自由度的双足平台，用一部普通安卓手机充当相机、惯性测量单元与主要算力，手机通过 Wi-Fi 把指令发给板载小电脑再驱动 13 个舵机，机身与手机之间没有电气连接。硬件成本约 400 美元（不含手机），论文里列出的同类小型研究平台报价在 3,500 至 13,800 美元之间。

实测它能走动、用摄像头跟人、面朝下摔倒后自己爬起来，测试覆盖包括 2017 年 Honor 9 在内的四款机型；目前没有手臂、只在平地验证，语音问答仍需外接笔记本处理。论文 10 月 6 日提交 arXiv，10 月中下旬经媒体扩散。

关注理由

把终端智能落到了实处：机器人的感知与推理单元直接用消费级手机，省掉专用视觉计算和传感器模块，成本降到教学与科研可负担的量级，也说明手机目前的算力只能扛运动控制与轻量感知。真正决定它能否从教学平台走向实用的，是把语言模型搬进手机、以及补上手臂与非结构化地形。
