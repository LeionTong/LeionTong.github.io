OpenAI 与阿里降低单位任务成本，微软把智能体管控放进 Windows

本期收录 OpenAI GPT-6.2 Astra 与 Sol 的降价发布、阿里 Qwen4-Max 的百万上下文与 token 效率数据、Cognition 的常驻编排智能体、微软 Ignite 公布的智能体治理与端侧混合推理，以及华为麒麟 9050 的显示处理单元。

NO.01 · 模型 · 编码

OpenAI 发布 GPT-6.2 Astra 与 Sol，输入输出价格比上代低两成

Agents' Last Exam 比上代高 5.2 分，成本不到三分之一FrontierCode 2.0 上两档相差 0.5 分，成本约五分之一缓存输入每百万 token 0.40 美元
事件简述

11 月 17 日，OpenAI 发布前沿模型 GPT-6.2 Astra 与日常档 GPT-6.2 Sol，同日进入 ChatGPT Work、Codex 与 API。Astra 在 Agents' Last Exam 上比 GPT-6 Astra 高 5.2 分、成本不到三分之一，比 Claude Fable 5.2 高 5.5 分、成本约 5%；在测试终端内科研流程的 Terminal-Bench-Science 0.1 上高出 9 个百分点；Harvey LAB-AA 的通过率超过 Fable 5.2 两倍；内部 GDPval v2 高出 6.2 个百分点，同时输出 token 少 22%。API 价格为每百万 token 输入 8 美元、缓存输入 0.40 美元、输出 40 美元，输入输出比上代低 20%，缓存折扣 60%；Sol 维持每百万 token 2 美元与 10 美元。Cognition 的 FrontierCode 2.0 上，Sol 与 Astra 相差 0.5 分，成本约为后者五分之一，发布当天即接入 Devin。

关注理由

编码与终端类任务开始按单位任务成本比较，同样预算能跑更多轮智能体循环；缓存输入降到 0.40 美元，反复读取同一代码库的长上下文成本结构随之改变。

两个档位的分差缩到 0.5 分，选型从只挑最强模型转到按任务分档，日常改动交给便宜档、复杂重构留给前沿档，是更省钱的组合方式。

NO.02 · 模型 · 长程任务

阿里 Qwen4-Max 正式上线，2.4 万亿参数配百万 token 上下文

Work360 得 52.69 分，上代为 47.74 分Terminal-Bench 4.0 的 token 消耗降约 48%单任务平均费用从 26.58 元降至 11.16 元
事件简述

11 月 16 日，阿里通义千问把 Qwen4-Max 从限时预览转为正式版，开放 API 与 Token Plan 调用。模型主干 2.4 万亿参数，采用稀疏 MoE，原生支持视觉输入与 100 万 token 上下文。架构上每四层中三层用 Gated DeltaNet 把历史信息压缩成固定状态，剩余一层用 Qwen Sparse Attention 按块选择上下文；Gated Residual 把残差流扩成四条并行分支；第二层用 N-gram Embedding 以查表方式补充局部模式。评测方面 Work360 得 52.69 分，前代 Qwen3.8-Max 为 47.74 分；同等性能下 Work360 的 token 消耗在 Xhigh 与 High 两档分别减少约 24% 与 35%，Terminal-Bench 4.0 上减少约 48% 与 49%；Work360 单个任务平均费用从 26.58 元降到 11.16 元。API 每百万 token 输入 1.5 美元、输出 4.5 美元，缓存命中 0.075 美元。智能体场景引入 Live Delivery，先交可用首版再按反馈逐版扩写，同步开源 Qwen-Live-Delivery-Plugin 插件。官方展示的汽车零件加工案例里，单个工件的编程人工投入从约 475 分钟降到 24 分钟。公司称 Qwen4 系列的小尺寸模型后续开源。

关注理由

编码与多步任务上的 token 消耗下降接近一半，直接决定智能体循环能跑多久、单次交付摊到多少成本。

Live Delivery 把交付节奏前移，接口形状开始围绕长周期任务设计，评审者在中途就能改方向，重做的代价比等最终结果小。

NO.03 · Agent · 编码

Cognition 推出 Devin Bots，一个智能体带一批 Devin 跑数周项目

以 Slack 成员身份驻留，跨周保留上下文模板含 QA、Android、延迟优化与幕僚长内测用户每条消息的合并 PR 数平均 4.5 倍
事件简述

11 月 17 日，Cognition 发布 Devin Bots：用户给一个目标，Bot 拆成任务并在各自云电脑上并行启动 Devin 会话，一路推进到产出可合并的 PR。Bot 以成员身份加入团队 Slack，可短信或电话联系，按计划巡查 Slack 与 Linear 等工具，遇到阻塞或需要决策时找人；每个 Bot 有独立预算并按交付结果核算。模板包括 QA 工程师、Android 工程师、延迟优化器，以及把任务派给其他 Bot 的幕僚长。安全上 Bot 运行在独立云机器、远离工程师本机的密钥，管理员限定每个 Bot 可访问的仓库与工具，网络策略拦截越权数据外传，团队自行规定哪些改动必须人工复核、低风险改动可自动合并。产品用到 7 月收购的 The Interaction Company（Poke 助手）的技术。Cognition 估值 480 亿美元，9 月年化收入超过 10 亿美元，花旗称有 1.4 万名工程师在用 Devin。

关注理由

智能体从接单个任务转到带一条项目线，管理界面变成群聊与预算表，人的角色收缩到决策点，评审与合并成为主要接口。

按仓库范围与预算切权限，是把多智能体放进企业环境的必要结构；这套边界能否通过安全评审，决定了自动合并能不能开到生产仓库。

NO.04 · Agent · 企业治理

微软 Ignite 把智能体治理下沉到 Windows，并给出端侧混合推理路径

Agent 365 策略在每台设备生效Execution Containers 提供更细的执行隔离Cobalt 200 虚拟机正式可用，性能最高提升 50%
事件简述

11 月 17 日，微软 Ignite 2026 在旧金山开幕。Copilot 侧新增 Copilot Workspaces（人与智能体共用工作区）、Autopilot（长期运行、无需逐步提示的智能体）与 Copilot Code（用自然语言建看板与应用）；Microsoft IQ 作为企业上下文管理平台，新增业务插件，把知识打包成可复用的上下文、技能与工具。治理侧 Agent 365 Business Analytics 给出成本与产出的统一视图，从任务成功率到累计节省工时；Windows 增加操作系统级的智能体保护，用 Microsoft Execution Containers 做更细的执行隔离，内置 Entra 智能体身份，Agent 365 策略在每台设备生效；Microsoft Perception 正式可用，以 MAI-Cyber 系列模型驱动漏洞发现、防御与修复。基础设施侧 Cobalt 200 虚拟机正式可用，性能比上代最高提升 50%，年底覆盖 23 个区域；Azure Catalyst 把 Azure 与 GitHub 的智能体工具并到一个入口；Windows 上的混合推理让模型在设备或云端运行，先在 GitHub Copilot 与 Copilot 上提供。大众集团为超过 33 万名员工部署 Copilot，雅诗兰黛扩展到 1.4 万人。

关注理由

智能体身份的签发、策略下发与执行隔离被做进操作系统与目录服务，企业不必自己拼一套管控；这让自建个人智能体与统一治理可以并存。

端侧混合推理给出一条明确分工：涉及隐私与低延迟的活留在设备，重任务回云端，终端产品的模型边界与功耗预算据此划分。

NO.05 · 终端智能 · 显示

华为公布麒麟 9050 显示处理单元，把普通片源做 HDR 化并支持像素级防窥

AI-HDR 2020 已适配 364 款视频应用SoC 的 DPU 与朱雀 DDIC 协同做像素级控制防窥按屏幕区域切换
事件简述

11 月 17 日，华为公布麒麟 9050 系列新一代显示处理单元的两项能力。AI-HDR 2020 对普通 SDR 内容做处理，扩展明暗层次与色彩表现，官方对比中用同一段篝火视频展示火焰亮度层次与暗部细节的改善，并称该能力已适配 364 款主流视频应用、后续继续扩展。显示像素级精准控制由 SoC 的 DPU 与朱雀 DDIC 协同驱动，可对屏幕不同区域分别调节，用于防窥模式快速切换、画质一致性优化与像素补偿，不再只调整整块屏幕亮度。

关注理由

画质增强从面板参数转到芯片侧算法，片源本身不是 HDR 也能得到更好的观感，同价位终端因此在观影一项上拉开差距。

分区控制与防窥结合，说明显示链路开始承担隐私交互，公共场合使用的默认设置有了由硬件实现的做法，而不依赖应用逐个适配。
