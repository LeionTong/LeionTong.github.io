NO.01 · AI 编程 / AI Agent

VS Code 1.136 让 Copilot 与 Claude Agent 跨多根工作区协同

AI coding AI Agent 开发工具
事件简述

VS Code 1.136（2026 年 9 月发布）引入多根工作区 Agent 会话：编辑器 Chat 视图中的 Copilot 与 Claude Agent 不再局限单一根目录，可按项目名称解析文件夹、跨多个服务仓库推理与执行；同步推出 Agent Merge（自动化 PR 清理）与 Agent Host（Open AHP 协议）。该能力目前标注为实验性，Agent hooks 仍按单文件夹作用域生效。

关注理由

单体 Agent 长期被单仓库边界束缚，多根工作区支持直接回应了 monorepo 与多服务项目团队的真实诉求，意味着 IDE 内的 Agent 正从「单目录助手」转向「跨代码库协调者」，是企业级变更管理的入口能力。

NO.02 · AI 编程 / 开源

OpenSpec 规范框架登 HN，68k stars 成 AI 编程事实标准候选

AI coding spec-driven 开源 MIT
事件简述

OpenSpec（Fission-AI，MIT 许可）于 9 月 16 日登上 Hacker News 首页（154 分），官方页面显示其 GitHub stars 约 68k、月活开发者超 26.5 万；提供 /opsx 工作流（explore → propose → apply → verify → archive），以规范文件约束 AI 编程 Agent「先理解再动手」，已兼容 Claude Code、Cursor、Codex、Copilot 等 50+ Agent。

关注理由

当 Agent 能「自信地写错东西」，结构化规范层成为降低返工的关键基础设施。OpenSpec 的走红说明 AI 编程的竞争焦点正从模型能力转向「如何让 Agent 做对的事」，规范驱动开发（spec-driven）正在沉淀为行业共识。

NO.03 · 具身智能 / 量产

智身科技（GENISOM AI）完成数亿元 B 轮融资，量产破 1.5 万台

具身智能 融资 规模量产
事件简述

9 月 20 日，具身智能机器人企业智身科技宣布完成数亿元 B 轮融资，由阿联酋 Stone Venture（磊石资本）领投，洪山资本、粤科金融、吴中金控等机构及东软集团、豪鹏科技等产业方参投。公司披露截至 2026 年 6 月累计量产突破 15000 台，单月产能较去年月均提升超 10 倍，产品进入电力、石化、消防、安防、应急、教育等行业，与 500 余家生态伙伴合作。

关注理由

融资与量产数据同步走高，说明具身智能的竞争维度已从「技术 demo」转向「规模量产 + 稳定交付 + 真实场景」。智身科技「一体双脑」架构（大脑决策、小脑运动控制）指向机器人从「进现场」到「完成任务」的产业落地路径。

NO.04 · 具身智能 / 资本趋势

资本涌向具身智能感知层，融资向中后期与产业化集中

具身智能 融资趋势 感知层
事件简述

据《证券日报》9 月 19 日报道，机器人赛道融资密集落地：触觉技术企业枢途科技完成近亿元 Pre-A 轮（鼎晖百孚、鲲鹏基金领投），具身感知龙头帕西尼完成 B++ 轮、累计融资超 40 亿元。IT 桔子数据显示，2026 年上半年国内具身智能融资总额约 935 亿元，同比增 5 倍，融资事件 322 笔、同比增 137%；中银证券指出资金正从中早期广撒网转向具备量产潜力的中后期项目，上游核心零部件（触觉传感器、灵巧手、关节模组）受捧。

关注理由

资金结构变化是产业化临近的先行信号：当资本从「赌路线」转向「押量产与核心零部件」，意味着行业共识正在对硬件栈与数据飞轮收敛，触觉与感知层有望成为继本体之后的下一个价值高地。

NO.05 · 终端智能 / 边缘 AI

智能体走向硬件：Violoop 与绿联 MasterAgent 把 Agent 带出屏幕

终端智能 边缘 AI 智能体硬件
事件简述

两款面向「Agent 上硬件」的产品近期亮相：BVIO 的 Violoop 在 IFA 2026 发布、9 月 15 日登陆 Kickstarter（起价 399 美元），巴掌大设备通过 HDMI/USB-C 接入任意电脑，读取屏幕、调用 ChatGPT/Claude/Gemini/Codex 执行多步任务，数据本地留存；绿联 9 月 12 日在厦门发布本地 AI 智能体中枢 MasterAgent，搭载 NVIDIA Jetson Thor T500（2070 TFLOPS），可在本地运行 122B 参数模型，主打家庭场景的低延迟与隐私。

关注理由

智能体不再只活在 App 与对话框里，硬件化（PC 外设、家庭算力中枢）正在把「主动办事」从手机延伸到桌面与家庭。本地算力 + 持久记忆 + 用户授权边界，是端侧 Agent 能否真正落地的前提，也重新定义了终端设备的价值。
