§ TERM-01 终端 · CLI 可信度：一级规范信源

MCP 2026-07-28 最终规范今日发布Final

Model Context Protocol 今日作为最终规范发布，自上线以来最大修订：①无状态核心——移除握手与 `Mcp-Session-Id`，任意请求可落任意实例；②新增 MCP Apps（沙箱 iframe 渲染交互 HTML）与 Tasks（有状态任务句柄转正）；③授权对齐 OAuth 2.1 / OIDC（含 RFC 9207 `iss` 校验）；④生态已超 10,000 个服务器。

值得关注这是所有建在 MCP 上的 CLI / 编码 Agent / 工具「接线标准」重写的迁移事件。无状态核心让服务器能直接跑在普通负载均衡后（最便宜的基建），对端侧 / 边缘 / 企业网关意义重大；MCP Apps 模糊了「工具调用」与「应用」边界。今日之后，依赖 MCP 的终端工具都要面对 12 个月弃用窗口。
§ AGENT-02 AI Agent 安全 可信度：一级厂商（微软）

微软 MAI-Cyber-1-Flash + MDASH：专用安全大模型上岗

微软发布 MAI-Cyber-1-Flash——专为网络安全训练的专用模型，号称 5 分钟完成中型企业完整安全评估、自动识别并验证漏洞；配套 MDASH 模拟真实攻击者手法验证可利用性、降误报；整合 Perception 统一编排。微软称 CVE 识别准确率 98.7%、比人工快约 100 倍。

值得关注当 Agent 开始自主调工具、执行命令、操作文件，「谁来审计 Agent 本身」从边缘变基础设施问题。微软把它做成专用模型 + 自动验证框架，标志 AI 安全审计从「人做」转向「AI 做」。诚实标注：98.7% 等为厂商自报，独立基准待测。
§ BODY-03 具身智能 可信度：一级厂商 + 媒体

智在无界发布 Being-H0.8：全球首个隐式触觉世界动作模型

智在无界 7/28 发布 Being-H0.8——全球「首个隐式触觉世界动作模型」。相较 H0.7，首次将触觉模态系统引入隐式世界模型，用大规模人类视频 + 触觉数据共同预训练，目标是让模型从视频学动作、在隐空间预测动作后果。同日卢宗青直言行业「大脑还在 0.x 阶段」、泛化是最大瓶颈。

值得关注直击具身最核心卡点——泛化。工业级靠任务确定能稳定干活，家庭 / 柔性任务就露怯，根因是缺「物理直觉」。触觉是机器人从「看视频学动作」到「真干细活」的关键模态缺口，H0.8 把它塞进世界模型，是「世界模型 = 物理直觉破局」共识的一次具体落子。诚实标注：厂商自评，泛化上限待第三方评测。
§ TERM-04 终端 · 推理经济性 可信度：学术预印本（arXiv）

Corbenic KV-State Grafting：12B 干翻 31B，成本 1/6500

Corbenic AI 预印本提出 byte-exact KV-state grafting：不改参数、不换硬件，把推理 KV 缓存按比特级精确保存 / 重载。AIME 2025 上冻结 12B 从 80% 跳到 93.3%；8 道最难题仅 61 输出 token vs 暴力采样 401,026——降 6,574 倍。Gemma-4-31B 上同样有效，SHA-256 校验 byte-exact。

值得关注对端侧 / 边缘 / CLI Agent 是底层经济性突破——推理成本与延迟是端侧长任务第一约束。与其堆参数，不如「把已算过的推理路径存下来复用」，对长上下文、长程 Agent 任务尤为关键。诚实标注：预印本未同行评审，benchmark 为数学竞赛，泛化待验证。
