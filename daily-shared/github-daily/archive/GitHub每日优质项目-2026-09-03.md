## 一、今日首选

**cactus-compute/needle**。它是今天唯一同时满足「边际成本趋零 + 30 分钟可验证 + 客户自带硬件」的标的，且正对端侧与机器人方向；14MB 的体量意味着验证失败的成本也几乎为零。

## 二、组合观察

五条里有四条在做同一件事——把原本按月付费的能力搬回自己可控的基础设施：语音（VoiceStudio）、可观测（Laminar）、安全自动化（Tracecat）、知识底座（Utopia）；Needle 则把这条逻辑推到了设备端。今日信号很清楚：**AI 采购的第一理由正在从「模型能力」转向「成本与数据主权」**，谁能给出可量化的替代账，谁就容易成交。
