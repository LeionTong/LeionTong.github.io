这一批都在处理同一件事：设备的实际控制权锁在厂商的应用界面里，用户只能点，不能调。电视的桌面、没有 API 的网站、电话线路、墨水屏面板、仿真模型，各自的专用入口都被一层薄的脚本、REST 或 Python 包替换掉。付费点也跟着挪了位置，落在运维复杂度上，不在软件许可上。

今日首选

Dograh（dograh-hq/dograh）。它的收费结构最完整：自托管免费做入口，托管云按用量收，正对着按分钟计费的 Vapi 与 Retell，通话量越大成本差越明显。语音这条线的工作流、线路、模型三层都已经在产品里跑通，一条 docker 命令就能验证，不靠演示视频。赛道拥挤是事实，但它把「数据不出内网」做成了默认值，这是闭源 SaaS 卖不了的部分。

组合观察

五项都在拆同一层东西：设备与系统的专用控制界面。电视桌面靠 adb 脚本顶掉，没有 API 的网站包成 MCP 工具，电话平台换成自托管的编排器，墨水屏靠 REST 推送，仿真模型写成 Python。更值得注意的是收费点的位移：钱不再收在软件许可上，而是收在运维复杂度上——浏览器机群、站点改版修复、权限与登录代管、批量改机与上门。许可能免费送出去，是因为真正难的那部分本来就不在许可里。
