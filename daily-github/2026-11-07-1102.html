Impeccable pbakaus/impeccable

⭐ 104,878 · 近 30 天 未获取到（Trending 今日 +8,172） Rust · Apache-2.0 最近提交 11-06 · engine-v0.1.19

定位给编码智能体的设计词表：polish、bolder 指方向，critique 按可用性启发式打分，audit 把无障碍与响应式问题排成 P0 到 P3。

痛点没有词表时智能体只会产出米色底、胶囊按钮、卡片套卡片；说一句再好看点，它只能自己猜。

付费没有付费层，不要 key，规则在本地跑；能收钱的是设计体系落地与评审咨询，以及把它改成企业自有规范。

规模化npx 一条命令接进二十多种编码工具，规则是静态文件，同一套词表跨项目复用。

边际低 · 不调模型，评审在本地完成，没有推理账单。

验证npx impeccable install，重载工具后运行 /impeccable critique <页面路径>，一分钟拿到评分与修复排序。

风险62 条规则是硬编码审美，换一套品牌语言就误报；词表一周能被复制，护城河在作者的案例与口碑；6,233 个 fork 与 71 个未关 issue，方向由作者一人定；评分不能替代真实的用户测试。

定位自托管的 PR 评审智能体，/review、/improve、/ask 三个命令，GitHub、GitLab、Bitbucket、Gitea 都能接。

痛点按席位卖的评审机器人一人一月二三十美元，代码要出门，提示词还改不了。

付费仓库免费靠赞助；买方自建替掉按席位订阅，钱落在部署、模型调用与私有规则上。Qodo 另有付费产品，这是社区维护的原始开源版。

规模化一个容器或 GitHub Action 接进现有流程，PR 压缩策略把大改动压进单次调用。

边际低 · 每次评审一次模型调用，账单落在自己的 key 上。

验证docker run --rm -it -e OPENAI__KEY=… -e GITHUB__USER_TOKEN=… pragent/pr-agent:latest --pr_url <PR 地址> review，半分钟出评论。

风险与 Qodo 商业版分家后靠社区维护，人力与路线都不稳；单次调用省钱，跨文件推理就浅；53 个未关 issue；自建要自己管密钥与模型账单。

痛点演示视频人人会拍，换一台臂、换一批场景就复现不了；采购要的是可比分数与单次成本。

付费框架 MIT 免费，母体 Robocurve 是公益公司，靠对外做真机评测与报告收费；公开榜上 GR00T N1.7 每次尝试 0.05 美元、Dream-1 0.15 美元、Gemini 4 Argon 0.66 美元。

边际低 · 软件不背算力，真机台架与人力按项目报价。

验证uv venv && uv pip install inspect-robots，再 inspect-robots run --task cubepick-reach --policy scripted --embodiment cubepick，无硬件跑通全链路。

风险仓库自己写明 API 会变，得锁版本再用；真机控制（ROS、CAN、V4L2）只支持 Linux；本体插件生态薄，没插件的新臂要自己写；78 个未关 issue。
