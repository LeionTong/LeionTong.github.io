今日首选

组合观察

四条语音加一条文档转换，共同动作是把云端按量计费的那一段搬回本地：模型不动，改的是交付形态与收费口径。对设备厂和内容工作室的含义是，采购清单会从「API 调用额度」变成「授权 + 一次性安装 + 支持合同」，谁的安装包和 C API 更干净，谁更容易进采购。
