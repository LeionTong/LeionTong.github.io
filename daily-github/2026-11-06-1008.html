定位从企业元数据生成本体，把指标口径、实体关系与血缘整理成智能体能查的上下文层，出口是 MCP、CLI 与 API。

痛点智能体既能查库也能翻文档，可同一笔收入在 CRM 和数仓里定义不同，答得越快错得越远。

付费软件免费，账单落在 NIM 的推理容量上；自建 NIM 就折成 GPU 预算，企业为口径治理与审计出处付钱。

风险仓库明说不接收外部贡献，路线由 NVIDIA 单方定；换模型要换 NIM 端点；多租户与细粒度权限得自己补；57 个未关 issue；Hacker News 上 289 分、139 条评论里，「再来一层本体到底解不解决问题」的质疑占了大半。

痛点手机上大半事情只能手点；云端手机农场按分钟计费，还要把屏幕内容交出去。

付费目前全免费、无服务端，模型 key 自备；能付钱的是手机厂商预装、企业移动流程自动化，以及模型厂商买这个端侧入口。

PageSift YOLOW92/pagesift

⭐ 240 · 近 30 天 +240（10-20 建仓，等于全部） Rust · AGPL-3.0 + 商业授权 最近提交 11-04 · v1.1.2

定位一个自托管 Rust 二进制，把网址、扫描 PDF、Office、邮件、压缩包转成干净的 Markdown 或结构化 JSON，自带 MCP 与八种语言 SDK。

痛点智能体的输入层最脏：网页要去壳、扫描件要 OCR、表格要留结构，第三方抓取 API 按页计费还会限流。

付费双许可写在仓库里：AGPL 自托管免费；闭源嵌入、对外托管又不公开改动、要合同与赔偿的，走商业授权并附支持。

规模化与 Firecrawl v1/v2、Jina Reader 同协议，改个地址就能迁移；CLI、HTTP、MCP、容器的引擎是同一套。

边际低 · 单机二进制，抓取与 OCR 的算力在客户机器上。

验证docker run -p 3002:3002 ghcr.io/yolow92/pagesift:1.1.2，再 curl localhost:3002/r/https://example.com 看返回正文，两分钟内出结果。

风险速度数字是作者自建 benchmark 的结果，换站点结构未必复现；AGPL 与商业授权的边界要法务确认，别先上线后补；0 个未关 issue 更像没人报而不是没问题；单作者维护，路线风险集中。

定位用 Rust 重写的自托管元搜索，聚合外部引擎结果，JSON 与 MCP 两种接口把结果和页面正文递给智能体。

痛点智能体联网一般买按次计费的搜索接口，量一大账单跟着涨，查询内容还得出门。

付费没有官方收费版本；买方是企业为私有化部署、内网检索与合规审计买单，卖的是部署与运维，软件本身 AGPL。

组合观察

这五件都在模型外面：口径、手机执行、抓取、检索、建模。共同动作是把原本按调用量或席位计费的一段做成可自托管、可审计的组件，开源负责获客与试用，签约落在部署、支持与许可边界上。智能体的预算正在从「用哪个模型」转向「谁来保证这一段不出错」。
