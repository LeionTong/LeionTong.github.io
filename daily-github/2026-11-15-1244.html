语音这门生意过去有三个收费口：听写软件按席位卖、会议记录与同传按分钟卖、呼叫中心按坐席卖。这一期五件把这几个口子的软件做成可以自己跑的形态，剩下的成本落在麦克风、算力与 SIP 线路这些真实开销上。

Hex anomalyco/hex

⭐ 6,740 · 近 30 天 +5,063 Rust · MIT 最近提交 11-15 · v3.4.0

定位按住快捷键说话、松手把文字粘进当前窗口，识别在本机完成，覆盖 macOS、Windows 与 Linux，命令行也能转录现成录音。

痛点按席位订阅的听写工具把语音变成长期账单，法务、医疗这类不许把录音送出本机的场景根本用不了。

付费本体 MIT 免费，厂商卖的是分发渠道与后续服务；替掉的是每人每月的订阅费，团队越大差得越多。

规模化一份安装包铺三平台九种包格式，同一套模型在 Apple silicon、x64 与 ARM64 上都能跑。

边际低 · 识别全在本机，没有服务端开销。

验证装完按住快捷键说一句就有字，两分钟能判定：

brew install --cask anomalyco/tap/hex
hex transcribe meeting.m4a
风险明确不接 PR，代码与发版节奏由一家公司掌握；首次运行要下模型，离线机器得自己搬；216 个 open issue，长尾问题还多；只发自有域名与 Homebrew、AUR，企业内分发要自己核验安装包。

Pipecat pipecat-ai/pipecat

⭐ 17,268 · 近 30 天未获取到 Python · BSD-2-Clause 最近提交 11-15 · v1.16.0

定位实时语音与多模态智能体框架，把识别、合成、传输与打断做成一条可拆可换的流水线，多智能体之间能交接与并行。

痛点做语音客服或陪伴类产品，最难的是延迟与打断；WebRTC、端点检测、识别、合成这些胶水代码每家都要重写一遍。

付费框架 BSD-2 免费，官方托管 Pipecat Cloud 与部署命令行收费，客户是把语音接进产品的团队。

规模化官方给 JavaScript、React Native、Swift、Kotlin、C++ 与 ESP32 六套客户端 SDK，一套服务端喂多种终端。

边际低 · 纯软件框架，模型与算力费用由使用方承担。

验证装命令行工具后一分钟起一个能说话的机器人：

uv tool install "pipecat-ai[cli]"
pipecat init quickstart
风险这一层已经很挤，LiveKit Agents、dograh、bolna、Patter 抢同一批客户；抽象层厚，出问题要用 Whisker 单独调试；模型与传输按供应商分别计费，账单分散在多家；框架版本每周一版，升级要跟。

Cicada 知了 wquguru/cicada

⭐ 2,268 · 建仓 11-01，13 天到 2,268 Swift 主仓 · Apache-2.0 最近提交 11-14 · v1.10.1

定位直接采系统声音做实时双语字幕与同声传译，按住说话键把自己的话翻过去，会后自动出摘要、议题、结论与待办。

痛点跨语言会议要么请同传按小时付费，要么用云端转写按分钟计费，录音还得交给第三方平台。

付费开源免费；Apple silicon 上识别全在本机，其他平台填自己的模型服务 key，钱付给模型商，中间层不收。

规模化Mac、Windows、Linux、Android 共用版本号与记录格式，会议、直播、播客与网页音源都能接，不往会议里塞机器人。

边际低 · 桌面与移动端软件，识别在本机或用户自己的 key 上跑。

验证下安装包，随便开一场会即出字幕：

https://cicada.indaloop.app/en/download/
风险建仓十三天、一个人的项目，接口与记录格式还会动；Windows、Linux、Android 依赖第三方模型 key，换供应商要重配；Linux 上笔记窗会被屏幕共享看到；手机端录不到会议音频，只能开免提走进场模式。

Yogurt FrigadeHQ/yogurt

⭐ 1,514 · 建仓 11-10，5 天到 1,514 TypeScript · MIT 最近提交 11-15

定位本机录音、逐字稿与纪要三合一，识别用 whisper.cpp，摘要用 llama.cpp 跑本地权重，不往会议里加机器人。

痛点按月订阅的会议记录服务把录音与逐字稿放在别人的服务器上，签了保密条款的团队用不了；自己拼三套工具又要长期维护。

付费MIT 免费、不用账号；买单方是要把录音留在本机的律所、医疗器械与研发团队，省下的是一人一份的订阅。

规模化三平台单机程序，九十九种语言，笔记可导出 Markdown，自带本机 MCP 服务器给其他助手读。

边际低 · 全在本机跑，八 GB 内存起步。

验证下对应平台的安装包，开一次通话即出逐字稿：

https://github.com/FrigadeHQ/yogurt/releases/latest
风险建仓五天，企业要的集中管理、权限与审计都还没有；说话人识别与日历联动只在 Mac 上；本机模型在八 GB 机器上会慢；Windows 安装包未签证书，首次运行会被系统拦一次。

RustPBX restsend/rustpbx

⭐ 841 · 近 30 天未获取到 Rust · MIT 核心 · 商业版按 license 最近提交 11-13 · 0.5.0

定位Rust 写的软件定义 PBX，SIP 与媒体都在进程内，路由与通话控制通过 HTTP、WebSocket 与 Webhook 外置，AI 智能体能作为通话方加入。

痛点换一套呼叫中心，Asterisk 要写 C 模块重编译，云呼叫中心按坐席与按分钟收费，两种都把计价方式绑在供应商身上。

付费核心 MIT，商用、批发与呼叫中心三档镜像按 license key 开通，收费点写在明面上。

规模化SIP 是通用协议，一套配置服务客服、外呼、通知与内部分机；官方实测五千路并发在约 3.8 核上跑满。

边际低 · 一台机器起步，扩容靠加核与加节点。

验证一条 docker 命令起服务，再拨官方测试号验通断：

docker run -d --name rustpbx --net host \
  -v $(pwd)/config.toml.example:/app/config.toml \
  ghcr.io/restsend/rustpbx:latest --conf /app/config.toml
# 注册分机后拨 sip:echo@probe.rustpbx.com 听回放
风险版本停在 0.5.0，接口还会变；商业镜像放在国内仓库，与 ghcr 社区版不同源，升级路径要自己确认；智能体走 WebSocket 加入通话，延迟与打断要自己调；从 Asterisk 迁过来的拨号方案要重写。

今日首选

Hex（anomalyco/hex）。一个安装包装上、按住快捷键说一句话就能验完，替掉的是每人每月的听写订阅，成本差当场算得出来。识别在本机，不许外传录音的场景直接可用。要盯的是它不接 PR、发版与分发都握在一家公司手里，选型前先确认这个依赖能接受。

组合观察

五件压的是语音入口的三段计费：听写按席位、会议按分钟、电话按坐席。本地模型与自托管软件把这三段的加价空间一起挤掉了，能留下来的收费位置是麦克风阵列、算力与线路这些真实成本，以及把几段拼成一套能验收的系统的工程能力。

暂不建议碰

  1. huamidev/GestaltX（7,603★，建仓 11-09）· 改 iOS 机型标识与区域码的工具，五天涨到七千多星，走的却是系统校验之外的路子，商用分发要面对合规与保固问题，也找不到能持续的收费点。
  2. Lynpoint/CyberVerse（1,993★）· 实时数字人框架，README 里塞了不少云 GPU 的推广链接，正式发版只有 v0.1.0，实时视频推理按并发吃显卡，交付一台就得配一台机器。
