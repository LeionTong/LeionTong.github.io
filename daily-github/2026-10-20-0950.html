同一件事的五种做法：agent 要干活，得先有一块能读、能点的屏幕。手机侧分托管云机、本地软件桥与物理触控三条路，屏幕侧一个管智能屏内容、一个给 agent 自己一块虚拟屏。

Phone Harness ShawnPana/phone-harness

⭐ 3,830 · 近30天 +1,144 Python · MIT 最近提交 10-17 · 68 open issues

定位让 agent 直接操作你的真机：iPhone 走 Mac 的镜像窗口，Android 走 adb，也可用云手机；不越狱、不装 Xcode。

痛点手机 App 大多不给 API，agent 想替人跑注册、下单、回消息，缺一层统一的读屏与点击原语。

付费本地免费；云端 Phone Harness Cloud 首 100 分钟免费，云安卓按分钟计费，卖真机号码与 2FA。

规模化凡要替用户在手机上跑流程的团队都适用，helpers 是稳定的屏幕与点击原语，换 App 不改代码。

边际中 · 本地插件零成本，云手机按台按分钟摊算。

验证uv 装好 CLI 后跑 phone-harness skill 注册技能、phone-harness doctor 自检，再按 onboarding.md 配对手机。

风险iPhone 这条路依赖 macOS 镜像窗口与辅助功能、录屏授权；68 个 open issue；云端有机器与号码成本，规模化后边际不归零。

iPhone Use zhongerxin/iPhone-use

⭐ 4,317 · 近30天 +4,317（10-06 建库） Python · MIT 最近提交 10-16 · v0.3.15

定位把 USB 连着的那台 iPhone 交给 Codex：用 WebDriverAgent 读屏、点击、输入，侧边栏同步手机画面。

痛点手机上整理收件箱、核对表单只能手点；控件定位失败时还要人截图回传，agent 够不到真机。

付费插件免费，装在自己 Apple 开发者签名下；仓库暂无收费，收费位置留给托管设备的一方。

规模化每个有 iPhone 的开发者都能装，交付是安装脚本加本地 MCP 服务，不挑宿主。

边际低 · 纯本地运行，一次装配长期复用。

验证sh scripts/install.sh，缺 WDA 时按提示用自家团队签名构建并启动。

风险首次要 Apple 账号签名并部署 WDA，个人免费账号 7 天到期需重签；默认发匿名使用统计可关；仍需一台 Mac 侧支持。

⭐ 397 · 近30天 +96 Python · MIT 最近提交 10-20 · 硬件版 v0.50

定位相机读屏、触控笔点击的物理手机操作手，手机不装东西、不开调试，agent 像人一样点屏幕。

痛点ADB 与桌面自动化会留下可被风控识别的指纹，而生活类 App 基本没有 API。

付费软件 MIT、模型 BYOK，卖 CAD-as-code 的硬件套件；站点已备中英文文档与装配视频。

规模化「替人跑腿」跨 App 通用，但每台手机要配一套相机与机械笔，交付带硬件。
