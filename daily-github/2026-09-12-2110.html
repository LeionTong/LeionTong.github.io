Chrome DevTools MCP ChromeDevTools/chrome-devtools-mcp

⭐ 51,725 近 30 天 未获取到 TypeScript Apache-2.0 v1.9.0 · 提交 2026-09-11 主流

定位把 Chrome 完整调试协议包成 MCP 服务，让 coding agent 直接读 DOM、截图、抓网络、跑性能分析。

痛点让 Agent 操作真实浏览器，过去只能接 Browserbase / Steel 这类按会话计费的托管服务。

谁付钱需要浏览器自动化的工程团队与 Agent 产品；开源免费，第三方靠私有化支持与集成变现。

规模化凡 coding agent 需取网页上下文都通用，MCP 接入即标准化，无实施。

边际成本低 —— 纯软件 MCP 服务，无硬件无 GPU。

验证≤30 分钟：

npx -y @chrome-devtools/mcp@latest

# 在 Claude Code / Cursor 的 mcp 配置里加上述命令，重启后让 agent
# 「打开 example.com 并截图标出登录按钮」

风险本质是 Google 免费基础设施，路线图由 Chrome 团队定；原生面向调试协议，登录态与反爬场景仍需配 stealth 方案。

Centrifugo centrifugo/centrifugo

⭐ 10,742 近 30 天 未获取到 Go Apache-2.0 主干 · 提交 2026-09-12 主流

定位语言无关的可扩展实时消息服务器，自托管替代 PubNub / Pusher / Ably。

痛点实时消息按量计费，用量上来账单陡增，且供应商锁定协议。

谁付钱需要实时推送 / 在线状态的 Web 与移动产品；开源免费，商业云与优先支持变现。

规模化实时消息是通用基建，跨行业，Docker 一行起，可标准化。

边际成本低 —— 纯服务端软件，新增客户零增量。

验证≤30 分钟：

docker run -it --rm -p 8000:8000 centrifugo/centrifugo:latest

# 打开 http://localhost:8000 走内置 demo，或用 centrifugo config.json 起生产节点

风险与托管实时服务（Ably / Pusher）和云厂商托管 WebSocket 直接竞争；客户端需接它的协议，迁移成本在 SDK 层。

Dograh dograh-hq/dograh

⭐ 5,635 近 30 天 未获取到 Python BSD-2-Clause v1.46.0 · 提交 2026-09-12 小众

定位自托管语音 AI 平台，BYOK 接 STT / TTS / LLM，替代 Vapi 与 Retell。

痛点语音 AI 按分钟计费，Vapi / Retell 单价高，且供应商锁调用与计费的入口。

谁付钱要做语音 Agent、电话机器人的团队；开源免费，客户只为底层模型付费，厂商赚支持与私有化。

规模化语音交互是高需求垂直，但依赖 telephony / STT / TTS 供应商生态，交付需配置。

边际成本中 —— 平台软件自托管无硬件，但跑语音需接外部 STT / TTS / LLM，有外部成本。

验证≤30 分钟：

git clone https://github.com/dograh-hq/dograh && cd dograh
docker compose up -d   # 按 README 填 BYOK 的 STT/TTS/LLM key 后接电话或 Web 渠道

风险强依赖外部语音供应商，成本与可用性不完全自控；项目新（v1.46.0），多厂商编排与 telephony 稳定性待生产验证。

一、今日首选

centrifugo/centrifugo（加权 5.00）。它攻击的是最成熟、最易量化的替代场景——按量计费的实时消息（PubNub / Pusher / Ably），且有十年生产验证与 Apache-2.0 许可，Docker 一行即可交付，成本差是立刻可算的。

二、组合观察

五条都是同一件事的不同切面：把一类已被市场验证、按量或按席位计费的 SaaS，换成开源自托管形态——浏览器自动化、实时消息、语音 AI、邮件发送、嵌入分析。共同信号是「用量越大、账单越痛」的品类最先被自托管搬走，而交付形态正从「另起平台」收敛为「一个可嵌入的库或一行 Docker」。

三、暂不建议碰

  1. Gitlawb/openclaude（⭐ 33,192，TypeScript，MIT）— 实为 Anthropic 专有 Claude Code CLI 的衍生物，MIT 仅覆盖二次修改，底层代码受 Anthropic 商业条款约束。商用即把上游 ToS 风险写进自己的交付，一票否决。
  2. DietrichGebert/ponytail（⭐ 136,259，JavaScript，MIT）— 让编码 Agent「像最懒的高级工程师一样思考」的 Claude Code 配置 / 技能合集。无产品形态、无收费入口、复制成本为零，热度来自安装量而非付费意愿，属当日高热但不符标准的技能类项目。
