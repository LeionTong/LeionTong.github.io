今日首选

OpenBot（CopilotKit/OpenBot）。上线 29 天近 5k 星、登 Trendshift 日榜，Agent 治理是确定性企业刚需；CopilotKit 已有云服务变现路径，五者中商业化最清晰。

组合观察

五项共同指向同一条线：Agent 基础设施正从「更强的模型」转向「可控、可审计、数据不出门」——OpenBot 用策略门禁、AgentVerse-OS 用隔离工作区、agent-launcher 收拢入口，openshorts 与 editor 则代表本地优先、拒绝 SaaS 订阅的并行浪潮。这意味着企业把 Agent 当生产基础设施时，先解决「管得住」，再谈「更聪明」。

暂不建议碰

  1. Tencent/teamai-cli（4,520★）· 团队级 Agent Skills/Rules/MCP 配置同步，被广泛讨论；但 License 为自定义/非 OSI（NOASSERTION），企业采用与二次分发存在合规不确定性，落地前需先解决许可。
  2. VaderChen/YourDesk（229★）· 远程桌面 MCP 接口让 Agent 操控真机；同样为非 OSI 自定义许可（NOASSERTION），且依赖 macOS/Windows 硬件加速，跨平台与许可风险偏高。
