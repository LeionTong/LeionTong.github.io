Fleet fleetdm/fleet

⭐ 7,019 · 近 30 天未获取到 Go · MIT Expat（ee/ 目录另授权） 最近提交 10-22 · v4.93.2（10-21）

定位跨 macOS、Windows、Linux、Android、iOS 的设备管理平台，一个 Go 二进制加 Web 控制台，覆盖入网、合规检查、补丁与漏洞。

痛点设备上千台后，按台订阅的设备管理变成每年固定大额支出，策略节奏还得跟着云厂商的发版走。

付费价目公开：Free 每主机每月 0 美元，Premium 每主机每月 7 美元；自托管与付费共用一套代码，ee/ 目录单独授权。

规模化员工终端、门店设备、实验室机器走同一套入网与合规流程，换行业不改产品。

边际成本低 · 服务端跑在客户机器上，官方增量成本只有支持人力。

验证git clone https://github.com/fleetdm/fleet && cd fleet && docker compose up -d，compose 把服务与控制台一起拉起。

风险3970 个 open issue；设备管理能力压在 APNs、ABM、Autopilot、Android EMM 这些厂商通道上，证书与合规材料是深水区；零接触部署与迁移只在 Premium 里。

Anthias Screenly/Anthias

⭐ 3,700 · 近 30 天未获取到 Python · GPLv2 与商业许可双授权 最近提交 10-21 · v2026.10.0（10-16）

定位刷进树莓派或 x86 小机的数字标牌系统，资产库、播放列表、定时调度与网页控制台都在本机。

痛点标牌 SaaS 按屏按月收费，几十块屏一年就是一笔固定开销；门店网络常常不允许播放端连外网。

付费双授权：GPLv2 自用免费，闭源集成或要商业条款向 Screenly 买；官方另卖托管服务与硬件。

规模化连锁门店、学校、诊所、车间的播放需求同构，烧一张卡能复制到任意台。

边际成本低 · 只发镜像与容器，播放算力在客户自己的设备上。

验证bash <(curl -sL https://install-anthias.srly.io)，也可在 Raspberry Pi Imager 的 Digital signage and kiosks 里直接选 Anthias。

风险只支持 Debian 系的 Armbian，Ubuntu 版会在 apt 阶段失败；非树莓派板子的视频靠软件解码，1080p 以上容易卡；闭源分发要另买商业许可。

Bambuddy maziggy/bambuddy

⭐ 3,138 · 近 30 天未获取到 Python · AGPL-3.0 最近提交 10-22 · 稳定版 v1.2.5.7（10-02）

定位自托管的 Bambu Lab 打印机群控制台，排队、耗材、摄像头、切片、固件回滚都在本地完成。

痛点打印农场要么绑厂商云，要么用按台订阅的第三方平台；多机排队与失败重打全靠人盯。

付费AGPL-3.0 开源，收费位置在农场部署与运维支持；对标 SimplyPrint 那类按打印机分档的订阅，Basic 每月 5.99 美元、上限 2 台。

规模化一台 A1 到几十台的农场是同一套队列逻辑，学校创客空间与小批量代工同构。

边际成本低 · 自托管，切片挂可选 sidecar，算力由客户出。

验证docker compose up -d，容器起来后在网页里填打印机 IP 与访问码。

风险只覆盖 Bambu Lab 生态，换品牌等于换产品；251 个 open issue，1.3.0 还在 daily beta 上滚动；AGPL 对想闭源集成的买方是硬约束。

FreeKiosk RushB-fr/freekiosk

⭐ 690 · 近 30 天未获取到 TypeScript · MIT 最近提交 10-20 · v2.0.0-beta.6（10-14）

定位安卓平板的锁定模式，用 Device Owner 接管设备，支持 WebView 与外部应用两种模式，40 多个 REST 端点加 MQTT。

痛点展厅、点单台、签到机的平板必须锁死，商业方案按设备收授权，一百台就是一笔硬支出。

付费核心 MIT 免费；官方云已在收费，首台永久免费，之后每设备每月 1 欧元起。对照 Fully PLUS 每台 8.90 欧元一次性授权、Fully Cloud 每台每月最高 1.18 欧元。

规模化任何 Android 8 以上的平板都能刷成同一套配置，连锁门店与临时活动共用流程。

边际成本低 · 云端只做状态与配置下发，负载随设备数线性增长，单价压得下来。

验证先装 v2.0.0-beta.6 的 APK，再执行 adb shell dpm set-device-owner com.freekiosk/.DeviceAdminReceiver，之后应直接进锁定页。

风险2.0 仍是 beta；Device Owner 只能在没有登录 Google 账号的新设备上设置，设错要恢复出厂；云端自托管版本排到 2027。

ScreenTinker screentinker/screentinker

⭐ 235 · 近 30 天未获取到 JavaScript · MIT 最近提交 10-22 · v3.0.2（10-21）

定位自托管的数字标牌内容管理系统，多租户、播放列表、排期、视频墙与播放端状态监控，播放端就是浏览器。

痛点连锁门店几十块屏要统一换内容，SaaS 按屏计费，素材还要过第三方服务器；断网只能等人上门。

付费代码 MIT，托管云有免费额度，付费档位没有公开；自托管设 SELF_HOSTED=true 后首个账号解锁全部功能。

规模化一个后台管多门店，播放端覆盖 Android TV、Fire TV、Tizen、webOS、Roku、树莓派与普通浏览器，不装播放器授权。

边际成本低 · 作者说法是一台 5 美元的 VPS 带数百块屏。

验证git clone https://github.com/screentinker/screentinker.git && cd screentinker && SELF_HOSTED=true npm start。

风险单人维护、235 星，v3 刚发布；托管定价不透明，商业条款要直接谈；播放端靠浏览器兼容，老电视盒子跑复杂动画会掉帧。

组合观察

设备管理、数字标牌、平板锁定、打印农场今天在做同一件事：把按台数计价的订阅换成客户自己服务器上的部署，收费挪到支持、合规与云控制面。对买方，采购清单会从「每月多少台」变成「镜像或容器加支持合同」；对卖方，毛利取决于运维与合规能力，云端只剩状态与配置下发这点负载。
