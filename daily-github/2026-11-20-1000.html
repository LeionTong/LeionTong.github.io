Mika wangzan101/Mika

⭐ 9,192 · 近 30 天 +9,192（建仓 22 天） Kotlin · Apache-2.0 最近提交 2026-11-19 · v0.1.49（11-19）

定位安卓上的本机智能体：在一块隐藏的后台屏上开 App、读屏幕、点按钮，主屏照常使用。

痛点多数 App 不开放接口，跨 App 的活只能靠手指；而手机上的操作与模型 key 又要留在本机。

付费Apache-2.0 免费，官网写明没有账号也没有服务器；DeepSeek、通义、Kimi、OpenAI 与本机模型各带各的 key，眼下没有收费档。

规模化按无障碍方式看屏幕、点按钮，不依赖各家接口；个人助理、客服巡检、批量任务用的是同一套能力。

边际低 · 纯 APK，推理走用户自己的 key，官方不承担调用成本。

验证下载 APK，填一个兼容 OpenAI 协议的模型，说一句「总结这个群今天聊了什么」。

风险后台屏与无障碍服务在部分厂商系统上会被清理；代用户点付款会带来责任界定问题；无付费档，商业路径要集成方自己补。

ESP32 iPhone Agent onehumanbeing/esp32-iphone-agent

⭐ 5,114 · 近 30 天未获取到 Swift · MIT 最近提交 2026-11-18 · cli-v0.1.4（11-08）

定位一块七美元的 ESP32-S3 插在 iPhone 上：AirPlay 把屏幕投给板卡当眼睛，USB HID 当手指点按。

痛点iOS 不允许第三方自动化别的 App，越狱和开发者账号各有门槛；真机回归与演示又非要用真机。

付费自家 Manina AI 应用配免费模型额度，命令行版让 Claude Code、Codex 通过 MCP 操作手机；官网另开企业设备实验室与硬件排队。

规模化固件与命令行同源，设备实验室、真机回归、演示录制都能按台标准化交付。

边际中 · 软件免费，每台设备要一块板卡与一根数据线，硬件与物流留在成本侧。

验证刷固件后插上手机，开屏幕镜像与辅助触控，让智能体先截一张屏：

curl -fsSL https://manina.ai/install.sh | sh
风险锁屏、密码输入与 DRM 画面投不出来；占用 USB-C 口无法同时充电；上架受 App Store 审核限制，目前只在 TestFlight。

Airhand sqlpxc/airhand

⭐ 1,818 · 近 30 天 +1,818（建仓 20 天） Rust · MIT 最近提交 2026-11-19 · v0.2.3（11-12）

定位自建中继的远程桌面：屏幕在显卡上编 AV1 或 HEVC，走 QUIC 与 BBR，最高 120 帧，弱网丢帧不堆延迟。

痛点商用远控按席位收费，开源方案在弱网下延迟越积越多；云手机与设备农场还要把流量留在自己机房。

付费MIT 全免费，中继用 Docker 自部署；愿意买单的是接 SDK 的远控厂商、云手机平台与自动化测试服务。

规模化Windows、macOS、Linux、安卓与浏览器共用一套协议，主机端做成系统服务，锁屏和登录界面也能控。

边际低 · 分发客户端与中继镜像，带宽走客户自己的服务器。

验证在一台有公网 UDP 4433 的机器起中继，两端装客户端后输入六位码：

docker compose up -d
风险0.2.3 属开发中版本，协议 v9 之前互不兼容；Linux 主机仅支持 X11 且为软件编码；无付费档，商业模式要集成方自己搭。

Sand3D Sandflow-ai/sand3d

⭐ 2,175 · 近 30 天 +2,175（建仓 17 天） Python · Apache-2.0 最近提交 2026-11-19 · v1.6.3（11-06）

定位把三维件写成几十到几百行的 Python 程序：轮廓、实体、编辑、骨架、关节与装配，跑在 Blender 的 bpy 上。

痛点模型直接写 bpy 脚本，同一个零件要四倍 token，改一处常要重跑整段；网格文件又改不动参数。

付费Apache-2.0 库免费，Sandflow 用十万件代码形态的资产与在线编辑器承接，客户是仿真、具身与工业设计团队。

规模化可导出 URDF 与 OBJ，直接进 ROS、MuJoCo、Isaac；同一套语言覆盖日用品、机械件与带关节的装配。

边际低 · pip 装一个库，数据集放在 Hugging Face，无服务端要养。

验证装好后跑官方示例，改一个尺寸看模型是否跟着变：

pip install sand3d
风险依赖 bpy，版本与 Blender 绑定；产出偏程序化，曲面雕刻类资产仍要别的工具补。

Git for Global Law lexifina/global-law

⭐ 2,122 · 近 30 天 +2,122（建仓 23 天） HTML · CC0（仓库许可自定义） 最近提交 2026-11-20

定位把各国法条按生效日期做成 git 提交：每条现行文本都能查出是哪部法、哪一天写下的。

痛点法律检索按席位收费，历史版本要另买；模型答法条时常把旧版当现行。

付费语料 CC0，可商用免署名；承接方是自家 Lexifina 的法律 AI，Word 插件与浏览器协作按律所和法务团队卖。

规模化每个法域一个子模块，国家、州、市与法院判决分开；命令行与 MCP 读同一份数据。

边际低 · 数据在 git 里，抓取整理一次，后来的人只是读。

验证克隆后查一条法条在某天的文本：

python3 tools/law.py show 2022-05-01 united-states/federal/usc/title-11/1182.md
风险覆盖深度取决于各法域发布方，部分国家只有现行文本；原文再分发权按各国规定，商用前要逐法域核。

今日首选

Sand3D（Sandflow-ai/sand3d）。一行 pip 就能装上，改一个尺寸立刻看到零件跟着变，这种反馈速度在三维工具里少见；更难替代的是它把零件写成可读的程序，导出 URDF 直接进 ROS 与 MuJoCo，具身与仿真的团队省下的是建模与改型的时间。

组合观察

五条在补同一类缺口：手机的后台屏、板卡上的屏幕与触控、显卡编好的帧、几十行的零件程序、按生效日期切开的法条，都是模型默认碰不到的东西。收费位置随之挪动，Mika 不收，Manina 收硬件与企业设备，Lexifina 用免费语料养付费的法律 AI，Airhand 与 Sand3D 把集成方留在自己手里。
