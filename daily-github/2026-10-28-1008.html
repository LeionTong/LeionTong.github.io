Agentgateway agentgateway/agentgateway

⭐ 5,685 · 近 30 天未获取到（本周 +261，Trending 周榜实测） Rust · Apache-2.0 最近提交 10-27 · v1.7.0（10-27）

定位智能体的连接层，一个 Rust 代理同时管模型路由、MCP 工具接入与代理之间的通信。

痛点自建智能体平台要自己拼一层把模型、工具、别的代理串起来的安全与计量层，现成的模型网关不管 MCP 与代理协议。

付费要把智能体上生产环境的团队，以及与参与厂商签订的支持与合规服务；Linux 基金会项目，企业支持由厂商提供，价格未公开。

规模化接入多家模型与工具的需求跨行业同构，交付是一个二进制、一个容器或一份 Helm chart。

边际成本低 · 一个二进制加一份配置做转发，成本随流量线性增长且很薄。

验证curl -sL https://agentgateway.dev/install | bash && agentgateway（不带配置文件时会自举一份 ~/.config/agentgateway/config.yaml）

风险网关赛道已有 LiteLLM、Portkey、Kong 与各家云厂商的产品，差异在 MCP 与 A2A 原生，但 290 个未关闭 issue 说明接口还在动；v1.7.0 刚发布，升级节奏快。

Security Audit Skill cloudflare/security-audit-skill

⭐ 50,277 · 近 30 天未获取到（本周 +16,388，Trending 周榜实测） JavaScript · MIT 最近提交 09-14 · 首次发布 06-18

定位把编码智能体改造成安全审计员的技能，六个阶段从侦察、分派猎手做到独立复核与出报告。

痛点代码审计靠人排期，覆盖到哪里说不清；多个智能体并行审计时各自的结论互相污染，也没有人复核。

付费需要持续做漏洞发现的安全团队；技能本身免费，是 Cloudflare 披露自家漏洞发现体系的入口，间接服务于它的平台与安全产品。

规模化审计流程与项目用什么语言无关，一份技能可以复制到任意仓库。

边际成本低 · 纯提示词与两个校验脚本，成本就是模型 token。

验证npx skills add https://github.com/cloudflare/security-audit-skill --skill security-audit

风险仓库最后一次提交停在 09-14，一个月里涨了 1.6 万 star，热度与维护节奏不匹配；把智能体放到审计位置上，它自己就需要权限治理与结果复核。

SPACE perplexityai/SPACE

⭐ 1,982 · 近 30 天未获取到 Rust · Apache-2.0 最近提交 10-28 · 建仓 10-01 · 无正式版本

定位用 Firecracker 微虚拟机跑代码的沙箱平台，用 HTTP 接口建环境、执行命令、收输出与回收。

痛点让智能体执行代码，要么买按秒计费的沙箱服务，要么自己写一整套隔离、回收与输出通道。

付费自建智能体平台的团队；自托管省掉按沙箱时长计的账单，Perplexity 自己的链路在用，还提供一个 E2B 兼容层方便迁移。

规模化代码执行环境的需求跨行业同构，部署形态是 Kubernetes 上的一套服务。

边际成本中 · 要自备支持嵌套虚拟化的宿主机，冷启动与资源池得自己管。

验证git clone https://github.com/perplexityai/SPACE，按 docs/installation.md 在本地 Kind 集群部署，再照 docs/first-sandbox.md 跑通第一条命令

风险仓库只有四周龄、150 个未关闭 issue、还没有正式版本号；自托管要管微虚拟机宿主、热池与快照，运维负担不轻。

Splash incoai/splash

⭐ 1,889 · 近 30 天未获取到 C++ · Apache-2.0 最近提交 10-27 · v1.4.1（10-26）

定位面向 Apple 芯片的本地推理引擎，投机解码加 Metal 内核，对外给 OpenAI 与 Anthropic 兼容接口。

今日首选

agentgateway（agentgateway/agentgateway）。连接层是每套智能体系统都躲不开的一处，它把模型路由、MCP 工具接入与代理间通信放进同一份配置，还带着预算控制，以及按 GPU 利用率、KV 缓存与队列深度做推理路由的能力。Linux 基金会项目、v1.7.0 刚发布、安装是一条脚本，是这批里接入成本最低、替换意愿最明确的一个。

组合观察

五者分别接管连接、隔离、数据、推理与审计，都在智能体上服务器之后真正要用到的那一层，而不在界面上。它们替换的目标也很一致：按席位买的网关、按沙箱时长买的执行环境、按页买的解析接口、按 token 买的推理。开源与自托管的边界，正从模型本身往模型周边的每一层退。
