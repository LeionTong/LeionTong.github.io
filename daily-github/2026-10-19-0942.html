今日首选

Equibles（daniel3303/Equibles）。五条里唯一把收费、免费额度与数据口径写清楚的：免费 100 请求/天，Plus 卖延迟行情，Pro 卖实时价与预测，自托管版还能直接塞进客户内网。交付是标准 MCP，换供应商只改一个 endpoint，抓一次数据能服务全部客户。

组合观察

编码 agent 的竞争正从上层的「哪个 CLI 顺手」沉到三层底座：可改的工作台、可隔离的执行环境、可追溯的数据源。开源在这三层都退成获客层，收费点分别是模型订阅、托管会话与数据订阅，软件本身越来越难单独卖钱。

暂不建议碰

  1. storytold/photocraft（67,510★ · 纯 Rust 图片编辑器）· 同组织一个月内批量上线 photocraft、pdfcraft、filmcraft、wordcraft、cadgrid 等十余个「clean-room 重写」，star 增速与真实使用证据脱节；单仓库看是爆款，放到组织维度更像集中投放，商业化只剩消费级买断一条路。
  2. Ebony-Vinyl/dsh-our-free-model（24,863★ · 免费前沿模型插件）· 靠绕过登录、注册与 API Key 提供「无限量」调用，上游一封即失效，没有收费主体，也没有合规路径。
