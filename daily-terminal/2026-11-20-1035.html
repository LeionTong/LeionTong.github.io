旧音箱被改写成本地语音端点，手表表盘改成浏览器里拖出来

本期六条：二手 Echo 与 Yandex 音箱各有替换固件，ESP32 上跑实时语音管道、Mac 上一条命令起本机对话、NAS 上自建多房间语音端点；穿戴侧只剩一条，用浏览器画表盘再一键写进板子。

本期扇区语音终端 · 穿戴 · 桌面机器人
入选6 个仓库
检出口径30 天内有推送 · 非 fork 非归档

语音终端这一档的共同动作是把音箱从厂家的云里摘出来。Echo 的两代 Dot、三款 Show，Yandex 的旗舰音箱，全都有替换固件：麦克风、喇叭、灯环、屏幕继续用原来的，唤醒、对话与音乐换成本地跑的。另一头在往上走，ESP32 直接接实时语音管道，Mac 上一个命令就把本机模型串成对话，NAS 上则按房间铺开多台设备。存量硬件不值钱了，值钱的是让这些硬件还能用的那一层软件。

穿戴侧只有一条，落在表盘制作上。把界面设计从写 C++ 变成拖图层，预览直接编译板子自己的代码，按下 Load 就是把刚画的东西变成固件。这条路对白牌方案商的意义大于对个人开发者：表盘做得多快，决定样机能不能赶上客户的档期。

ElatoAI akdeb/ElatoAI

⭐ 2123语音终端部署: 源码（固件 + 云函数）商业化: 强无正式发版 · 2026-11-17

定位在 Arduino ESP32 上跑实时语音对话，走安全 WebSocket 与边缘函数，STT、LLM、TTS 三段都能换，接一百多个语音模型。

亮点构建支持 PlatformIO 与 Arduino IDE 两条路，后端可以用 FastAPI 加 Pipecat 起一百余种管道组合，也可以换 Cloudflare Workers AI 与 Durable Objects 做成万台设备的全球网络，单次对话能连着说二十分钟以上。OpenAI Cookbook 收过它的 ESP32 实时示例，另有一个 local-ai-toys 分支把模型换成本机的 Qwen、Mistral 与 MLX TTS。许可文件正文是 MIT，随仓库带了 AI 玩具套件的 Kickstarter 记录与多设备部署文档。

商业化玩具与陪伴类设备厂可以直接把它当语音层，模型自选、云边都通，省掉自己去拼实时音频链路的活。

风险与坑GitHub 的 License 接口认成 NOASSERTION，LICENSE 正文是 MIT 但附了附加条款，商用前要逐条读；模型密钥与云账号自备；ESP32 的音频前端功放与回声消除取决于底板，套官方开发板以外要自己调；社区答疑压在 Discord，仓库里只有 6 个 issue；没有走 release 页发版。最近推送 2026-11-17。

EchoLocal ygelfand/echolocal

⭐ 601语音终端部署: 固件商业化: 中v0.0.15 · 2026-11-18

定位把二手 Echo Dot 与 Echo Show 换成开源固件，接管麦克风、喇叭、灯环和屏幕，接入 Home Assistant 当本地语音卫星。

亮点设备端跑 microWakeWord 与 openWakeWord，两个助手各配唤醒词与 Assist 管道，「stop」不用唤醒词就能打断；喇叭做成 media_player 并带 Music Assistant 的 Sendspin 播放器与 Chromecast 接收。Show 上有 21 种表盘、门铃画面与双向对讲、Immich 与 Google Photos 壁纸、33 种音频可视化、18 套配色。每台设备带 HTTPS 网页控制台与 HTTP 脚本接口，蓝牙代理兼发 iBeacon，升级走 Home Assistant 的稳定或开发通道，回滚可点名版本。已支持 6 款 Echo，姊妹项目 LANovo 另覆盖 5 款联想屏与 JBL Link View。MIT。

商业化二手 Echo 存量极大，翻新商与渠道商可以预装成离线语音盒卖；软件本身不收钱，收益在整机与服务。

风险与坑绑 Fire OS 6/7 的旧固件版本，设备要先解锁；Echo 2 代仍是实验状态；版本号还在 0.0.x，37 个未关闭 issue；自签证书，壁纸接 Immich 与 Google Photos 各需凭证。最近推送 2026-11-20。

Boubou runboubou/boubou

⭐ 100语音终端部署: 源码（npx）商业化: 中无正式发版 · 2026-11-18

定位在 Mac 上一条命令起本机语音对话，模型全开源，不注册账号，说话就是输入。

亮点启动时按芯片、内存与磁盘余量筛出这台机器跑得动的音色，再让人挑语言与音色，STT、LLM、TTS 三段配置随即定好；serve 子命令把声音共享出去，手机扫二维码、机器人或外部应用填地址与端口就能接。目标环境是 Apple Silicon macOS 13.3+ 与 Node 18+，MIT。

商业化机器人、玩具与桌面摆件的厂商可以拿它当本机语音后端，硬件侧只留麦克风与喇叭，不必自建推理服务。

风险与坑只支持 Apple Silicon 的 macOS，Linux 与 Windows 没有；仍挂 beta 标签，靠 npx 拉取，无正式发版；100 星、2 个 issue，社区很薄。最近推送 2026-11-18。

小瑞 rui yes999zc/rui

⭐ 24语音终端部署: 容器商业化: 中v0.8.19 · 2026-11-05

定位让家里已有的音箱继续用自己的麦克风与喇叭，把唤醒、对话、记忆、音乐全交给自建服务跑，配置在本地。

亮点一条 Docker 命令部署在 NAS 或小主机上；每台音箱分一个音频平面，唤醒与播放按房间隔离，一间放歌不会把另一间弄聋；支持播放中打断与自回声抑制，接 Navidrome 或 OpenSubsonic 当音乐源，提醒由本机播报。v2 控制台中英双语，管设备、房间、凭据、日志与体检，不必手改 YAML；新设备接入脚本把备份、写入、逐字节读回校验、重启设备串成一条命令，可以交给 AI 助手代跑。MIT。

商业化多房间语音的私有化替代正好落在愿意维护一台 NAS 的家庭，可做整机交付或上门装机。

风险与坑必须有一台常开的 Docker 主机；主力接入设备是刷过 EchoMuse 的 Echo Dot 2 与小米 LX06，前置刷机门槛不低；单维护者、24 星，接入新音箱要自己写桥接插件。最近推送 2026-11-05。

PopkaStudio PopaSpinka/PopkaStudio

⭐ 75穿戴部署: 源码（编辑器 + 固件）商业化: 中v2.5 · 2026-11-19

定位在浏览器里给 ESP32 板画表盘与应用界面，预览是板子自己的代码编译成 WebAssembly 跑出来的，按下 Load 就把刚画的界面变成固件写进表。

亮点16 种时钟样式、任意叠层与沿边缘排的曲线文字、天气与步数卡片、播放列表与网络电台（圆表和 7 寸板带跟声音跳动的频谱），7 寸板还能播 microSD 或 Wi-Fi 推流过来的视频。屏幕之间用连线的地图管理跳转，板子插在 USB 上时拖动即改色即预览，不用每次 Load；Check the board 只读不写，先替机主备份别人的固件。覆盖 1.75 寸圆表、ESP32-P4 的 7 寸与 4 寸方屏，社区另有 WT32-SC01 Plus。MIT，v2.5 于 2026-11-19 发布。

商业化表盘做得多快直接决定样机交付节奏，白牌表厂与套件商可以拿它当随货工具，卖的是板子与定制。

风险与坑单人项目，75 星；视频转换要本机装 ffmpeg；板型与面板绑定很死，换一块未收录的屏要等适配；编辑器是桌面端分发，不是纯网页服务。最近推送 2026-11-19。
