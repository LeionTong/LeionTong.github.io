⭐ 15203 语音终端 源码 商业化 强

定位离线语音识别 API，一套 C 核心配 Python、Java、C#、Node 绑定，同一套模型跑在 Android、iOS、树莓派与服务器上。

亮点Apache-2.0，最近推送 2026-10-15；Kaldi 打底，几十兆的小模型就能在树莓派与手机上常驻识别，官方给出多种语言的预制模型；602 个未关 issue 集中在跨平台绑定与模型转换，属于被大量真实设备长期使用的痕迹；最新版本 v0.3.50（2024-04-22），发版放缓，改动主要落在 master。

商业化许可宽松、模型体积小、绑定齐全，做语音终端整机或语音订阅产品时是最省事的可嵌入底座。

风险与坑识别精度与主流云端大模型有差距，中文长句与大词汇量场景基本要自训模型；上游发版间隔以年计，新平台适配靠社区 issue 与自行打补丁。

⭐ 211 语音终端 源码 商业化 中

定位在 ggml 上把语音合成、语音识别与断句检测装进一个 C++ 仓库：Qwen3-TTS、Irodori-TTS、Qwen3-ASR、ReazonSpeech、parakeet 与 Silero VAD，后端覆盖 Metal、Vulkan 与 CPU，另带 OpenAI 兼容服务端与实时转写。

亮点MIT，最近推送 2026-10-26；八月末创建，一个月内发出 23 个版本，最新 v0.9.0（2026-10-26）；纯 C++ 无 Python 运行时依赖，release 直接给二进制，适合塞进小主机与端侧设备；同一套 ggml 后端把合成、识别、断句串成完整的对话链路。

商业化端侧语音对话需要一个不依赖云端、同时出识别与合成的二进制，这类项目直接对应整机预装与私有化交付。

风险与坑11 个未关 issue，一个月的新仓库，各模型权重的许可要逐个确认才能商用；ggml 上的合成质量与延迟还在快速变化，接口不保证稳定。
