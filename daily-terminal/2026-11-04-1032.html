亮点覆盖 1.9 寸到 7 寸的九组板型：2432S022、2432S024、2432S028（三个变体）、2432S032、3248S035、4827S043、4848S040、8048S050、8048S070，电阻触摸与电容触摸版本分别给到。同一份应用只改构建标志就能换板编译，驱动直接用芯片厂固件里已有的 esp_lcd_panel 接口，不夹带只为别的板子准备的冗余代码；LVGL 挂在 9.1.0，运行中可旋转屏幕与触摸坐标，带触摸校准与背光自适应回调。

商业化这类板子在电商上几十元一块，出货量在，可收的钱在做整机方案的固件定制、量产烧录与外接屏模组的适配服务；GPL-3.0 对闭源出货有约束，卖服务比卖固件顺。

风险与坑最新 tag 停在 2.1.0（2024 年 11 月），近期改动都在主干上，用平台库安装拿不到新板型支持；28 个未关闭 issue；只对 Sunton 这一家的板型负责，换屏幕要自己写板级定义。

定位把 Qwen3.5 视觉语言模型放到键盘鼠标操作的游戏录像上继续预训练，看当前画面直接给出下一段操作。

亮点一次调用输出未来 200 毫秒的动作：6 步、每步 33 毫秒的按键，外加整段的鼠标位移与滚轮；模型可以先写一段推理再动手，局面没变就直接沿用上一步策略。训练用了 1600 小时游玩数据，放出 0.8B、2B、9B、27B 四种规模，每档两份配比——S1 只用 Minecraft，S3 混入其它游戏（Minecraft 占 27%），共 8 个权重，27B 双卡张量并行能跑。仓库给的是推理客户端、系统提示模板、Doom 示例与测试。

商业化价值在“看懂屏幕就直接出手”的通用操作策略，可往 GUI 自动化、回归测试回放、遥操作数据采集上迁移；权重 Apache-2.0，能商用，但训练侧要自己攒数据与流水线。

风险与坑仓库只有推理，没有训练代码，换领域等于从数据开始重做；从游戏画面迁到真实设备的效果没有给出证据；按 200 毫秒块输出，实际可用性取决于本地推理吞吐。

⭐ 50 智能屏显示 固件 商业化 中

定位把一块 3.5 寸的 Guition JC3248W535 开发板（320×480 电容触摸、ESP32-S3、16MB 闪存加 8MB PSRAM）做成桌面触摸控制台。

亮点分页磁贴直接开关与读取 Home Assistant 实体，走局域网 WebSocket，不上云、不要账号；电脑端配一个伴随程序，用 UDP 把实时性能数据推到屏上；还能盯 Bambu Lab 打印机状态。所有配置在设备自带网页门户里完成，桌面 Chrome 或 Edge 插 USB 就能一键刷机并在同一个标签页配好 WiFi。外壳有现成打印模型，状态灯、振动马达与壁纸用的 SD 卡都是可选加装。

商业化几十元的屏加打印外壳，是智能家居中控最省成本的形态，可做整机套件、外壳与预配置服务；MIT 允许闭源出货。

定位面向硬件工程师的 Qt 6 可视化上位机设计器，拖控件、绑数据，导出一个不用编译就能跑的独立应用。

亮点串口、TCP、MQTT 三种数据源在属性面板里直接绑定，Modbus RTU 与 Modbus TCP 采集也在其中；导出不到一秒，目标机器不必装编译器与运行环境；28 种控件，明暗两套主题。工程文件 .uidp 就是 JSON，把格式说明交给编码模型，它能直接写出整套界面工程。兼容 Python 版 PyQt UI Designer 的工程，从旧项目迁过来不用重画。

商业化上位机是设备调试与产线工装的刚需，按席位或按项目卖授权、再配定制控件与私有协议适配，是能直接收到钱的形态；作者已上线官网承接，GPL-3.0 之下闭源分发需要另谈商业授权。

风险与坑GPL-3.0 对闭源出货是硬约束，商用前必须先把授权路径谈清；导出的是桌面程序，跨平台与国产系统适配要逐个验证；0.3.x 的版本号说明接口仍在变，工程文件格式有向后不兼容的可能。

kube32 arterialist/kube32

⭐ 42 服务端配套 固件 商业化 中

定位在 ESP32-S3 上跑一个 Kubernetes 兼容的控制面，集群里的 Pod 是 WebAssembly 模块。

亮点kubectl 与 k9s 隔着 WiFi 或串口直接管一片开发板；实现了 Pod、Node、Namespace、Service、Endpoints、Ingress、Deployment、DaemonSet、Job、ConfigMap、Secret、Lease、Event 等对象，带 watch 流、表格式输出、OpenAPI v3 校验与日志跟踪。Pod 交给 wasm3 解释执行，Rust、C、AssemblyScript 都有 SDK 与模板，带内存上限与每次调用的 gas 预算；有 PSRAM 的板做控制面并跑本地 kubelet，没有的板当工作节点，全集群刷同一份固件。另有主机模拟器、写 flash 或 SD 卡的持久化对象存储、Ingress 路由、Pod 间 HTTP 调用，以及给智能体用的 MCP 服务端。

商业化把云端那套运维习惯搬到单片机集群，对批量部署边缘设备、做教学实验箱、或在设备侧开应用商店的团队有吸引力；Apache-2.0 允许商用，没有额外限制。

风险与坑还在 0.x，没有正式 release，接口会变；单板算力有限，解释执行的 wasm 只适合轻量逻辑；控制面依赖带 PSRAM 的板型，选型被框住；这类“单片机上的编排”更多是演示价值，量产要有具体场景才站得住。
