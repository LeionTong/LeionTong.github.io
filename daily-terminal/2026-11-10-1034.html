ZSWatch ZSWatch/ZSWatch

⭐ 3435 穿戴 固件 + 硬件图纸 商业化 中

定位从零做的 Zephyr 智能手表，38mm 直径的 PCB 与固件同仓开放，v5 板在产、v6 在画。

亮点主控是 nRF5340（u-blox NORA-B10 模块，128MHz 双核、512KB 内存、1MB 闪存），240×240 圆屏带触摸，运动传感器用 BMI270 做手势、抬腕与计步，BMP581 气压计标称 20cm 高度分辨率，另有磁力计、64MB 外部闪存、光照传感器做自动亮度、独立时钟芯片与 I2S 麦克风，电源管理走 nPM1300；硬件全在 KiCad 画，手表、开发板、扩展板、底座的 PCB 各自单独开仓；约 16.8mm 直径的扩展板插在开发板排针上补健康与音频，要扬声器得先有它；99 美元的 WatchDK 开发套件在 Elecrow 卖，芯片与传感器同最终手表一致、体积更大便于调试，电池可选、USB-C 供电；文档站把工具链、写应用、硬件设计的路径写全。

商业化中。图纸、固件、开发套件三件齐备，钱落在套件与整机装配上，软件侧必须开源，差价来自硬件与服务。

风险与坑GPL-3.0 会把整机固件拉进开源义务，闭源出货前要先谈清；NORA-B10、Buydisplay 圆屏、nPM1300 都是小批量难凑的料，配一套要跨几家代理；音频与心率扩展板仍是半成品，扬声器功能不完整；31 个未关闭 issue，v6 硬件一改又要一轮适配。

agentring mutonby/agentring

⭐ 325 语音终端 容器 / Android 应用 商业化 中

定位让编码 Agent 主动给你打电话：任务卡住、需要决策、长活干完时手机像真来电一样响，你在通话里把事情说清楚，转写回到 Agent 继续干。

亮点全自托管，不申请号码也不用 Twilio，通话音频走自建 LiveKit，信令与消息走自写 relay；四件套分工清楚，relay 管配对、消息、推送与通话状态，daemon 跑命令行、MCP 服务器与语音 AI，LiveKit 扛音频，Android 应用负责扫码配对与原生通话界面；语音 AI 只负责说话，脑子仍是你的 Agent，Gemini Live、OpenAI Realtime、Grok Voice、Phonic 与自建服务器都能换；Claude Code、Codex、opencode、OpenClaw 走 MCP 接进来，命令行方式也能在通话里被查问；漏接的电话转成可回复的消息；某个 Agent 答得慢不阻塞通话，答案晚到就按消息送出。

商业化中。给 Agent 加一条能被人打断的语音通道，托管版已经在招客，开源版用来铺信任，收费位置在托管与团队席位。

风险与坑预发布，README 自述只在一台 Pixel 6、Android 16 上测过，iOS 还没有；推送依赖 FCM，国内网络用不了；语音模型与通话中继都要外网；7 个未关闭 issue，接口还在变。

DuckBuddy Animan-AI/DuckBuddy

⭐ 89 桌面机器人 源码 + 3D 件 + 物料清单 商业化 中

定位开源硬件的小鸭机器人，在 Orange Pi Zero 3W 上跑一整套本机服务，会走、会听、会看，还带自己的需求与情绪。

亮点主控换成全志 A733（2×A76 + 6×A55、4GB 内存、3 TOPS 神经网络加速器），舵机用十五只飞特 HL-2915，强化学习步态按这只舵机重训，50Hz 控制，摔倒、过热、低电量、失联都有自动保护；声音侧用 SenseVoice 离线识别，配降噪与人声检测，双麦判断声音方向，叫它一声会转头看你；视觉看人脸与移动物体，扫码连 WiFi，问它「看看这是什么」时交给多模态大模型；生命层管需求、情绪与注意力，把意图交给唯一直接驱动舵机的进程，手柄优先级最高；人设写在一份 JSON 里，换一份就是另一只鸭子；物料清单、组装说明、新手教程与系统镜像都公开。

商业化中。把原版的 Radxa 主控换成国产 Orange Pi、把 Dynamixel 换成飞特，物料与供货都更贴近国内小批量，套件与整机是现成的收费位；Apache-2.0 允许闭源改。

风险与坑Rust 与 Python 多进程混布，系统镜像按 GB 计，刷机走百度网盘；视觉与人脸部分 README 标着实机验证中，步态也只训好基础动作；十五只舵机的装配与标定对新手门槛高；3 个未关闭 issue，无 release。

Physical Hermes RegeneratusLabs/physical-hermes

⭐ 103 桌面机器人 固件 商业化 弱

定位把三十多美元的 ESP32-S3 圆屏语音玩具改成 Hermes Agent 的身体，按住一个键说话，屏幕放它的表情，全部跑在自己机器上。

亮点不用焊接也不用加零件，固件按目录里的 bin 用 esptool 一条命令写进 0x0；板子没有键盘，靠配网页面告诉它 WiFi；之后在同一网段连到自己那台跑着 Hermes Agent 的机器，模型与密钥都留在本地，链路里没有厂商云；圆屏当脸，自带电池，可以离开电脑拿着走；文档把刷机、配网、接入写成三步，连不上时给了按住 boot 键再插线的复位办法。

商业化弱。硬件是 AliExpress 上的公模现货，能收费的部分只有刷机服务与配套固件；对做陪伴类终端的团队，这是成本最低的一次整机验证。

风险与坑仓库没有许可文件，按著作权保留处理，商用要先拿作者书面同意；前提是已有可用的 Hermes Agent 与同网段网络，脱离这个前提就只是个玩具；没有 release 记录，版本以 firmware 目录里的 bin 为准；最近推送停在 2026-10-18，距今已过三周。

Ray-Ban Meta GOD MODE GhanshyamPaunikar/rayban-meta-god-mode

⭐ 31 穿戴 Android 应用 + macOS 端 商业化 弱

定位给 Ray-Ban Meta 眼镜加一个自起唤醒词的助手 CJ，眼镜当麦克风与喇叭，手机当中转，Mac 干活。

亮点走 Meta 的 Wearables Device Access Toolkit 取眼镜的摄像头、麦克风与扬声器；没有自家服务器也没有账户，模型密钥只留在 Mac 上；「Hey Meta」仍归 Meta，「CJ」归它自己，两套唤醒词并存；能叫车、点单、发 WhatsApp、开任意手机应用，凡涉及付款、预订与发送，先把价格读回来等一句「是」；无障碍模式逐字读标牌、标签与信件，认钞票并累加，报药品剂量与有效期；喊一声 help 进五秒倒计时，随后给指定联系人发定位短信再打电话，这段跑在手机上，Mac 连不上也照样用；Mac 侧能开关应用、按键、打字、找文件、读屏；另有二十多种语言的同声传译与边说边记的会议纪要。

商业化弱。踩在 Meta 开放工具包的口子上做应用层，独立开发者能收的是订阅或买断，硬件与唤醒词入口都在 Meta 手里。

风险与坑只支持 Android 10 以上，大脑锁在 macOS，Windows 与 Linux 用户用不了；依赖眼镜侧工具包权限与 Alexa、Uber 等外部集成，条款或接口一变就可能失效；31 星、单人维护，0 个未关闭 issue 说明外部反馈还很少；靠语音确认付款这类动作，误识别的后果由用户承担。
