宗主 Zongzhu Bot Liu-zhongxian/zongzhu-bot

⭐ 240 语音终端 固件 商业化 中

定位ESP32-S3 圆屏开发板加电脑端后端的桌面语音终端，唤醒后把话分流给本机命令或 Grok Bot。

亮点板子只管听和说，屏幕是一对会眨、会跟手、会被摇晕的眼睛，13 种表情实时绘制，触摸、倾斜、摇晃都有反应。本地离线识别走 X-ASR，中英混说能认，热词与识别后纠错把「你好宗猪」改回「你好宗主」。后端按语义分流：放歌、暂停、调音量、下一首在电脑上直接执行，其余交给 Bot 并朗读，断线期间的回复下次连上补发。官网有网页刷机页，微雪 1.75C 与立创实战派 S3 两种板都支持，MIT 许可，93 个 fork，最新 v2.5.2.9。

商业化固件加后端开箱可用，整机、外壳与预配置镜像能直接打包卖，MIT 允许闭源出货，桌面陪伴类产品少见的低成本原型参考。

风险与坑深度绑定 Grok Bot 的账号与接口，上游限流或改协议就影响可用性；点歌依次搜网易云、QQ、酷狗、酷我、咪咕，全是网页接口，改动即失效；界面与唤醒仅中文；开源一天多，长期维护未验证。

ThinkSmart View 语音终端镜像 justhalfbit/thinksmart-ubuntu-image

⭐ 48 语音终端 固件 商业化 弱

定位把联想 ThinkSmart View（CD-18781Y）会议屏刷成开机即进语音界面的系统镜像。

亮点基于 rickx/ubuntu-thinksmart（Ubuntu 24.04 加 postmarketOS 6.19 内核），去掉 Plasma，预装语音客户端与本地网关：客户端管唤醒、对话界面、睡眠时段、亮度与在线更新，网关负责本机识别并接各家大模型与语音合成，带网页管理后台。设备层修掉了两颗麦克风、扬声器、熄屏与接近唤醒、WiFi 稳定性、GPU 白屏卡死。刷机教程按人和 AI 助手两条线写，含 EDL 进法、分区表判断、整盘备份与镜像结构附录，MIT 许可。

商业化这类退市会议屏二手价极低，整套镜像配合刷机与售后是可收费的服务，规模取决于能拿到多少存量机。

风险与坑刷机会清掉原厂 Teams 与 Android，动手前必须整盘备份 eMMC，否则无路可回；只支持这一个型号；镜像上线一天、48 星，社区验证样本还少；界面与唤醒词目前只有中文。

Sonia grigio/sonia-assistant

⭐ 67 语音终端 源码 商业化 弱

定位不需要独立显卡、15GB 内存以内跑起来的全双工本地语音助手。

亮点麦克风常开，回答说到一半可以打断，回声感知能区分附和声与真人插话。轮次判断叠了三层：Silero VAD、静音间隔，再加 Smart Turn 分类器，含糊时用一次 4 token 提示判听还是答。每轮最多 6 次工具调用，闸门按用户原话复核参数，shell 命令分关闭、询问、自动三档；技能目录可指向别处已有的 SKILL.md 包，界面里逐轮开关。前端是浏览器窗口，也有命令行模式，聊天记录落盘可续。GPL-3.0。

商业化价值在把长链路本地语音栈装成一台可交付的终端：迷你主机或开发板加这套服务，做离线会议机、客服应答机与门店导览，按部署与调优收费。

风险与坑语音链路要同时起三个 audio.cpp 服务和一个外置 llama-server，任何一环没起来整个链路就断；语言只测过英语与意大利语；7 个 fork，遇到问题基本靠自己查代码。

版本v0.4.0（2026-10-26）｜ 最近推送 2026-10-26

AsteroidOS AsteroidOS/asteroid

⭐ 1075 穿戴 固件 商业化 中

定位基于 OpenEmbedded、libhybris 与 Qt5 的开源智能手表系统构建工程。

亮点一条 prepare-build.sh 选机型，再 bitbake 出可刷镜像，机型名单里有 TicWatch Pro 3 等量产手表。分层把 BSP、Qt5 界面与手表应用拆开，界面与表盘可以单独替换；官网与 wiki 的移植文档是这套系统最值钱的部分。GPL-2.0，84 个 fork。

商业化给已停产或不再更新的 Wear OS 手表续命是现成需求，刷机服务、机型适配与定制固件都能单独收费，GPL-2.0 要求衍生固件开源，做服务比做产品顺。

风险与坑默认分支 2.0 的最后一次提交停在 2026-06，11-01 的推送来自其他分支，主线节奏慢；整包编译要数小时且吃磁盘；73 个未关闭 issue；libhybris 绕不开原厂 Android 驱动，新机型适配成本高。

Open Health Sync soma-intelligence/open-health-sync

⭐ 57 穿戴 容器 商业化 中

定位自托管的穿戴与健康数据聚合服务，把各家手环、手表、血糖仪的数据收进一个接口。

亮点入口覆盖 Apple Health、Health Connect、Garmin、Oura、WHOOP、Fitbit、Withings、Polar、Strava、Dexcom；出口给 REST、FHIR R4、Open mHealth、签名 webhook、CSV 与 Parquet，另带 MCP 服务端让模型直接读数据。一个 Go 二进制加 Postgres 就能跑，官方写明树莓派也可以，Docker Compose 一条命令起，并能灌 90 天样例数据试接口。AGPL-3.0，9 个 fork。

商业化可穿戴硬件厂商与诊所都需要一层数据接入与归一，按私有部署、接入开发与合规咨询收费有空间；AGPL-3.0 堵住闭源 SaaS 直接套壳。

风险与坑每个入口都依赖厂商 OAuth 与配额，凭据过期要重连，个别平台还会收紧权限；25 个未关闭 issue；健康数据的合规责任落在部署方，跨地区上线要先过本地法规。

版本v0.2.0（2026-10-22）｜ 最近推送 2026-11-01

Stack-chan stack-chan/stack-chan

⭐ 1839 桌面机器人 固件 商业化 中

定位M5Stack 上 JavaScript 驱动的开源桌面小机器人，固件、用户应用、外壳与电路图一起放。

亮点标准配置是 CoreS3，固件用 Moddable SDK 写，用户应用叫 MOD，浏览器里就能刷固件、跑开发工具，不用装 Moddable SDK 或 ESP-IDF。配套整机 K151 在官方店与淘宝在售，遥控器可选。Apache-2.0，244 个 fork，Discord 社区是这类玩具型机器人里最活跃的之一，最新版本 v2.0.1。

商业化硬件已经量产，软件侧的空间在做 MOD、定制表情与动作，以及给展会、门店做互动终端；Apache-2.0 允许闭源分发衍生物。

风险与坑65 个未关闭 issue；刷本仓固件会覆盖出厂固件，想回原厂要用 M5Burner 按厂商流程恢复；CoreS3 只有 8MB PSRAM，复杂应用容易撞内存墙。

版本v2.0.1（2026-10-20）｜ 最近推送 2026-11-01

StackChan 官方开源 m5stack/StackChan

⭐ 1476 桌面机器人 固件 商业化 弱

定位M5Stack 放出的 StackChan 整机资料，含主机固件、遥控器固件、手机 App 与服务端。

亮点主机是 CoreS3：ESP32-S3 双核 240MHz、16MB Flash、8MB PSRAM、2 寸电容触摸屏、0.3MP 相机、九轴 IMU、双麦克风。机身另有两个反馈舵机、12 颗 RGB、三区触摸、红外收发与 NFC。出厂固件带 AI Agent、动画、ESP-NOW 无线遥控与在线应用下载，App 支持视频查看、远程替身操控与 OTA，也能用 Arduino 与 UiFlow2 二次开发。412 个 fork。

商业化厂商自己把整机资料放出来，第三方做配件、外壳与行业二次开发更现实，固件本身没有直接售卖空间。

风险与坑仓库根目录没有许可文件，按保留所有权利处理，不能当成可商用代码分发；官方在 README 里写明仓库更新落后于已发布固件与 App；33 个未关闭 issue；断电状态下强行掰舵机会损坏硬件。
