Anthias Screenly/Anthias

⭐ 3710 智能屏显示 容器 商业化 强

定位树莓派与 PC 上的数字标牌平台，前身是 Screenly OSE：装好系统后由网页后台管理素材、排播与屏幕分组，屏幕那头只负责按时把画面放出来。

亮点2026-10-29 最近推送，最新版本 v2026.10.0（2026-10-16）；3710 星、729 个 fork、57 个未关 issue，是这一细分里活得最久的一支。安装覆盖三条路：balenaOS 镜像可以直接从 balenaHub 或 release 页烧卡，树莓派系统上跑安装脚本，通用 64 位 ARM 单板（Rock Pi、Orange Pi、Banana Pi 之类）走尽力支持，安装脚本会把 Docker 源接进 Debian 系镜像。素材侧支持图片、视频与网页，网页资产在内置 WebView 里渲染。

商业化仓库采用 GPLv2 与商业许可双授权，同一家公司既卖托管版也维护开源版，硬件厂拿开源版做整机白牌、按屏幕数量收管理费，是这条路上已经被验证过的做法；医疗、零售、写字楼电梯口的排播需求都属于可以按点位收钱的买卖。

风险与坑通用 ARM 板上视频是软解，1080p 在慢一点的芯片上会卡，4K 基本别想，硬件视频解码还挂在 issue #2849 里没做；非树莓派的 Plymuth 开机画面起不来，开机过程会露内核日志；GPLv2 加商业双授权意味着改完要分发就得开源，做闭源整机必须单独谈商业条款。

FreeKiosk RushB-fr/freekiosk

⭐ 707 智能屏显示 应用 商业化 中

定位安卓平板的自助机模式：把平板锁成单用途设备，只跑指定网页或应用，拦住返回键、下拉通知与系统设置，适合做点单牌、看板与查询机。

亮点MIT，2026-10-26 最近推送，最新版本 v2.0.0（2026-10-22）；707 星、132 个 fork、68 个未关 issue，装机量已经能撑起问题区。能力比常见的锁屏方案深一层：以设备所有者（Device Owner）身份下发策略，提供 40 多个 REST 接口供外部系统远程改配置、截屏与重启，内置 MQTT 与 Home Assistant 自动发现，能用现成的家居平台托管一整批平板；上架 Google Play，同时给 APK 直装，渠道不锁死。

商业化同类里最有名的是收费的 Fully Kiosk，一套免费 MIT 方案把授权费直接抹平，做门店数字化与展馆集成的团队可以拿它当底座，钱从硬件、安装调试与远程运维的年费里挣。

风险与坑设备所有者模式要在出厂或恢复出厂状态时激活，已经在用的平板得重置一遍，批量部署必须提前规划；各家安卓定制系统对后台存活与自启的限制差别很大，具体机型要一台台验；MIT 只解决代码授权，网页内容与账号安全仍由使用方兜底。

PixelFonts mcer12/PixelFonts

⭐ 276 智能屏显示 源码 商业化 弱

定位手工绘制的窄体点阵字体族，兼容 AdafruitGFX 与 u8g2，专门给分辨率极低的单色小屏用，一行里尽量塞进更多字。

亮点MIT，2026-10-01 创建、2026-10-04 最近推送，四天 276 星；仓库直接给 BDF 源文件、字形素材、C 源码与 Arduino 的 library.properties，拿来就能进工程。每个字体分英文版与扩展拉丁版，后者要配支持 UTF-8 的 AdafruitGFX 分支，英文版省内存；作者还提供了用模型放大字形、拉开像素间距的做法，做复古街机风或者伪造低分辨率效果都能用。已覆盖英语、西班牙语、法语、意大利语、捷克语，重音字符只做了小写。

商业化单个字体文件本身卖不出价钱，价值在于它能把低分辨率屏的可用信息量提上去，做墨水屏标签、仪表盘与手持终端的团队可以省掉排版返工，跟着整机走而不是单独收费。

风险与坑扩展拉丁字形有一批由模型生成，非拉丁语系的覆盖要自己补，中日韩字符完全不在范围内；小屏上一味窄体会牺牲辨识度，老年用户与强光环境要先做实机比对；点阵字体按像素对齐，字号缩放只能整数倍，界面布局得迁就它。

RGB MoCap toyxyz/toyxyz_RGBMocap

⭐ 329 具身 源码 商业化 中

定位Windows 上的原生应用，把普通视频转成可编辑的人体动画：本地跑 ExMR、FlowHMR、GVHMR 三套动作估计模型，做接触修正与人形重定向，最后导出 FBX 或 VMD。

亮点MIT，2026-10-26 创建、2026-10-29 最近推送，四天 329 星、43 个 fork，工程化程度明显高过多数研究仓库：一条 install.cmd 把运行时、Blender、FFmpeg 与原生修正模块装齐，权重在程序里的模型管理器按需下载，附多机位动捕与角色重定向的样例视频；界面同时给视频跟踪与三维预览，输出能直接进 Blender。对人形机器人团队来说，它解决的是训练数据的来路问题——一段手机拍的视频就能变成带关节角度的轨迹。

商业化动作数据的采集成本一直压在具身与动画两条线上，把采集、修正、重定向收进一个桌面工具，可以按席位卖授权，也可以往上游接机器人遥操作与技能学习的数据服务。

风险与坑只跑 Windows，且依赖 Blender、FFmpeg 与几张显卡模型，机器配置低的时候一条视频要等很久；模型权重另外下载，体积与许可要单独确认；单目视频的手臂遮挡与快速旋转仍是硬伤，进机器人训练前必须做一轮数值校验，别直接拿去训策略。

P-BFM Roboparty/P-BFM

⭐ 106 具身 源码 商业化 弱

定位人形机器人的行为基础模型：把动作参考、目标机体状态与奖励函数映射进同一个行为意图空间，策略再把意图与深度感知、朝向与速度指令合起来，输出能适应地形的全身动作。

亮点2026-10-04 创建、2026-10-27 最近推送，106 星、12 个 fork，论文挂在 arXiv:2610.15833 并有项目页与在线试跑。论文里的 G1 实验只用了 40 段平地动作序列加在线地形交互，没喂任何针对地形的示范，这一点是它与常规地形课程学习的区别；仓库同一套算法给了两台机器人的配置，宇树 G1 控制 29 个关节、RoboParty RP1 控制 24 个关节，深度栈尺寸、重定向动作与权重各自独立，不混用；跑在 MJLab 1.4 与 MuJoCo 3.8 上，PyTorch 2.7，训练走八卡，推理给了 ONNX 一致性校验入口。

商业化地形适应与奖励推断这类能力一旦稳定，可以直接变成人形整机厂商的运控软件包，按机型授权；眼下它更像研究资产，离能卖还有距离。

风险与坑许可为 CC BY-NC 4.0，明确禁止商业使用，任何产品化动作都要先谈授权；RP1 那一支只有冒烟测试与 ONNX 对齐，长时训练与真机验证都还空着，作者自己也把状态写清楚了；环境锁在特定版本的 MJLab、MuJoCo 与 PyTorch 上，换版本要重做数值对齐。

EMQX emqx/emqx

⭐ 16869 服务端配套 容器 商业化 强

定位面向物联网的消息中间件，做设备接入与消息路由的底座：海量终端用 MQTT 连上来，平台侧订阅、转发、落库，终端与后端之间不必点对点耦合。

亮点2026-10-30 最近推送，最新版本 6.3.2（2026-10-16）；16869 星、2574 个 fork、269 个未关 issue，Erlang 写的，单集群可撑到千万级连接。协议面比多数同行宽：MQTT 5.0 与 3.1.1/3.1 之外，还支持 MQTT over QUIC、MQTT-SN、CoAP 与 LwM2M 网关，弱网与移动网络切换场景下 QUIC 的连接迁移省掉重连开销；对接 Kafka、数据库与各类后端系统的桥接是标配。从 v5.9.0 起，原来的开源版与企业版功能合并成一份，统一走 BSL 1.1。

商业化BSL 1.1 的写法是四年后转开源、生产环境商用需要商业许可，等于把付费墙立在规模化使用那一步；公司靠企业版订阅、技术支持与托管云收钱，硬件厂接入自家云平台时这套授权模型已经替它把收费口子留好了。

风险与坑BSL 1.1 不是开源许可，做产品前必须读完整条款，把部署形态与营收规模对照一遍；Erlang 运行时对运维团队的门槛高于 Java 与 Go，排障要专门的人；集群规模上来之后的调参与跨机房部署，才是真正的成本所在。

定位跑在边缘设备上的轻量消息中间件：纯 C 写的 MQTT 代理，同时兼做车内与工业现场的消息总线，让网关、工控机与整机自己在本地完成消息分发。

亮点MIT，2026-10-26 最近推送，最新版本 0.25.7（2026-10-21）；2649 星、321 个 fork、55 个未关 issue，是 LF Edge 基金会的项目。实现基于 NNG 的异步 I/O 与 Actor 架构，多线程对多核友好，完整支持 MQTT 3.1.1 与 5.0；资源占用按嵌入式环境调过，POSIX 原生、可移植性好，官方给 Docker 镜像与多平台安装包。它和 EMQX 同属一家公司，云边两侧可以组队用。

商业化MIT 授权对整机厂商最省事，可以直接编进网关固件；公司靠云侧 EMQX 与企业支持挣钱，边缘这层免费换来的是设备端的存在感，做工业网关与车载终端的团队能省掉自己写消息层的工期。

风险与坑版本号还在 0.x，接口与配置项随小版本变动，编进固件前要锁版本；边缘侧功能比云侧窄，集群、规则引擎与大规模设备管理都得靠上游补；嵌入式环境里内存与线程调度要实测，交叉编译到非主流架构需要自己维护工具链。
