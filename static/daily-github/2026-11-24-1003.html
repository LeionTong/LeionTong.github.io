今日视角

编码智能体写得出代码，卡住的地方在写完之后：界面改不动、真机点不到、模型服务散成一堆调用账单、几路会话没人调度。今天这五个项目都在处理这一步，且都把执行留在客户自己的机器或集群里。

UI SDK vercel-labs/ui

⭐ 6,840 · 建仓 29 天，全部落在近 30 天窗口内 TypeScript · Apache-2.0 最近提交 2026-11-23 · @ui-sdk/web@0.1.0-beta.16（11-23）

定位把弹窗、选择、输入提示这类界面行为拆成可组合的原语，让智能体自己拼出组件。

痛点组件库给的是成品，智能体改不动也拼不出新件，生成出来的界面停在截图上像。

付费Apache-2.0 免费，Vercel Labs 出品，本身不收费；钱在平台侧——把智能体做界面这件事接到自家的托管与部署上。

规模化core 一套行为配 React、Vue、Svelte、Solid、Web Components 五套适配，再给智能体一份技能文件。

边际低 · 纯前端库，随 npm 分发，无服务端成本。

验证装库并把技能塞进编码智能体，两条命令：

npm install @ui-sdk/react @ui-sdk/core
npx skills@latest add vercel-labs/ui --skill ui-sdk
风险仍是 beta.16，139 个未关 issue；行为抽象要智能体先理解原语，模型弱一点就退回手写；五套适配的成熟度不一致。

Exact expo/exact

⭐ 4,973 · 建仓 22 天，全部落在近 30 天窗口内 Rust · MIT 最近提交 2026-11-24 · 无 release（pre-1.0）

定位一套源码落在 web、iOS、macOS、Android、Linux 的原生控件上，围着智能体改完就能自己核对的回路设计。

痛点跨平台框架为统一牺牲各平台特性，智能体改完看不到真机效果，验收退回人工点。

付费MIT 免费，Expo 靠 EAS 的构建与更新订阅收钱，框架是进那个订阅的入口。

规模化60 多个一方包覆盖相机、钥匙串、健康、地图、支付；逻辑写 TS 或 Rust；一条 verify 出结构化报告。

边际低 · 框架随仓库分发，构建跑在开发者本机或客户自己的 CI。

验证需要 Rust、Bun 1.4.2 与 Xcode，首次 setup 要拉全套工具链，超过半小时：

git clone https://github.com/expo/exact && cd exact
bun scripts/exact.mjs setup
bun exact.mjs verify
风险pre-1.0 每天在变，没有打包版本与 API 稳定承诺；React Native 与 Flutter 的插件用不了；Windows 与 Android 的完成度还在补。

Argent software-mansion/argent

⭐ 3,231 · 近 30 天未获取到（GitHub 已不提供逐日 star 接口） TypeScript · Apache-2.0（模拟器二进制专有） 最近提交 2026-11-23 · v0.34.0（11-18）

定位MCP 服务加命令行，让编码智能体自己操作 iOS 模拟器、安卓模拟器、电视与桌面应用。

痛点移动端改完要人点开模拟器、截图、复现；设备云按分钟计费，回归靠人工盯。

付费源码 Apache-2.0，模拟器服务等二进制归 Software Mansion 专有；钱来自这家的工程服务，README 还挂着自家广告位，未见产品定价。

规模化一条 init 接进 Claude Code、Codex、Cursor；录一次操作即成 e2e 用例，视觉回归与性能剖析内建。

边际中 · 本地跑模拟器不花服务端钱，但依赖 macOS 与专有二进制，得跟着平台更新。

验证一条命令初始化，工具会自己写进编辑器配置：

npx @swmansion/argent@latest init
风险混合许可，二进制不许反编译与再分发，不能直接打包进自家产品；152 个未关 issue；安卓与电视端弱于 iOS。

SIE superlinked/sie

⭐ 3,538 · 近 30 天未获取到（GitHub 已不提供逐日 star 接口） Python · Apache-2.0 最近提交 2026-11-23 · v0.11.1（11-12）

定位OpenAI 兼容的推理集群，把检索、重排、OCR、字段抽取、内容审核的上百个开源模型装进一套接口。

痛点每个任务一套模型服务，embedding、rerank、PDF 解析各买一份按调用计费的 API，账单与数据边界都散。

付费自托管免费；Superlinked 另卖按调用计费的 Serverless，以及跑在客户集群里、由他们工程师兜底的原生版。

规模化Kubernetes 与 Helm 配置、KEDA 自动伸缩、Grafana 面板齐全，LangChain、LlamaIndex、Dify 直接接。

边际中 · 软件免费，GPU 与运维算客户的，容量规划省不掉。

验证笔记本 CPU 上一条命令起服务，再用 curl 出一次 embedding：

pip install "sie-server[local]" && sie-server serve
curl http://localhost:8080/v1/embeddings -H 'Content-Type: application/json' \
  -d '{"model":"sentence-transformers/all-MiniLM-L6-v2","input":"Hello world"}'
风险0.11.x 小版本迭代；权重首次下载体积大；GPU 镜像按模型族分开，选错镜像就加载不了。

Compozy compozy/compozy

⭐ 2,907 · 近 30 天未获取到（GitHub 已不提供逐日 star 接口） Go · MIT 最近提交 2026-11-24 · v0.7.8（11-22）

定位把 Claude Code、Codex、Cursor 的会话当常驻进程管起来，哪一路等你拍板就排到最前。

痛点几路编码智能体并行，最后是五个终端、提示词发错窗口、谁在等人说不清。

付费MIT 全开源，官网有 357 个插件的市场与桌面端，未见公开价格；付钱的是把智能体编进流程的研发团队，替代自建的调度脚本。

今日首选

SIE（superlinked/sie）。它替掉的是按调用计费的检索、重排与文档解析接口，成本差随调用量直接放大。笔记本上一条命令就能跑出结果，Helm、自动伸缩与面板都在仓库里。同一套代码同时支撑自托管与他们的 serverless，付费路径不用另造。

组合观察

智能体编程的瓶颈从模型能力挪到了环境：界面行为、跨平台构建、模拟器操作、模型服务、会话调度，各被单独重做一遍。付费方式也一致——替代按席位或按调用计费的既有服务，把执行留在客户自己的机器与集群里，供应商收支持、托管与算力差价。
