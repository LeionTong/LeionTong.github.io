Needle 2 cactus-compute/needle

⭐ 10,109 近 30 天 +6,771 Python Apache-2.0 最近提交 2026-09-02 主流

定位14MB 的端侧工具调用模型，28MB 内存跑完一整个会话。

痛点设备端 Agent 现在几乎只能回连云端，延迟、token 费、数据出网三重卡点同时压着。

谁付钱可穿戴、智能家居、机器人与工业边缘设备厂商；省下的是云端 tool-calling 调用费。模型开源免费，可变现的是企业授权 + LoRA 微调与集成交付。

规模化覆盖消费电子、家居、工业、机器人四类场景，交付物就是一个 pip 包加一份权重，可标准化。

边际成本低 —— 纯软件分发，客户自带硬件，无服务端要养。

验证≤30 分钟：

pip install cactus-needle

再按 README 用 @needle.tool 装饰一个函数跑通一次调用 → github.com/cactus-compute/needle#quickstart

风险仓库目前无 GitHub Release（未获取到版本标签）；45M 参数能力边界有限，复杂任务必须靠置信度阈值兜底后上抛云端；CQ2-bit 量化精度损失要在自己场景重测。

VoiceStudio debpalash/VoiceStudio

⭐ 14,860 近 30 天 +5,159 Python AGPL-3.0 v0.5.1 · 2026-08-28 主流

定位全本地的 ElevenLabs 替代，16 个 TTS 引擎 + 11 个 ASR 引擎、646 种语言。

痛点语音克隆与配音按字符计费，且声音样本与文本必须出网。

谁付钱出版、教育、电商、客服、自媒体；直接替代 ElevenLabs 订阅，可变现的是自托管部署与音色定制。

风险AGPL-3.0，若包装成对外 SaaS 需开源衍生代码；仍处 Active beta；引擎多、模型体积大，首启下载慢。

Laminar lmnr-ai/lmnr

⭐ 3,219 近 30 天 +未获取到 TypeScript / Rust Apache-2.0 v0.2.3 · 2026-08-30 YC S24 小众

定位专为 AI Agent 做的开源可观测平台，追踪 + Signals + Evals + 数据集一体。

痛点Agent 上生产之后跑了什么、在哪一步卡死，缺少统一的追踪与评估面。

谁付钱任何把 Agent 上生产的团队；托管云 laminar.sh 收费、自托管免费，对标 LangSmith / Braintrust。

规模化是所有 Agent 团队的通用刚需，SDK 一行接入，不挑框架。

边际成本低 —— 纯软件；自托管要带 ClickHouse 与 Postgres，有一定运维。

验证≤30 分钟：

git clone https://github.com/lmnr-ai/lmnr && cd lmnr && docker compose up -d
# UI: http://localhost:5667

风险版本 0.2.x 未 GA；关键指标与告警需自行配置；托管版定价未公开（未获取到）。

一、今日首选

cactus-compute/needle。它是今天唯一同时满足「边际成本趋零 + 30 分钟可验证 + 客户自带硬件」的标的，且正对端侧与机器人方向。14MB 的体量意味着，验证失败的成本也几乎为零。

二、组合观察

五条里有四条在做同一件事——把原本按月付费的能力搬回自己可控的基础设施：语音（VoiceStudio）、可观测（Laminar）、安全自动化（Tracecat）、知识底座（Utopia）；Needle 则把这条逻辑推到了设备端。

今日信号很清楚：AI 采购的第一理由正在从「模型能力」转向「成本与数据主权」，谁能给出可量化的替代账，谁就容易成交。

三、暂不建议碰

  1. cloudflare/computer（⭐ 8,913，近 30 天 +8,868）— README 明写 PREVIEW ONLY、NOT suitable for production use at this time，API 与架构仍在变，不能作为交付底座。
  2. Agent Skills 合集类（mattpocock/skills ⭐ 245,286；ComposioHQ/awesome-claude-skills ⭐ 74,323）— 纯提示词与技能包集合，无产品形态、无收费模式，复制成本为零，形不成可防守的商业化路径。
