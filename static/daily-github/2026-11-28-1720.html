智能体跑长之后，成本与卡点落在哪

本期收了把交付流程固化成可复用 LOOP 的 LoopForge、按事件派活并只在拍板时找人的 Agent Autoloop、按符号取数的 jCodeMunch、把记忆落成 Markdown 的 memsearch，以及一次前向就给概率的 StartLux 决策模型；共同点是让长跑智能体少花无效 token，多留可核对的卡点。

今日视角

这五项的钱都不落在模型调用上。两项流程工具本身免费，收费落在它们接管的编码命令行与生态；取数与记忆两项靠买断授权和托管索引；StartLux 把判断压成一次前向，卖私有部署。共同压力是长跑智能体烧掉的上下文，以及同一份需求两次跑出不同结果。

LoopForge Tencent/LoopForge

⭐ 6,108 · 近 30 天增量未获取到（11-17 实测 2,599，此后 11 天 +3,509） Go · MIT 最近提交 2026-11-27 · v0.4.3

定位把「让编码智能体交付一个需求」的做法固化成可复用的 LOOP，节点是沙箱、脚本与人工审批，节点之间可以断点续跑。

痛点每次让智能体改代码，跳计划、忘测试、自己审自己；同一个人同一句话两次，产出不一样，也没人知道它停在哪。

付费MIT 自托管，本身不收钱；钱在被它接管的十种编码命令行上——CodeBuddy、Codex、Claude Code、Cursor CLI 等，按席位与 token 走。

规模化跨团队通用，交付物是流程模板加 Docker 沙箱；接一个新仓库只多一个沙箱，不按客户改代码。

边际低 · 纯软件加容器，人审卡点由客户自己的人点，供应方不增人力。

验证三步起一个本地实例，脚本自带 Docker、Compose、Python 与 curl 的检查：

git clone https://github.com/Tencent/LoopForge.git
cd LoopForge
./start.sh
风险508 个未结 issue；LOOP 模板写松了等于没有卡点，产出仍取决于模型的自觉；十种命令行混跑，token 账单集中在一个地方放大，要先配额度。

Agent Autoloop KKKKhazix/agent-autoloop

⭐ 6,743 · 近 30 天 +6,743（11-03 创建，增量即全量） TypeScript · MIT 最近提交 2026-11-28 · v1.10.5

定位事件驱动的智能体中台：定时任务、新提的 issue、业务系统报错都变成标准事件派给命令行 Agent，遇到删数据、停服、花钱这类事才发卡片找人拍板。

痛点人守着终端用 Claude Code、Codex，走开一轮就断；要常驻就得租服务器、开公网端口。

付费MIT 免费，一条命令装在本机；替掉按席位卖的自动化 SaaS 与云端常驻智能体平台的月费。

规模化事件源、Agent、通知通道、上线流水线四个方向都是插件，能接收提示词的命令行工具都能接，团队与个人配置同构。

边际低 · 跑在客户自己的电脑上，等待拍板期间不占进程、不烧 token。

验证装完用本机已登录的 Agent 真实走一遍「提问、退出等回复、拍板、接着干完」：

curl -fsSL https://raw.githubusercontent.com/KKKKhazix/agent-autoloop/main/install.sh | sh
agent-autoloop try
风险断点靠 Agent 的最后一条回复，换模型或换版本可能丢上下文；卡片推到飞书、钉钉、企微要各自配机器人；只有 1 个未结 issue，问题入口窄，用户量也可能还小。

痛点grep 加整文件读把上下文塞满，一次查找大半 token 花在无关代码上，大仓库里这一项就是主要成本。

付费非商用免费；营利公司一次买断授权，官网标价，承诺 30 天不省就退。价格页与许可写在同一个站点上。

边际低 · 装机即用，无服务端、无在线计费。

StartLux-Decision StartLuxLabs/StartLux-Decision

⭐ 1,804 · 近 30 天增量未获取到（10-16 实测 418，此后 43 天 +1,386） Python · Apache-2.0（代码），权重在 Hugging Face 最近提交 2026-11-27 · v1.1.0

定位决策模型族，0.8B 到 27B，给每个选项一次前向出校准概率；把握不到阈值才生成一段短推理，读完再答。

痛点分类、打分、路由这类判断也用大模型全量生成，贵、慢，还同一输入两次不同答案。

验证装引擎、拉 4B AutoThink 权重、起服务：

pip install -e '.[vllm]'
hf download startlux-models/StartLux-Decision-v1.1-4B-AutoThink --local-dir models/StartLux-Decision-v1.1-4B-AutoThink

今日首选

LoopForge（Tencent/LoopForge）。它把一次成功的交付变成可以重复跑的模板，人工卡点写成流程节点，签字这个动作留在人手里。MIT 加 Docker，三十分钟能起，11 天增 3,509 星，是这一轮里少数能立刻拿去用的东西。

组合观察

智能体的成本结构在往读取次数与等待时间上挪：按符号取数、按事件派活、断点等人，都是在削掉无效上下文与空转。开源侧已把这几个环节拆成可插拔内核，收费点退到托管索引与一次性授权，流程工具本身靠生态引流。同一批项目的未结 issue 数都很高，说明用起来之后的麻烦在集成与版本漂移，不在算法。

暂不建议碰

  1. heydamir/unslop（22,781★，CC-BY-4.0，11-15 有提交）：把 AI 味界面改成设计稿的技能规则集，得装在客户端里才有用，没有服务形态与收费位置；CC-BY-4.0 是内容许可，团队要嵌进产品时条款说不清。
  2. zortos293/Lichii（10,388★，GPL-3.0，11-27 有提交）：Switch 2 模拟器，依赖破解固件与游戏本体，法务风险落在使用者身上；热度高，但没有企业买家愿意为它签交付合同。
