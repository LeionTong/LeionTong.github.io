colibri JustVugg/colibri

⭐ 47,267 · 近 30 天 +8,811（star-history 推算） C · Apache-2.0 最近提交 10-31 · 版本 v2.1.0

定位纯 C 写的推理引擎，把 744B 级 MoE 常驻的专家留在内存、其余专家按需从磁盘读，没有显卡也能跑 GLM-5.2、Kimi K3、DeepSeek V4.1 Flash 等十三套引擎。

痛点想用前沿 MoE 只能租多卡或按 token 付费，权重与推理过程都不在自己手里。

付费Apache-2.0 免费，作者只挂打赏。付钱的是替代位——一台 16GB 内存的机器顶掉 API 账单与 GPU 租赁，做私有化交付的集成商按项目收费。

规模化模型族与平台矩阵已铺开，Windows、Linux、macOS，CPU、Vulkan、CUDA 都在支持范围，GGUF 文件可直接读，换模型不换工具链。

边际低 · 代码是文件，推理在客户机器上跑，作者侧不承担算力。

验证git clone https://github.com/JustVugg/colibri && cd colibri && ./start-here.sh，脚本自检内存与磁盘后给出能跑的模型。

风险专家从磁盘流式读取，首 token 延迟高，体验强依赖 SSD 速度；十三套引擎靠单人维护，169 个未关 issue；打赏模式没有商业承诺；量化掉点只有自家基准。

Floci floci-io/floci

⭐ 28,839 · 近 30 天 +1,645（star-history 推算） Java · MIT 最近提交 11-04 · 版本 2.4.0

定位本地 AWS 模拟器，S3、DynamoDB、SQS、Lambda、RDS、EC2 等服务都在 localhost:4566，镜像可直接替换 LocalStack。

痛点开发与 CI 跑集成测试，要么连真云花钱，要么用 LocalStack，多账号、auth token 与功能门禁卡在付费档。

付费MIT 免费，无账号无 token。省下的是 LocalStack 团队席位费与测试期的真云账单；同族还有 Azure、GCP、OCI 三个模拟器。

规模化用 AWS 的后端团队与 CI 流水线通用，Testcontainers 与原生二进制都支持，SDK、Terraform、CDK、OpenTofu 原样指向即用。

边际低 · 单容器或单二进制，没有服务端。

验证docker run -p 4566:4566 floci/floci，或 floci start && eval $(floci env) 后照常跑 aws cli。

风险模拟语义与真云有差距，IAM 策略求值、跨服务事件这类深水区容易漏；170 个未关 issue；四个云分仓维护精力分散；Java 镜像内存占用偏高。

组合观察

被替掉的都是「按量计费 + 厂商托管」这一层：推理的 token、云的请求、地理工具的席位、网页数据的抓取次数。替代件的接口刻意贴着既有客户端做，S3 的 4566 端口、Cloudflare 的 v4 API、各家本地推理端口，换上去多半只改一行地址。定价权正从「用多少付多少」转向「一次装好，自己承担机器」。
