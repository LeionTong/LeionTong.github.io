LeRobot huggingface/lerobot

⭐ 28,914 · 近 30 天未获取到 Python · Apache-2.0 最近提交 11-16 · v0.7.0（11-05）

定位Hugging Face 的机器人学习库，数据集格式、策略训练与真机控制收成一套 Python 接口，从 SO-101 小臂到人形都在支持列表里。

痛点各家机械臂的采集脚本、数据格式与回放工具都不一样，换一台机器要重写一遍，攒下的数据也没法跨团队共用。

付费库本身免费，数据集与策略托管在 Hugging Face Hub，收费落在企业版存储、私有数据集与推理额度上，机构买的是共享数据与托管。

规模化硬件无关的 Robot 接口已成事实标准，OpenArm、LeKiwi、Reachy2 都在原生支持之列；新增一种机器只需实现一个类。

边际低 · 纯 Python 库，托管侧按存储与流量计费，新增用户的交付成本接近零。

验证装完直接列出识别到的硬件与依赖版本，一分钟出结果：

pip install lerobot
lerobot-info
风险974 个 open issue，接口随版本改动；真机调试依赖具体电机与串口，文档偶尔滞后于代码；Hub 上数据集的授权要逐个确认，不能默认可商用。

⭐ 3,710 · 近 30 天未获取到 Apache-2.0 代码 · CERN-OHL-S 硬件 最近提交 11-16

定位7 自由度开源人形臂，双臂整机 6,500 美元，配统一背景与光照的 OpenArm Cell，让接触密集任务的实验能跨机构重复。

痛点做接触密集的操作研究，商用臂贵且闭源，自己搭又缺 CAD、驱动、标定与可比的评测条件。

付费整机按台卖，组装版与 DIY 版都有，官网列认证制造商；软件、固件与 CAD 开源，钱落在硬件与交付上。

规模化同一套 CAD 与固件交给多地认证厂商生产，扩展靠制造商网络，不必自建产线；Cell 场景让实验结果可对照。

边际中 · 硬件按台计，产量上来 BOM 会摊薄，装配与标定仍需人力。

验证MuJoCo 模型装上就能起 Cell 场景，先看动作空间再谈采购：

Copper copper-project/copper-rs

⭐ 1,553 · 近 30 天未获取到 Rust · Apache-2.0 最近提交 11-17 · v1.14.0（11-03）

定位Rust 写的机器人运行时，任务图在编译期定型，跑完可确定性回放；开源核心之外有 Copper PRO 三件付费工具。

痛点时序相关的故障只能在机器上复现，日志与回放对不上，回归测试做不起来，认证材料还得另找人写。

付费Copper PRO 卖 TimeTraveler、Harness 与 Safety，分别对应回放调试、CI 回归与认证证据；核心 Apache-2.0 免费。

规模化航空、汽车、人形、水下与机械臂共用一套运行时，接 ROS 2 走 Zenoh 可渐进迁移；卖的是工具与工程服务。

边际低 · 纯软件，工具授权复制成本为零。

验证脚手架生成一个可跑的工程，几分钟见到运行结果：

cargo install cargo-cunew
cargo cunew hello_copper
cd hello_copper && cargo run
风险Rust 与编译期任务图的学习曲线陡；比 ROS 2 快百倍的延迟数据来自自建基准；团队规模小，PRO 工具未公开报价；静态任务图不适合频繁变更的流程。
