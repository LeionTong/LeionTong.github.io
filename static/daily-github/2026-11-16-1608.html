Kiri libracoder/kiri

⭐ 7,379 · 近 30 天 +7,379（建仓 11-02） Rust · Apache-2.0 最近提交 11-15 · v0.2.1

定位Rust 写的轻量容器运行时，直接应答 Docker Engine API，docker、Compose 与 buildx 原样能用，替的是 Docker Desktop 与 OrbStack。

痛点桌面版容器要按席位买授权，虚拟机常驻吃内存；想把本机起的容器发给同事看一眼，还得另装一条内网穿透。

付费本体免费 beta、Apache-2.0 开源，省掉的是按席位的桌面版授权与穿透工具的月费；公网分享已经挂在 runkiri.cloud 域名下，收费位置留在这里。

规模化三个平台各自一个原生窗口，镜像、Compose 工程与 Kubernetes 集群都在同一个运行时里；迁移只换一个 docker context，脚本不用改。

边际低 · 纯软件，容器跑在用户自己的机器上，服务端只承担分享域名的流量。

验证装上后一条命令起容器，再点分享拿公网链接，两分钟出结果：

docker --context kiri run -d --name web -p 8080:80 nginx
kiri share web
风险0.2.1 仍是 beta，Windows 版走 WSL2 且标注 beta；官网的「快 8 倍」说的是空容器起停，重镜像构建的差距会缩到很小；单一公司维护，135 个 open issue；名字与标识不在授权范围内，分支发行要改名。

HA-MCP homeassistant-ai/ha-mcp

⭐ 7,895 · 近 30 天未获取到 Python · MIT 最近提交 11-16 · 86 个工具

定位把 Home Assistant 的实体、自动化、脚本与仪表盘做成 86 个 MCP 工具，Claude、ChatGPT 这类客户端可以直接读写、排障与批量改配置。

痛点家居自动化难在 YAML 与模板，改错一处整屋自动化一起停；会写的人少，找人配一次按项目收费，事后排障还得再找一次。

付费MIT 免费，靠 GitHub Sponsors；省掉的是按次付费的配置服务与人工排障时间，装成 HACS 集成后跑在 Home Assistant 进程里，不额外占一台机器。

规模化OS、Supervised、Container、Core 四种安装形态功能一致，客户换硬件不用换接入方式；86 个工具按功能分域，接入一套就复用到所有客户端。

边际低 · 纯本地服务，模型侧调用由用户自己的账号与额度承担。

验证先填一个管理员长期令牌，再用 uvx 起服务并接到客户端，问一句客厅有哪些实体：

uvx --python 3.14 ha-mcp@latest
风险默认给的是管理员权限，误改生产配置得靠自己留备份回滚；v7.3.0 把 YAML 编辑挪进 beta 通道，写法还会变；只保证当前稳定版 Home Assistant；同一客户端配两套安装方式会连接挂住，官方专门写了警告。

Mirobody thetahealth/mirobody

⭐ 1,527 · 近 30 天未获取到 Python · Apache-2.0 最近提交 11-16 · v1.6.1

定位把化验单、可穿戴与基因文件统一成 LOINC 编码的健康档案，开放版整套跑在自己机器上，另给智能体一个 MCP 入口查历史与趋势。

痛点同一项指标在不同医院叫不同名字、用不同单位，几年的报告拼不出一条趋势；商业健康应用把完整病历锁在自家云里，换个应用就搬不走。

付费商业版 Theta 按 Pro 订阅收费，官网写 12,000 多用户、1,700 多日活；开源版是它背后的引擎，自建不花钱，等于把订阅拆成能自己跑的一层。

规模化标准化引擎一条命令就能嵌进任意客户端，个人、体检机构与医院用的是同一套编码与解析规则，不需要按机构定制词表。

边际低 · 解析与检索在本地跑，成本是用户自己的机器与模型额度。

验证一条命令把中英日文的指标名归到同一个 LOINC 编码，血脂这种类别词会正确地留在未解析：

uvx --python 3.12 mirobody resolve "LDL cholesterol" 血红蛋白 "Total Kolesterol" 血脂
风险医疗数据的合规责任落在自建方；完整解析报告要另装 parse 组件与模型 key；全本地部署要 Docker 与 16GB 内存；开源版与商业版的功能边界会随版本移动，升级前要核。

OpenStrap Edge OpenStrap/edge

⭐ 930 · 近 30 天未获取到 Dart · AGPL-3.0 最近提交 11-16 · v0.11.3

定位不经厂商服务端读取腕上设备数据的健康应用，WHOOP 4.0、5.0 与 MG 已支持，Android 与 iOS 都能装，除蓝牙之外不留别处。

痛点表带本身卖得不算贵，数据要按月订阅才给看；订阅一停历史记录跟着停，设备还在手腕上，记录却拿不出来。

付费AGPL-3.0 免费，靠捐赠与社区维护；省掉的是每年两百美元量级的会员费，Oura、Garmin、Pebble 这些机型在排期里。

规模化一套 Dart 代码出 Android 与 iOS 两端，新机型接一套蓝牙协议就能进；难处在于每家厂商的协议与固件校验都不一样。

边际中 · 应用本身无服务端开销，但每接一款设备都要逆向一遍蓝牙协议，人力随机型线性增加。

验证取安装包装到手机上、与表带蓝牙配对，五分钟能看到心率与睡眠曲线：

gh release download -R OpenStrap/edge -p "*apk"
adb install *.apk
风险WHOOP 固件 50.43.1.0 与 50.43.2.0 已被下发展期令牌，蓝牙能连但数据被扣住（社区 11 月 9 日核查）；再连一次官方 App 会被升级固件，项目方明确警告别连；AGPL 对二次分发有约束；机型覆盖仍窄。

gputaskman shanselman/gputaskman

⭐ 3,359 · 近 30 天 +3,359（建仓 11-03） Python · MIT 最近提交 11-16 · v0.4.3

定位终端里的显卡进程视图，把每个进程的显存与引擎占用，对上已加载的运行时、模型文件与 KV 缓存分段。

痛点任务管理器只说「用了 15GB」，说不清是权重、KV 缓存、浏览器还是桌面合成器；本机跑推理的人排显存问题只能靠猜。

付费MIT 免费，作者个人项目，没有收费形态；省掉的是排查一次显存占用异常所花的时间，这类排障过去靠反复重启试。

规模化一个 PyPI 包覆盖 Windows、Linux 与 WSL，另有 Apple silicon 版本；本机与远程机器用同一套界面与 JSON 输出。

边际低 · 纯本地采集，无服务端。

验证装上一分钟出界面，也可以只取一次快照：

uv tool install gputaskman
gputaskman --once
风险模型识别与 GGUF 拆分是估算，作者自己标注为实验软件；只覆盖本机 GPU，云端与纯 CPU 在范围外；Windows 需要受支持的驱动，笔记本双显卡切换时数据会跳。

今日首选

Kiri（libracoder/kiri）。装上换一个 docker context 就能验，替掉的是按席位的桌面版授权与穿透工具月费，两笔账当场能算出来。要接受的是 beta 阶段的稳定性与单一维护方，技术团队先在一台机器上并行跑一阵再换默认。

组合观察

五件压的是同一侧：数据与算力留在本机，收费的中间层换成能自己跑的软件。对做硬件的团队，含义是 OS、固件与 App 开源之后，收入位置转到设备本身、B 端席位与托管服务上，靠软件授权收钱的空间在收窄。

暂不建议碰

  1. Source-Robotics/PAROL6-Desktop-robot-arm（3,480★）· 开源桌面六轴机械臂，交付的是 BOM、打印件与装配说明，一台一台装、一台一台调，边际成本降不下来，属于硬件交付而非软件复制。
  2. Zagitta/gpu-unlock（19,765★，建仓 10-29）· 解锁消费级显卡 FP16、BF16 限速的工具，改的是驱动与固件行为，仓库没有授权声明，保修与厂商条款的风险落在使用者一侧，也找不到可持续的收费位置。
