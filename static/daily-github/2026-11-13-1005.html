01

rpi-rgb-led-matrix hzeller/rpi-rgb-led-matrix

⭐ 4,402 · 近 30 天 +44 C++ · GPL-2.0 最近提交 11-12

定位用树莓派 GPIO 直驱 HUB75 接口的 16×32 至 64×64 RGB LED 面板，三条链可并联，PWM 给到 11 位、24 位真彩。

痛点商用 LED 大屏要配厂商发送卡与上位机软件，软件按年授权；店招、展陈、实验室自拼几块面板，买不到这种小体量的配套。

付费库本身不受费，买单方是屏体集成商与展陈工程方；一块 Pi 加几块二手面板就能出货，省掉发送卡硬件与上位机授权，工程按项目计价。

规模化面板型号与链长任意拼，官方给的实测上限是单链 12 块、三链 36 块；同一套代码跨店招、展陈与科研可视化。

边际低 · 纯驱动库，算力与面板都在用户侧。

验证接好 HUB75 转接板，十来分钟能出画面：

git clone https://github.com/hzeller/rpi-rgb-led-matrix && cd rpi-rgb-led-matrix
make -C lib && sudo ./demo -D0 --led-rows=32 --led-cols=64 --led-slowdown-gpio=4
风险GPL-2.0 传染性强，做成闭源产品要随货给源码；Pi 5 的 GPIO 时序与旧款不同，slowdown 与引脚映射都得重调；1,345 个 fork 里多数是抄走改私有，主线只有作者一人；刷新率随链长明显下滑。

Glider Modos-Labs/Glider

⭐ 2,721 · 近 30 天持平 C · CERN-OHL-S-2.0 最近提交 07-11

定位开源墨水屏显示器的硬件设计，含低延迟驱动思路与完整面板资料，成品板卡与整机在 Crowd Supply 预售。

痛点以读写为主的桌面工作要一块不刺眼的屏幕，Dasung、文石这类墨水屏显示器千元美元级，固件封闭、坏了只能返厂。

付费设计文件免费，钱在板卡与整机：Modos Flow 预售价 699 至 799 美元，已筹 59.1 万美元、696 人跟单，价格被真实订单验过。

规模化走标准 13.3 英寸面板，同一套板卡可换尺寸；设计可授权给其他整机厂做白牌，屏体与外壳按需改。

边际中 · 每台要产一块板并要求料，设计文件复制成本为零。

验证板卡到手前先按仓库文档估料，按 USAGE.md 走刷写与显示配置：

git clone https://github.com/Modos-Labs/Glider && cd Glider
less USAGE.md
风险核心是硬件，FPGA 时序代码在另一个仓库 Caster，任一处断供就交不了货；主线四个月没提交；CERN-OHL-S 强互惠，改了设计必须开源；面板型号与贴合工艺受限，无法随便换屏。

Terminus usetrmnl/terminus

⭐ 787 · 近 30 天 +23 Ruby · MIT 最近提交 11-12 · 持续发版

定位TRMNL 官方的自托管服务端，管局域网里的墨水屏设备，发布自家云端 Core 没有的能力。

痛点TRMNL 整机 99 美元一台，看板默认走厂商云；要接内网数据源、要断网也能刷，就得自己在家里架一台服务端。

付费MIT 全开源，钱在硬件；买单方是不让内容出网的团队，省下的是按台的服务与订阅，以及合规评审里那条出网口子。

规模化多组织、多设备、多屏管理，Docker 部署，AMD64 与 ARM64 预制镜像，树莓派部署文档齐备，一套服务端带一片设备。

边际低 · 纯服务端软件，设备只管拉图。

验证两条命令起本地栈，之后写 .env 指到自己的域名：

git clone https://github.com/usetrmnl/terminus && cd terminus
bin/setup docker
风险官方明写 beta，未到 1.0，升级会有破坏性变更；要求 Docker 29.4.2 以上，老环境得先升；Ruby 加 Postgres 加 Sidekiq 的运维不轻；144 个 fork 说明分叉多过主线讨论，文档仍以自家云为准。

ZenLink zenvyzenshiro/zenlink

⭐ 298 · 建仓 11-03 后九天到 298 Rust · GPL-3.0 最近提交 11-12 · v2.5.14

定位把 iPhone、iPad 与安卓画面投到 Windows 的接收端，Rust 原生硬件解码 H.264 与 H.265，安卓侧免装 App。

痛点Windows 上收手机画面，AirServer、Reflector 这类软件按台卖授权；做直播、演示、移动端调试的人每月都在为一次投屏付钱。

付费免费开源，替代的是二十美元级的单机授权；买单方是直播间、培训教室与测试团队，按人头装机就能覆盖。

规模化单个 Windows 程序，绿色版拷过去就跑，苹果与安卓两系都覆盖，走线与无线两种连接方式都在。

边际低 · 纯桌面软件，解码全在本机。

验证下便携版直接开，插上线选设备即出画面：

https://github.com/zenvyzenshiro/zenlink/releases/latest → ZenLink-v2.5.14-Portable.exe
风险建仓九天，单作者，接口与界面还会改；苹果侧走 CoreDevice 与 QuickTime 的逆向协议，iOS 小版本更新就可能打断；GPL-3.0 传染，做成商业产品要开源改动；只出 Windows 版。

esphome-native-hdmi-cec Palakis/esphome-native-hdmi-cec

⭐ 418 · 近 30 天 +13 C++ · ESPHome 许可 最近提交 10-17

定位ESPHome 原生 HDMI-CEC 组件，按 CEC 1.3a 从零实现，让一颗 ESP32 收发电视的开关机、切源与音量指令。

痛点会议室与展厅的屏幕要按场景自动开关与切源，现在靠人拿遥控器；商用 CEC 适配器 48 美元一个，还得挂一台常开主机。

付费组件免费，买单方是弱电与 AV 集成商；几块钱的国产开发板顶掉一个 48 美元的适配器，按点位报价，点位越多差得越多。

规模化CEC 通用于所有带 HDMI 的电视与投影，一份 YAML 改地址与物理地址就能换点位，配 Home Assistant 可直接编排场景。

边际低 · 纯组件，硬件是通用开发板。

验证按文档把 HDMI 13 与 17 脚接到 GPIO，写六行 YAML 后烧录：

hdmi_cec:
  pin: GPIO26
  address: 0xE
  physical_address: 0x4000
  osd_name: "meeting room"
esphome run meeting-room.yaml
风险要自己焊 HDMI 转接板；物理地址靠手填，E-DDC 自动发现还没做，接错就是收不到指令；许可沿用 ESPHome 的双许可，C++ 部分 GPL，闭源固件要单独评估；监控模式开了日志会被总线消息淹没。
