magpie yetone/magpie

⭐ 39,548 · 近一月 +21,794（10-20 为 17,754） Go · MIT 最近提交 2026-11-21 · v0.1.4624（11-21）

定位菜单栏里管模型：一个本地网关把 Claude Code、Codex、Gemini CLI 接到任一家模型上。

痛点每个编码智能体各存一份 key 与 base URL，付过的订阅只在一个工具里能用，额度用尽只能手动搬。

付费应用免费，macOS 签名分发；收入来自 API 网关服务商的赞助，官网挂的几家按牌价六成以下的转售价出货。

规模化一百多个智能体共用一套路由；一个 profile 切换全部工具的模型，桌面、Docker、Termux 读同一份配置。

边际低 · 纯本机进程，推理开销落在用户自己的 key 或订阅上。

验证装好后加一个 provider，把 Claude Code 指到 DeepSeek：

curl -fsSL https://usemagpie.ai/install.sh | sh
magpie provider add deepseek sk-…
magpie claude deepseek/deepseek-v4-pro
风险4,817 个未关 issue；发现已登录的订阅靠读 Keychain 与各智能体配置，隐私开关默认关闭；跨区订阅与多账号轮换踩各家的服务条款，上游一变就要跟着改。

DeepInfer deepseek-ai/DeepInfer

⭐ 26,263 · 近 30 天 +6,410（10-23 为 19,853） Python · Apache-2.0 最近提交 2026-11-19 · 无 release

定位DeepSeek 生产服务在用的推理框架，开源版只放 V4.1-Flash 的离线推理。

痛点MoE 大模型在集群上的显存调度与吞吐靠逐家手调；batch 组成一变结果就漂，评测与对账没法比。

付费Apache-2.0 全开源；值钱的是它背后的 token 服务，云厂商与一体机厂商拿它压每张卡的吞吐成本。

规模化NVIDIA SM100 与昇腾 950 双后端，Attention DP、MoE EP 加 EPLB、异步调度写在同一份配置里。

边际低 · 软件分发，机器与机房在客户侧。

验证要 SM100 或昇腾 950 的机器，消费卡跑不动；编译完跑官方离线示例：

export DEEPINFER_ACCELERATOR=nvidia && ./build.sh && python examples/offline_inference.py
风险只支持一个模型与两代新卡；KV cache、PD 分离、跨副本负载均衡要自己补；验证门槛卡在硬件上，本地三十分钟跑不通。

ManimGX academa-labs/manimgx

⭐ 2,833 · 近 30 天 +740（10-25 为 2,093） Python · MIT（本地轮子含 x264，整体 GPL-3.0） 最近提交 2026-11-16 · PyPI 0.1.1

定位按 Manim CE 的 API 用 Rust 与 wgpu 重写的渲染器，同一份场景脚本出 1080p60 三维动画。

痛点讲解视频靠 ManimCE 逐帧渲，四分钟的片子要渲几分钟到半小时，改一句台词再等一轮。

付费pip 免费；同一团队在 academa.ai 卖「说要讲什么，二十五分钟出节课」的托管服务，引擎就是它。

规模化pip 与 npm 双分发，浏览器里用 Pyodide 跑；课程平台、技术自媒体、教材动画共用一份脚本。

边际低 · 渲在用户机器上；托管版按课时收。

验证装完渲一个三维立方体，看秒数：

pip install manimgx && manimgx render scene.py
风险0.1.1 很早期；带 x264 的本地轮子整体按 GPL-3.0 分发，闭源产品要换掉这段编码；没有可用 GPU 时退到 CPU 软件渲染，速度掉回 ManimCE 量级。

blaze indexable-inc/blaze

⭐ 2,442 · 近 30 天 +2,442（建库 33 天） Rust · MIT 或 Apache-2.0 最近提交 2026-11-19 · v0.20261105.4（11-05）

定位把 cargo 换成 blaze：常驻守护进程把工程留在内存里，改一个函数只重编改动的那部分。

痛点Rust 全量构建几十秒到几分钟，改一行等一轮；CI 上按分钟计费的构建机把这笔账放大。

付费MIT 或 Apache-2.0；YC F26 公司，README 写明在跟几支团队做快速的 Rust CI 与远程构建，早期合作换反馈。

规模化一条命令装，build、test、run、bench 与 cargo 同名；cargo、zed、servo、bun 等真实工程都在 macOS 与 Linux 上验过。

边际中 · 远程构建与 CI 要算力，本地版吃用户自己的机器。

验证装完在任意 Rust 工程改一行再构建，跟 cargo build 对时间：

curl -fsSL https://ix.dev/blaze | sh && blaze build
风险自带一份 2026-10-27 的 Rust 工具链，跟项目 pin 的版本不一致；只覆盖五个 cargo 子命令；Windows 没有安装包；小工程也要吃几 GB 内存。

今日首选

ManimGX（academa-labs/manimgx）。pip 装完一条命令出 1080p60 视频，同一组场景比 ManimCE 快九十倍，改一行的反馈从分钟级压到秒级。做它的团队已经在 academa.ai 用「二十五分钟出一节课」卖它渲出来的东西，工具与付费入口是同一个。兼容 Manim CE 的 API，存量脚本能直接平移。

组合观察

按次付费的环节正在往自有机器上挪：模型入口回到本机网关，推理回到自家机房，动作数据回到一台 Windows 主机，视频渲在自己的显卡上，编译产物留在常驻进程里。开源代码本身都不收钱，收钱的位置在网关分成、托管课时、面向团队的构建服务与动作数据外包，越往上游走越难直接向个人收。

暂不建议碰

  1. Ebony-Vinyl/dsh-our-free-model（82,183★）· 给 DeepSeek Harness 装个插件就能免登录、免 key、不限量调前沿模型，JavaScript，许可自定义且不明。用的是别人的密钥池与配额，上游一封就断，没有收费位置，也没有可交付的东西。
  2. storytold/photocraft（80,751★）· 自称纯 Rust 从零写的照片编辑器，同一账号下的 pdfcraft、filmcraft、lightcraft、vectorcraft 都在 2026-09-30 同一天建库、同一套文案，八万星配一万四千 fork 的比例在成熟项目里罕见。涨星来源没法核，Apache-2.0 之外看不到任何收费位置，先看它能不能撑过三个月的迭代。
