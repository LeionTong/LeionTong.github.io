OpenSEO

every-app/open-seo ⭐ 16,201 本周 +2,625 TypeScript MIT 最近提交 2026-09-02
一句话定位

开源版 Semrush / Ahrefs，自带 MCP 与 Agent Skills。

解决什么痛点

SEO 套件年费高、功能臃肿，中小团队只为 20% 的功能付全价。

谁会付钱 / 怎么收费

官方托管 $10/月 已验证付费；自托管需自带 DataForSEO key 按量计费，第三方可收「代部署 + 代运营」费。

规模化判断

关键词研究 / 排名追踪 / 外链 / 站点审计跨行业通用，Docker 一键交付，可标准化。

边际成本

低。纯软件，API 成本由客户自付，新增客户只多一个容器。

快速验证 · ≤ 30 分钟git clone https://github.com/every-app/open-seo && cd open-seo && docker compose up
（先备 DataForSEO API key，见 docs/DATAFORSEO_API_KEY.md）
风险与坑SEO 数据强依赖 DataForSEO，成本不可绕过；官方 $10/月托管压制独立收费空间。
商业化 规模化 边际成本 验证速度 成熟度 4.6 / 5.0
No.02 · 主流 · 加权 4.3

WeKnora

Tencent/WeKnora ⭐ 21,151 本周 +529 Go MIT（第三方组件除外） 最近提交 2026-09-02
一句话定位

企业级文档 RAG 知识框架，含 ReAct Agent 与自维护 Wiki。

解决什么痛点

企业文档问答要同时搞定解析、切分、检索、权限、审计，自建周期长、商用 SaaS 按席位贵。

谁会付钱 / 怎么收费

制造业、政企、金融的知识库与智能问答预算；本体免费，收费落在私有化部署、数据源对接与调优。

规模化判断

多租户、RBAC、审计日志、IM 与 MCP 接入已内置，文档问答需求跨行业通用。

边际成本

中。纯软件且多租户就绪，但每客户仍需向量库与解析链路的部署调优。

快速验证 · ≤ 30 分钟git clone https://github.com/Tencent/WeKnora && cd WeKnora && docker compose up -d
（按 README「Getting Started」填入模型 API 即可建第一个知识库）
风险与坑644 个 open issue，国产模型与解析后端组合多、坑分散；腾讯自有云产品可能存在边界重叠。
商业化 规模化 边际成本 验证速度 成熟度 4.3 / 5.0

Workweave Router

workweave/router ⭐ 3,553 本周 +2,510 Go Elastic License 2.0 最近提交 2026-09-02
一句话定位

按每个请求路由到最优模型的代理，宣称降 LLM 成本 40–70%。

解决什么痛点

Claude Code / Codex 全面订阅化后账单失控，却没人知道哪些请求该走便宜模型。

谁会付钱 / 怎么收费

AI 编码重度团队与 AI 应用公司，按节省额分成或咨询交付；上游 Weave 已有 Robinhood、PostHog 等客户。

规模化判断

改一个 endpoint 即接入，适配 Anthropic / OpenAI / Gemini 协议，需求跨行业通用。

边际成本

低。Go 单二进制代理，无硬件、无重人力，OTLP 可观测开箱可用。

快速验证 · ≤ 30 分钟npx @workweave/router --claude
（交互式选工具与作用域，自动改写配置；自托管用 --local）
风险与坑ELv2 明确禁止转售托管服务，只能做内部降本或咨询交付；与 OpenRouter、vLLM semantic-router 正面重叠。
商业化 规模化 边际成本 验证速度 成熟度 4.6 / 5.0

AgentField

Agent-Field/agentfield ⭐ 2,545 近 30 天 未获取到 Go Apache-2.0 最近提交 2026-09-01
一句话定位

把 Agent 变成可被任何服务调用的 API 的开源控制平面。

解决什么痛点

Agent 从 demo 走向生产时缺路由、重试、状态、身份、审计，团队只能自己糊胶水代码。

谁会付钱 / 怎么收费

官方提供 Enterprise 版（审计、溯源、组织边界，需预约、无公开价）；第三方可做行业 Agent 底座交付。

规模化判断

Agent 后端属通用基础设施，但需求成立前提是客户已有 Agent，早期需一定集成。

边际成本

中低。控制平面纯软件，但客户环境对接与治理配置仍有实施量。

快速验证 · ≤ 30 分钟curl -fsSL https://agentfield.ai/install.sh | bash
（随后在 Claude Code / Codex 中粘贴 /agentfield Build a claims processor with risk scoring...）
风险与坑版本号仍为 0.1.x-rc，API 不稳定；与 LangGraph、Temporal、Agent 网关赛道拥挤，独立切口在「治理与证明」。
商业化 规模化 边际成本 验证速度 成熟度 4.2 / 5.0
No.05 · 小众 · 加权 4.2

OpenOutreach

eracle/OpenOutreach ⭐ 2,877 近 30 天 未获取到 Python GPL-3.0 最近提交 2026-09-01
一句话定位

自托管 B2B 线索挖掘 Agent，从一句话产品描述到合格线索并发出邮件。

解决什么痛点

Apollo / Clay 订阅加 SDR 人力成本高，多数团队只需要「小批量、高质量、可解释」的线索。

谁会付钱 / 怎么收费

B2B 中小企业的获客预算；可收「线索代运营」月费，模型与邮箱数据 key 由客户自带。

规模化判断

获客需求跨行业通用，但每个客户都要调 ICP 与话术，属轻度定制而非纯标准化。

边际成本

低。软件零成本，但邮箱富化按条计费（BetterContact 1 credit/条），随用量线性增长。

快速验证 · ≤ 30 分钟uv tool install openoutreach && openoutreach find 10
（find 不消耗额度，注册 BetterContact 送 40 credits）
风险与坑GPL-3.0，对外交付需开源改动；仓库创建于 2016-10-07 疑为旧仓改造，且无正式 release。
商业化 规模化 边际成本 验证速度 成熟度 4.2 / 5.0

组合观察 · 今日五仓共同反映的趋势信号

  1. 五条里有四条落在「AI 运行期的成本与治理层」——模型路由、Agent 用量与花费审计、Agent 控制平面、线索获取成本，说明 AI 商业化的主战场已从「能不能做」转向「这笔账划不划算」。
  2. 全部属于「替代已有付费 SaaS」型项目（Semrush/Ahrefs、Glean 类知识库、OpenRouter/E2B、Apollo/Clay），差异化切口不在功能多寡，而在「自带钥匙 + 自托管」带来的成本差与数据主权。
  3. 具身智能与机器人方向当日无合格标的：入榜的要么是论文配套代码与 awesome 清单，要么核心价值必须依赖机器人本体才能验证（如 OpenMind/OM1 的机器人 HAL，2,901★），触发重硬件一票否决。
一句话结论：这一批项目的共同卖点不是「AI 能干什么」，而是「把已经在烧的钱省下来、管起来」。对 TEI 的 C 阶段行业方案而言，成本可量化是拿单最短的话术路径。

暂不建议碰 · 当日高热但不合规

  • tt-a1i/archify（42,403★，本周 +25,469，当日增速第一）——交付物是给编码 Agent 用的 skill 提示词与图表模板，无独立工程化代码、无护城河，fork 一次即同质化，且无收费路径。
  • freestylefly/awesome-gpt-image-2（27,074★，本周 +10,669）——图像提示词模板库，本质是内容集合而非可交付产品，边际成本虽低但商业化清晰度不足。
