LiteLLM BerriAI/litellm

⭐ 58,653 近 30 天 未获取到 Python MIT v1.100.1 · 提交 2026-09-13 主流

定位把 100+ 家 LLM API 统一成 OpenAI 格式的一层网关，自带密钥管理、成本追踪、降级与缓存。

痛点多模型团队被各家 SDK 与账单割裂，按量网关（Portkey/Helicone）按月收费。

谁付钱需要统一模型接入的工程团队；开源核心 MIT 自用免费，企业版（enterprise/ 单独授权）变现。

规模化凡用多模型 API 的团队通用，proxy 接入即标准化，无实施。

边际成本低 —— 纯软件 SDK+网关，无硬件无 GPU，新客户零增量。

验证≤30 分钟：

git clone https://github.com/BerriAI/litellm && cd litellm
docker compose up -d   # 起 :4000 网关；或 pip install "litellm[proxy]" && litellm --test

风险核心 MIT，但 enterprise/ 目录为单独商业授权；多 provider 适配随厂商 API 变动需跟进。

一、今日首选

BerriAI/litellm（加权 5.00）。它把 100+ 家模型 API 收敛成一层网关，直接替代按月计费的模型路由 SaaS，MIT 核心可自托管零成本起，docker 一行即可验证，商业化与成熟度都拉满。

二、组合观察

五条都落在「让 LLM/agent 真正上生产」的环节——接入（网关）、评测（红队）、语音回归、私有运行时、团队共享。共同信号是模型能力本身不再稀缺，收费点在「把模型接稳、测准、跑私有、协同好」这一圈生产基建。
