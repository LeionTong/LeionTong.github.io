Univer dream-num/univer

⭐ 31,977 · 近 30 天增量未获取到（逐日 star 接口不可用） TypeScript · Apache-2.0 核心，商用 SDK 另授权 最近提交 2026-11-26 · v1.6.2（11-25）

定位表格、文档、幻灯片的编辑内核做成 SDK，嵌进自己的产品，不必接 Google Sheets 或 Office 在线版。

痛点SaaS 想做在线表格，自研协同与公式引擎要几年；嵌第三方则按席位付费、数据在别人机房。

付费Freemium 免费带水印（3 个协作连接、每月 10 次无水印导出）；Business 99 美元/月或 1,000 美元/年，单主域含子域，25 个协作连接与 5,000 次导出/月；Enterprise 定制。

规模化按容量授权不按席位，多租户 SaaS 用子域仍是一份许可；图表、透视表、打印、格式转换、协同、Server SDK 与 AI SDK 都在商业版。

边际低 · 客户自托管，许可本地校验，运行期无在线计费与遥测。

验证装 presets，起一个能编辑、能算公式的表格页：

npm i @univerjs/presets @univerjs/preset-sheets-core
# 最小示例与 API
https://docs.univer.ai/guides/sheets/getting-started/quickstart
风险开源核心与商业模块的分界线会移动，升级时可能撞上许可边界；表格内核已有 Luckysheet、OnlyOffice、Handsontable，替换成本落在公式兼容与协同冲突处理。

Chrome DevTools MCP ChromeDevTools/chrome-devtools-mcp

⭐ 59,509 · 近 30 天增量未获取到（本周 +1,175） TypeScript · Apache-2.0 最近提交 2026-11-26 · v1.14.0（11-24）

定位把 Chrome DevTools 交给编码智能体，MCP 服务与命令行两种形态，操作本机真浏览器。

痛点智能体改前端只能靠截图和日志猜，性能与网络问题还得人重开 DevTools 复现。

付费免费，Google 维护，不向使用者收费；收益是把 Chrome 留在智能体的工作流里。

规模化MCP 客户端通用（Claude、Cursor、Copilot、Antigravity），服务与命令行共用一套工具契约。

边际低 · 本机进程，无服务端与租户成本。

验证起服务、接进客户端，让它录一次性能追踪并读网络请求：

npx chrome-devtools-mcp@latest

风险默认上传调用统计（--no-usage-statistics 关），性能工具会把 trace 地址发给 CrUX；只保证 Chrome 与 Chrome for Testing；浏览器自动化 MCP 已拥挤，Playwright 系占位更早，差异化只剩协议层与性能数据。

openset-llm opensetlabs/openset-llm

⭐ 1,742 · 近 30 天 +1,742（11-13 创建，增量即全量） C++ · MIT 最近提交 2026-11-26

定位纯 CPU 的推理引擎，8 GB 内存跑 27B，OpenAI 兼容接口。

痛点私有化场景没有显卡，按 token 买云 API 过不了数据合规，普通 CPU 又跑不动这个尺寸。

付费MIT 无收费层；值钱的是无 GPU 机房的部署与支持，替掉按 token 计费的云推理。

规模化Linux x86-64 加 AVX2 或 AVX-512 的存量服务器直接装，交付是二进制加模型文件。

边际低 · 纯软件，跑在客户已有的机器上。

验证克隆后一条启动脚本，首次构建并下载约 7.3 GB 权重：

git clone https://github.com/opensetlabs/openset-llm && cd openset-llm && ./start
风险上线 14 天、26 个未关 issue，只有 Linux 与 WSL2；官方数字是单用户 8 vCPU 的 17–20 tok/s，并发与长上下文吞吐没有公开压测；指令集分支多，升级要自己回归。

今日首选

Univer（dream-num/univer）。今天只有它把价格与授权口径摊开写：99 美元/月起，按协作连接与导出量算，单主域含子域，自托管且许可本地校验。三十分钟能起一个会算公式的表格页，替换是否成立当场可判。

组合观察

账单单位在变：协作连接、导出次数、团队席位、部署机器、账号本体。五项软件都跑在买方机器上，供应方卖许可或托管；开源核心加商业模块的分层（Univer 的 Apache-2.0 核心、agentes 的 AGPL 加商业授权）成了通用做法。风险同源：分界线会移动，客户升级时可能撞上许可边界。
