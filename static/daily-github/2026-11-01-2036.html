⭐ 48,450 · 近 30 天 +48,450（建仓 10-17，全部落在窗口内） Python · MIT 最近提交 11-01 · 建仓 2026-10-17

定位一段 ADB 流程关掉 Android 电视的预装广告服务与内容行，再装一个 572KB 的原生桌面接管首页。

痛点电视开机先播赞助横幅，厂商内容行与埋点关不掉，换桌面还得先 root。

付费目前只有捐赠入口；钱在电视品牌与代工厂的白标桌面、售后与运营商集采渠道。

规模化407 款机型、106 个品牌、31 种语言，一套禁用清单加一个启动器覆盖各厂改版。

边际低 · 启动器 572KB，脚本跑在用户自己的电脑上，没有服务端。

验证手机装 cleanyour.tv/app 走完连接与分析，或 clone 仓库后让编码助手按 QUICKSTART 提示词执行，约十五分钟（同网段、Python 3、JDK 17-22、Android SDK 34）。

风险只覆盖 Android TV 与 Google TV，三星、LG、Roku、Vizio、VIDA 只能手动关追踪；固件升级后要重跑；连接需要常开 ADB 调试，等于在局域网留一个高权限端口；没有商业主体，企业采购过不了审。

痛点Windows 掌机贵、续航差，Android 掌机的商店里拿不到自己的 PC 游戏库。

痛点直播、客服质检、手游录屏要把手机画面送进 OBS，采集卡加 Mac 的方案贵且占一台机器。

今日首选

iPhoneMirror（RayrenSX/iPhoneMirror）。近 30 天加了一千二百多星，一个 exe 接上 USB 就能在 OBS 里出画面，直播机位与客服质检这两个场景本来就有预算，替代的是采集卡加一台 Mac 的组合。它的短板在协议侧，Apple 私有采集与未签名分发都悬着，接之前先把 iOS 版本与签名方案定下来。

组合观察

屏幕入口层的争夺已经从系统厂商转到第三方软件：电视首页、掌机启动器、投屏接收、阅读器商店，落点都是 ADB、私有协议与运行时兼容。个人侧几乎全免费，能收钱的位置在整机预装、机位授权与渠道分成；机型与协议适配铺得越宽，才有资格进预装谈判。

暂不建议碰

  1. shihabal3amri/DiPlay（13,003★，建仓 09-24，GPL-3.0）· 作者自己在 README 里写明：APK 里打包的是从公开 Carlinkit 固件里提取的实验性配件身份，私钥可被取出，不是为 DiPlay 申请的 MFi 凭证。Apple 一次验证规则变化就能让整条链路失效，拿它做车机方案等于把底座押在别人的开关上；支持范围也只到比亚迪，其余品牌明确不修。
  2. simbasjungles/free-my-tv（5,600★，建仓 10-19，MIT）· 与 Clean Your TV 同题，覆盖 Google TV 与 LG、三星的桌面替换，站点靠捐赠，没有收费层。同类里已经有机型与文档更完整的一份，两份并行只增加维护面与用户分流。
