今日视角

智能体写代码快过任何人读它。要求它自查、要求它少烧 token，这些写在提示词里的约束正在失效，于是被挪到外面，做成钩子、规则引擎、代理和流程图。谁来决定「这活算不算做完」，已经从模型手里转移给外挂的那一层，付费方式也跟着分成按通道、按请求、按席位三种。

Open Code Review alibaba/open-code-review

⭐ 54,183 · 近 30 天未获取到（本周 +3,056） Go · Apache-2.0 最近提交 2026-11-19 · v1.13.12（11-18）

定位把审查拆成两段：任务切分、文件过滤、行号定位、规则路由交给确定性代码，智能体只负责风险判断与上下文追查。

痛点智能体一次交几十个文件，人读不过来；让模型通读整仓，钱花在无关文件上，行号还常指错。

付费Apache-2.0 全免费，价值落在平台团队：可内网接自建模型、按仓库配规则、结果进 CI 与 MCP。官网称阿里内部 19,000 人使用、跑了 300 万次任务，同类改动 token 花费约为 Claude Code 的九分之一。

规模化规则集覆盖多种语言与空指针、线程安全、注入、XSS 等类别；命令、CI、Claude Code 插件、MCP 四种接入共用同一套规则。

边际低 · 单一命令行工具，推理走客户自己的模型 key，服务侧不背成本。

验证装完后配一个模型提供方，在仓库里直接跑一次改动审查：

npm i -g @alibaba-group/open-code-review
ocr config provider
ocr review
风险Apache-2.0 无付费档，变现要集成方自己做；审查质量随所选模型大幅波动，规则误报还需人工压；超大单仓的耗时依赖配置。

Context Mode mksglu/context-mode

⭐ 34,279 · 近 30 天 +232 JavaScript · ELv2 最近提交 2026-11-18 · v2.2.1（11-17）

定位把工具输出挡在上下文窗口外面：命令与网页抓取在本地沙箱里跑，全文进 SQLite 索引，模型只拿到它点名要的那一段。

痛点读文件、跑命令的原始输出动辄几十 KB，窗口一满就触发压缩，前面写下的需求被挤掉，会话越长越贵。

付费插件用 ELv2 免费，托管的 Gateway 订阅收费：免费每月一千次请求，Pro 二十美元一万次，Team 一百美元十万次含两个席位，企业版走年约或自有 Cloudflare；过线请求直接放行到模型，不中断工作。

规模化同一套钩子适配 Claude Code、Codex、Gemini CLI、Qwen Code、OpenCode、Copilot CLI 等十一个智能体，本地插件与网关是同一种协议。

边际低 · 索引与沙箱都落在客户机器上，网关只做转发。

验证加一个市场源再装插件，然后跑一条长输出命令，看回灌的字节数：

claude plugin marketplace add mksglu/context-mode
claude plugin install context-mode@context-mode
风险ELv2 是源码可得许可，拿它对外提供托管服务前要逐条核对；索引存在本机目录，换机要重建；九成九的字节节省取自它自选的 36 行样本，中位数口径偏乐观。

zeroshot the-open-engine/zeroshot

⭐ 2,199 · 近 30 天 +179 Rust · MIT 最近提交 2026-11-18 · v16.1.0（11-18）

定位把开发流程写成引擎强制执行的图：谁写、谁审、什么必须过、失败回到哪一步全由图定，写代码的智能体不能自己宣布完成。

痛点上下文一长，智能体开始忘需求、不再质疑自己的假设，还习惯性说做完了；靠提示词让它自查，收效很有限。

付费本地免费，云侧按通道收：送一条，每多一条每月一百美元；排队任务花五美元买加急，十、二十五、五十、一百份打包，九十天有效，云主机在欧盟。

规模化图存成文件可复用，同一张图换任意命令行智能体与模型都能跑；一条通道一次只跑一个任务，容量算得清。

边际中 · 本地版不花钱，云版每加一条通道就是一份常驻执行位。

验证装好命令行后在自己仓库里让它起一个带审查回环的任务，用界面看进度：

npm i -g @the-open-engine-company/zeroshot
zeroshot ui
风险版本号已到 16 但仍在两千 star 量级；画图比写提示词费脑子，团队得先把流程想清楚；本地跑消耗的是自己那份订阅额度。

roborev kenn-io/roborev

⭐ 1,821 · 近 30 天 +69 Go · MIT 最近提交 2026-11-19 · v0.75.0（11-09）

定位装一个提交后钩子，每次提交在后台起一次审查，问题进台账等人关，不打断当前会话。

痛点智能体一小时能提交几十次，评审却只在 PR 上做一次；等看见问题时，写坏它的那段上下文早已滚出窗口。

付费单个 Go 二进制、MIT、全本地，跑在已有的智能体与订阅上；眼下没有付费档，价值相当于把评审成本从 PR 挪到提交这一格。

规模化自动识别 Codex、Claude Code、Gemini、Copilot、OpenCode 等十二个智能体，任何仓库都能装；结果进终端界面、浏览器界面和事件钩子。

边际低 · 单文件二进制加 SQLite，不起服务端。

验证一条脚本装完，进仓库初始化，提交一次就能在终端界面看到后台审查：

curl -fsSL https://roborev.io/install.sh | bash
cd your-repo && roborev init && roborev tui
风险0.75 版本未到 1.0；提交粒度碎时额度耗得快，得靠批量参数压；无付费档，变现要自己搭。

Prefixwise tejachavali/prefixwise

⭐ 27 · 近 30 天 +27 Python · MIT 最近提交 2026-11-18 · v0.12.1（11-13）

定位架在智能体与模型之间的本地代理，逐条请求指出提示缓存为什么没命中、这一下多花了多少钱，并把常见成因就地修掉。

痛点供应商只报未命中的 token 数，不报原因；系统提示词改动一个字节、工具列表换个顺序，后面全按原价重算。

付费MIT 加 PyPI 包，代理本身不收钱；收费位置清楚，就是按省下来的 token 计价，团队一大账目立刻看得见。

规模化兼容 OpenAI、Anthropic、vLLM、SGLang、LMCache，能认出引擎并自行订阅 KV 事件；可接 CI 当门禁，也能读本机日志免 key 使用。

边际低 · 纯 Python 代理，只存哈希与计数，不落提示词原文。

验证装上后用它包住现有智能体跑一轮，再看会话报告和修复前后对比：

pip install prefixwise
prefixwise run -- claude
风险建仓才两周、27 star，0.12 版本接口会动；只解释缓存命中，任务本身对不对不管；订阅制智能体得走日志导入，覆盖不全。

今日首选

Open Code Review（alibaba/open-code-review）。它把审查里可以确定的部分用代码做掉，只把语义判断留给模型，同时把行号定位和幻觉拦截单列成模块，这种分法直接压低单次审查的 token 与误报。阿里内部十九万人用过、三百万次任务，成熟度不是靠 star 撑的；一条 npm 命令就能在自己的仓库里验真伪。

组合观察

三条在管「谁来核对智能体写出来的东西」，两条在管核对本身的上下文与花销。做法一致：从提示词里搬出来，做成钩子、规则引擎、代理和流程图，让约束不依赖模型的自觉。收费已经开始分化，按通道、按请求、按席位都出现了，最贵的一档是把审查变成必须通过的门禁。
