mobile-agent-testers pierridotite/mobile-agent-testers

⭐ 1,867 · 建仓 9 天，全部落在近 30 天窗口内 Python · MIT 最近提交 2026-11-24 · v0.1.0（11-19）

定位20 个 Claude 智能体各占一台 iOS 模拟器或安卓模拟器，按人格设定把 App 当新用户用一遍并出带截图的缺陷报告。

痛点多机型多语种回归要么买设备云按月按并行数计费，要么人工轮着点，漏掉的常是布局与翻译这类没人写的用例。

付费MIT 免费、模型费自付：官方实测 4 台 0.87 美元、单台 0.15–0.55 美元，替掉的是设备云的并行席位费。

规模化覆盖 Flutter、React Native、Expo、Kotlin、Swift、KMP、Capacitor、MAUI；跑在 GitHub 免费 runner 上，一次二十台。

边际低 · 算力用 Actions 免费额度，成本只剩模型 token。

验证用模板建仓库，脚本配密钥，跑演示工作流（约 20 分钟）：

gh repo create my-testers --public --template pierridotite/mobile-agent-testers --clone
cd my-testers && ./setup.sh
gh workflow run agent-testers.yml
bash scripts/collect.sh <run id>
风险私有仓库的 Actions 分钟数要付费；agent 会误报，报告仍需人复核；模拟器跑不了推送、相机这类真机专有能力。

定位给图像、视频、传感器读数、日志与 ROS bag 做按时间索引的对象存储，写入后按时间范围与标签直接取回。

今日首选

ReductStore（reductstore/reductstore）。五个条目里只有它把收费跑通了：价格页公开、按 GB 计价、100+ 生产部署与 1PB 托管数据都是自己写出来的战绩。它替掉的是时序库、对象存储与自建索引三套系统的组合，客户数据越长越大，账单跟着长，而交付不需要人跟着扩。开源自托管也留着，进可做托管、退可卖离线授权。

组合观察

模拟器授权、外部渗透、设备云席位、远程运维客户端、时序库加对象存储，五笔支出都在被换成本地一次部署。卖点不在算力，而在编排与模式库：681 份披露报告、二十台机型的人格设定、ROS bag 的格式兼容，这些才是别人短期抄不走的部分。反面是护城河薄——替的是通用商品，客户随时可以自建，收费只能落在支持与托管上。

  1. zortos293/Lichii（10,233★，10-31 建仓，今日高热）· Switch 2 模拟器。整类项目靠逆向与密钥提取推进，任天堂的诉讼先例在前，没有可授权的商业路径，仓库随时可能被下架；团队投入越深，法律尾部风险越大。
  2. mjmirza/app-store-compliance（5,898★，今日 +928）· 124 条拒审案例加提交前扫描，需求真实；但授权用自定义的 OpenRoots ORA 2.3（GitHub 识别为 NOASSERTION），商用前得单独确认条款，且价值一次性交付，很难做成订阅。
