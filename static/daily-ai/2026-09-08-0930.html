信号 01 / 终端智能 · 系统级智能体（原生形态冲规模）

华为 HarmonyOS 7 把小艺升级为系统级智能体：感知 200+ 系统数据、调用 2100+ 能力、接入 2000+ 鸿蒙智能体，跨应用跨设备主动执行

终端智能系统级智能体HarmonyOS 7小艺

事件

9 月 7 日华为推出 HarmonyOS 7，把小艺打造为系统级智能体：可感知 200 余项系统数据、调用 2100 余项系统能力，接入 500 多伙伴 Skills 与 2000 多鸿蒙智能体，实现跨应用、跨设备的主动执行任务；星盾安全体系可识别 AI 变声、境外转接等 7 类诈骗剧本，风险检出率超 90%。

为什么值得关注

"系统级智能体"意味着 Agent 不再是一个 App，而是操作系统底座——它直接读写系统状态、统一编排跨应用与跨设备能力，把"原生智能体终端"从单品推到系统生态级。这与努比亚 NaviX Ultra（NO.60/61 的端侧 MCP 跨应用）共同确认：终端原生执行体正成为厂商必争入口。

信号 02 / AI Agent · 流量与入口权力迁移（任务编排接管）

腾讯研究院「Agent 终结互联网免费午餐」+ Cloudflare「AI 流量首超人类」+ 微信小微内测 A2A：平台权力从「入口分发」转向「任务编排」

AI Agent流量接管任务编排A2A

事件

9 月 7 日多条信号共同指向 Agent 对互联网入口的接管：

  • 腾讯研究院发文指出，AI Agent 经济以"任务"替代"流量"为基本单位，非零边际成本正在瓦解传统广告逻辑，平台权力从"入口分发"转向"任务编排"。
  • Cloudflare数据显示，Agent 流量首次超过人类流量，搜索行为大规模转向 AI 消费，内容所有者的旧商业模式正在瓦解。
  • 微信小微内测"小微对话小微"——用户与好友的小微之间可 AI to AI 沟通，代为协调时间、传话，A2A 社交能力亮相。
为什么值得关注

这是 Agent 从"工具"升格为"互联网的新入口"的标志性拐点：当 Agent 流量 > 人类、且 Agent 之间能直接对话（A2A），分发权与编排权就从"人找 App"转移到"Agent 编排任务"。对 B 端而言，未来获客不再靠 App 商店曝光，而靠被 Agent 编排进任务流。

信号 03 / 企业智能体 · ROI 可核算（现金流 + 复购硬账）

迈富时转型企业智能体平台：上半年经营现金流净流入 5 亿、复购 +81%、八大场景落地；智用开物用 PRISM 把工业数字员工 ROI 量化

企业智能体ROI可核算现金流

事件

企业智能体从 NO.61「万级智能体降本（美的 4.5 亿）」再往前，进"现金流 + 复购"的硬账阶段：

  • 迈富时：自 2024 年转向 AI 企业运营智能体系，2026 上半年经营性现金流净流入 5 亿元、复购指标增长 81%，已落地八大智能体场景（营销/客服/供应链等）；某工业企业部署 8 套智能体后销售转化率 +30%、下单时长 -30%，文旅集团新客转化 +25%、销售人效 +43%。
  • 智用开物：在 XAIR Expo 2026 推工业数字员工（GoodCrew 平台），已适配 ICT/高端装备/汽车行业的品控、根因分析等核心岗位，并自研 PRISM 价值评估系统量化 ROI，把 AI 从演示工具变为可管控生产要素。
为什么值得关注

"现金流 + 复购 +81%"比"降本 4.5 亿"更硬——它证明企业智能体不只是成本项，而是能形成可持续收入与续费的生产要素。PRISM 这类价值评估系统则把"AI 有没有用"从乙方话术变成甲方可审计的账。

信号 04 / 终端智能 · 端侧算力底座（存算一体下云）

后摩智能 M50 存算一体芯片量产：10W 功耗、单芯片 122B 参数，落地 Agent Computer / AI PC / 具身智能 / 边缘推理——把大模型推理从云端搬下端侧

终端智能端侧算力存算一体M50

事件

后摩智能 M50 存算一体芯片（2026 年 2 月量产）典型功耗仅 10W、单芯片最高支持 122B 参数大模型，落地 Agent Computer、AI PC、具身智能、边缘推理四大方向；搭载 M50 的中国移动全光融合终端 Promax 支持 120B 模型本地运行，某商业综合体消控室改造项目半年内可回收投资。

为什么值得关注

"10W + 单芯片 122B"直接击中端侧 AI 的不可能三角（性能/功耗/成本）——它让终端原生智能体不必每件小事都回云端，断网也能跑、数据不出本机算力底座，也让具身智能的"端侧小脑"有了可量产候选。

信号 05 / AI Coding · 复杂工作流自治（computer-use 后台办复杂活）

GPT-6 Astra Agent 化推理（computer-use / 浏览器 / 软件工程 / 多步工作流）+ 阿里千问办公多人工作台：coding 与 agent 从「协助写」进「后台自主办」

AI Codingcomputer-use工作流Astra

事件

coding 与 agent 的边界进一步融合，从"帮你写代码"进"后台自主办多步复杂任务"：

  • GPT-6 Astra（OpenAI，9/8 券商解读）：能力重心落在 computer-use、浏览器操作、软件工程与多步骤专业工作流，可在后台调用桌面环境完成多步任务并产出文档、表格、演示文稿；其"非 GPU 工作负载"（工具调用/代码沙箱/浏览器渲染/文件处理/任务编排）随 agent 会话数线性放大，直接抬升 CPU 与服务器需求。
  • 阿里千问办公：上线多人协作能力，用户描述需求即可生成支持百人在线协作的网页，具备角色权限、云端数据库与管理后台，适用于活动组织与企业协作——coding 从个人写码变成"自然语言生成可协作应用"。
为什么值得关注

computer-use + 多步工作流让 Agent 不再停在"生成代码"，而是占有桌面与浏览器、自主办完整任务——这把 AI Coding 的战场从 IDE 扩到整个操作系统。同时 Astra 揭示一个被忽视的算力结构变化：agent 化推理把大量负载推回通用 CPU/内存。
