01 AI AGENTIDC DAA · 商业化拐点

WAIC 定调"Agent 工业化元年"，模型退居二线

事件

WAIC 2026 上智能体展示密度显著高于往届，几乎每家展台均布局智能体方案。IDC 预发布《DAA 研究报告》：全球日活智能体（Daily Active Agents）由 2025 年 2860 万升至 2026 年 7940 万，2030 年预计达 22.16 亿——该指标由李彦宏提出，意在衡量"每天有多少智能体真正进入业务流程、完成任务并创造价值"。

落地路径集中爆发：蚂蚁 Agentar 2.0（近 200 个岗位级数字专家模板）、腾讯 WorkBuddy（拖拽搭助理）、阶跃（长期记忆 + 自主规划）、商汤 SenseNova U1 Pro（交付级原生多模态智能体基座）。商业化讨论趋务实——腾讯云吴运声明确不按任务计费，主张拆分流程压缩 Token；阿里云李飞飞提出智能体架构须与底层模型解耦、自主匹配最优模型。

为什么值得关注

这是行业拐点的明确信号：竞争终点从"更大的模型 / 更高跑分"转向"更快量产可用的智能体"。DAA 取代参数规模成为新的时代度量衡，未来 1–2 年 AI 公司的价值锚点将从"模型能力秀"转向"可规模化的真实交付能力"。"能否进厂干活"比"榜单排名"更具投资与选型参考价值。

理性提示：IDC 数据为预测值；"Agent 工厂"仍是早期形态，岗位模板的跨企业泛化与复用率尚无大规模验证。

02 AI AGENTAgent 支付 · 确责

Agent 支付落地，"机器管钱"进入确责阶段

事件

多智能体协同开始打通真实支付链路：阶跃 × 支付宝系统级合作，一句话跨 App 完成充电、外卖下单；蚂蚁展示 HOP 高阶智能体架构 3.0（密态计算 + 结构化任务语言）；寻汇 Sunrate × 万事达卡发布 B2B 行业首份《AI 智能体全球支付白皮书》，提出跨境支付跃迁至第三阶段"自主化"。

核心考题浮出：当 Agent 掌管资金，安全、合规、责任溯源成为规模化前提。从业者反复提及"人机协同"与"责任可溯"——每笔交易从指令、授权边界、推理过程到风控节点均需留存审计记录，事后可像回放录像一样还原事实。

为什么值得关注

这是 Agent 从"信息助手"跨入"资金执行"的第一个规模化垂直场景，也是"信任 / 问责机制决定能否规模化"的典型样本。越是高价值、高敏感的业务环节，越不取决于模型多强，而取决于能否建立可审计、可确责的协作底座。谁先建立 Agent 商务的可信基础设施，谁就掌握高价值 B 端入口。

理性提示：多位 CTO 强调"AI 是辅助、非替代决策"，高风险交易仍需人工复核；确责链路标准尚未行业统一，"机器管钱"离完全自主仍有合规边界。

03 终端 · 端侧智能体手机 · 端侧模型

端侧模型 + 智能体手机集体亮相，"Agent 原生系统"争夺战开启

事件

监管与产业双线推进：7/15 网信办首次将"手机端侧生成式 AI 服务"单列公告（苹果、华为、OPPO、vivo、小米、三星、努比亚 7 款备案）。WAIC 三款 AI Agent 手机同台——努比亚 NaviX Ultra（端侧大模型 + GUI Agent，MCP/A2A）、阶跃 STEPX Neo（全球首款大模型原生智能体手机，Step AOS 系统级重构，已过 L3 测试）、荣耀 Robot Phone（四自由度机械云台，Agent 操作物理世界）。

端侧模型能力跃升：面壁 MiniCPM5-2B（AA 榜 4B 以下首位，9 款芯片 Day0 适配，将开源）、阶跃 Step Edge 全家桶（本地 toolcall 低至 0.1 秒）、Google 开放 Gemini Nano 3（端侧 Function Calling）。

为什么值得关注

终端是 Agent 真正"长在用户身边"的入口。三条路线（外挂 GUI Agent / 系统级 Agent OS / 物理形态重构）正面交锋，叠加监管单列与端侧模型跃升，2026 年被视作"端侧算力、模型能力、制度确认、市场需求四条件首次同时到位"的窗口期。手机正从"交互入口"变为"具备行动能力的终端"。

理性提示：三款手机路线分化明显、尚非终局；努比亚依赖 App 后台、阶跃需自建伙伴体系（首批无微信）、荣耀偏物理交互。能否跑通可持续利益分配（App 广告收入被削减的冲突）仍是未知数，部分机型发售要到 10 月下旬。

04 具身智能部署态元年

具身智能"部署态元年"——从炫技到进厂干活

事件

WAIC 具身智能超 200 家企业、近 60 台人形机器人"上岗"干活（非摆拍）：智元 × 京东物流精灵 G2 Max 已在真实仓储 24 小时搬运码垛；智元彭志辉预判人形机器人全年出货超 10 万台"可能性较高"。千寻 Moz1 现场"整理客厅"可抗干扰动态规划；云深处 DR02 完成技术验证并启动商用投放；腾讯发布三大具身基座模型 + 智能体 Apexio / TairosAgent，打通"感知—身体—行动"闭环。

为什么值得关注

衡量标准已从"能不能动"转向"能不能持续、大批量在真实场景干活"，标志具身智能越过演示门槛、进入生产力阶段。更深层变化在成本结构：灵心巧手展示"灵巧手组装灵巧手"全自动产线，探索"机器人自己生产自己"，一旦批量落地将从根本上改写产业的成本与扩张逻辑。

理性提示："部署态"多为点状验证，跨场景泛化与大规模可靠性仍需时间；10 万台为预判非既定目标；To B 真实产线 7×24 稳定性是下一阶段硬指标。

05 具身智能基础设施 · OS 层

全球首个多形态机器人协同训练物理 AI 操作系统（松应 ORCA OS）

事件

松应科技在 WAIC 发布全球首个多形态机器人协同训练的物理 AI 操作系统 ORCA OS，首次实现人形、四足、无人机等异构智能体在同一数字工厂协同训练与任务执行，呈现"陆空全域协同"，打通从数字训练到真机部署的闭环。同期复旦可信具身智能研究院构建"真机部署—数据飞轮—模型训练"链路，自研视触觉传感器（指尖约 4 万感知点 / cm²）与首个支持精细化操作的视触融合具身大模型，已落地车灯精密装配。

为什么值得关注

具身智能的竞争维度正从"单机本体 / 单项技能"扩展到场景理解、任务编排、跨设备通信、协同决策与系统能力。ORCA OS 这类"操作系统"层是规模化部署的关键基础设施——没有统一调度与多智能体协作底座，单台机器人再强也无法进入复杂工业流程。具身智能将像云计算一样走向"底层 OS + 上层应用"的分层格局。

理性提示：多形态协同目前多在仿真 / 受控场景验证，真机跨厂商、跨任务稳定协同仍处早期；"操作系统"标准尚未收敛，存在多家并行定义的风险。
