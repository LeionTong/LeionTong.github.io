信号 01 / 具身 · 世界模型底座（补大脑）

李飞飞 World Labs 发布 Atlas 全模态世界模型：单图生成 1 分钟 1440P 视频，物理规律驱动——补具身智能「大脑」的世界理解底座

具身智能世界模型补大脑Atlas

事件

李飞飞创立的 World Labs 正式发布 Atlas 全模态世界模型，实现从单张静态图像生成 1 分钟 1440P 高清动态视频；模型基于物理世界规律训练，生成画面遵循光影、重力、物体运动逻辑，长时序稳定性与场景连贯性大幅提升，无需多段拼接即可输出完整一分钟高质量视频，覆盖影视创作、数字孪生、机器人仿真等场景。

为什么值得关注

世界模型是具身智能「大脑」的底层——它让机器人在真实落地前，先在一个可物理推演的世界里做长时序想象与规划。Atlas 把世界模型的长时序生成能力从"秒级"推到"分钟级 + 1440P + 物理一致"，意味着仿真到落地的训练基建又补了一块关键拼图。

信号 02 / AI Coding · 基础设施/协议层（控制面）

DeepSeek 开源 Harness（全插件化、可 delegate 给 Claude Code/Codex）+ Zed Delta + MCP 改 stateless + Agent Plugins 标准：coding agent 竞争下沉到「harness/协议」控制面

AI Coding开源控制面Harness

事件

9 月 Radar 显示 coding agent 的"控制面"密集演进，从"模型/工具"下沉到"harness/协议"：

  • DeepSeek 开源 Harness：其 agent harness 几乎一切皆插件、极度灵活，可对接多模型，并能在内部把工作 delegate 给 Claude Code 与 Codex——把"自有 coding 底座"变成可本地搭的开源件。
  • Zed Delta：面向"与 agent 协作编码"的 multiplayer 环境，重新定义 Git/GitHub——核心洞察是"关于代码的对话"与源码同等重要，必须和源码一起被捕获留存。
  • MCP 更新：把 Model Context Protocol 改为 stateless，解决大规模采用的关键障碍之一（状态管理）。
  • Agent Plugins 标准：用可复用组件扩展 agent 的插件标准，获 OpenAI、Microsoft、Cursor、AWS 支持（Google/Anthropic 未加入）。
为什么值得关注

coding agent 的护城河从「谁模型强」转向「谁能统一编排、插件化、跨模型代理」——harness 是控制面，协议（MCP stateless / Agent Plugins）是互操作地基。开源 Harness 让企业能本地搭"自有 coding 底座"，不再绑死单一厂商模型。

终端智能终端扩散MCPHome Agent

事件

智能体终端从"手机"一种形态扩散到更多原生硬件，且普遍把 MCP 作为跨应用协议：

  • 绿联 Home Agent：在 WorkBuddy 生态发布会中亮相，主打本地数据 + AI Agent 协同（家庭/私有云场景），产品预计 10 月众筹，目标定位高于 AI NAS。
  • 阿里 Qoder 眼镜版：9/3 宣布上线，首批接入千问与乐奇 AI 眼镜，用户戴镜即可通过语音让 Agent 执行任务；完整功能将于 2026 云栖大会发布。
  • 努比亚 NaviX Ultra（豆包手机二代）：9 月正式开售，大模型 Agent 深度集成进系统底层，核心运算支持本地端侧运行、采用 MCP 应用协议与第三方应用对接，跨应用任务执行成功率 80%+。
为什么值得关注

智能体终端的外延被拓宽：从手机到 NAS（本地数据中枢）/ 眼镜（自然交互）/ 家电（场景执行），共同范式是"端侧算力 + 本地数据 + MCP 跨应用执行"。MCP 正从"Agent 互联协议"变成"终端跨应用协议"——谁定义终端侧的 MCP 接入规范，谁占入口。
