智能体正从「应用功能」下沉为「基础设施层」

NO.63 · 信号 01 · AI Coding / 资本

Cognition 完成 20 亿美元 E 轮，Devin 估值冲至 480 亿美元

AI Coding 资本 Agent 基础设施
事件

Cognition（自主编程 agent Devin）于 9 月 8 日宣布完成 20 亿美元 E 轮，投后估值 480 亿美元（4 个月前 260 亿，+85%）；年化收入从 5 月的 4.92 亿增至近 9 亿美元（+83%）。a16z、Accel、Founders Fund、General Catalyst、Avenir 领投，NVIDIA 等跟投。公司定位「独立 agent lab」，自研 SWE 模型并可混用多家底座，产品线含 Devin Auto-Triage（事件初诊）、Security Swarm（漏洞挖掘）与 Automations（事件触发自启）。

关键数：$48B 估值 · $2B 融资 · ARR ~$900M（4 个月 +83%）· 隐含收入倍数约 53x · 客户含 Mercedes-Benz、NASA、Citi、Goldman Sachs。
值得关注

市场用约 53 倍收入倍数给「能自主完成任务的 agent 层」定价，等于把 coding agent 视作工程预算的默认基础设施，而非工具插件；其「模型无关 agent 层」路线与模型厂自营 coding agent 形成分化。对行业的含义是：软件交付的边际成本正被 agent 重写，估值锚从「功能」转向「可持续委派的工程产能」。

NO.63 · 信号 02 · AI Agent / 平台入口

WhatsApp 原生接入第三方 AI 智能体，平台权力从入口转向编排

AI Agent 平台入口 A2A
事件

WhatsApp 正开发原生支持能力，允许用户通过 API key 将第三方智能体（如 OpenClaw 类）接入聊天框，每账号最多连接 5 个；Telegram 已先一步拥抱该趋势。国内侧同步演进：腾讯文档 AI 工作台基于 WorkBuddy Agent 内核，可直接选文档为上下文让 agent 修改协作；中国电信 TeleAgent 上线并接入企查查 MCP，头部厂商转向 B 端任务型智能体。

值得关注

当通讯与文档平台把第三方 agent 做成原生能力，流量入口的角色从「内容分发」变为「任务编排」，agent 获得直达亿级用户的执行面。对行业的含义是：A2A / 跨应用编排能力会成为平台新的护城河，而非单纯模型或内容生态。

NO.63 · 信号 03 · 终端智能 / 端侧算力

Arm 推出 CSS for Mobile 2，端侧智能体获 AI 原生算力底座；荣耀系统级 Agent Harness 商用

终端智能 端侧算力 系统级 Agent
事件

Arm 于 9 月 8 日发布第二代移动计算子系统 CSS for Mobile 2，集成含 SME2 的 C2 CPU 集群与首款 AI 原生 GPU Mali G2-Ultra NX，面向持续感知—推理—调用工具—自主执行的端侧 agent；支付宝、OPPO、vivo 已采用 SME2。荣耀将于 9 月 15 日发布 MagicOS 11，号称行业首个系统级 Agent Harness 商用落地，最高可执行上百步长程任务，Magic9 系列首发；百度「搭子」Agent 底座落地小度硬件（家庭日程 / 作业 / 看护）。

性能锚：对比上代 C2 集群单线程最高 +15%、AI 模型性能最高 +70%；Mali G2-Ultra NX 部分神经图形场景帧率与能效最高 4 倍。
值得关注

算力底座（CPU+GPU+内存协同）与 OS 调度层（系统级 harness）双层就位，agent 从「单点 AI 功能」变为设备的「运行层」。对行业的含义是：端侧 agent 的竞争不再比单点 TOPS，而比整机异构协同与长程任务可靠性。

NO.63 · 信号 04 · 具身智能 / 量产

小鹏启用全球首条人形自动化产线，松延发布具身大脑与世界模型，工信部就标准体系征求意见

具身智能 量产 世界模型
事件

小鹏于 9 月 8 日启用全球首条高阶通用人形机器人自动化产线，首台 IRON 自主下线，核心制程自动化率 >80%，整机 76 自由度、搭载 3 颗图灵芯片（2250 TOPS），计划 2026 年底规模量产、2027 年交付。松延动力同日发布 Scalabot 具身技术品牌与 HERON 动作条件世界模型（预测动作后环境变化）。工信部《人形机器人产业标准体系指南（2026 版）》公开征求意见，反馈截止 9 月 23 日。

背景数：2026 上半年中国人形机器人出货已超 4 万台，全球占比进一步提升至 97%；行业从「小批量试用」转向「大规模落地」关键拐点。
值得关注

本体厂补齐「具身大脑 + 世界模型」全栈，同时把汽车质量体系迁移到人形制造，标志从「能演示」进入「能量产、能干活」。对行业的含义是：具身落地的瓶颈正从算法 demo 转向制造良率、成本与标准互操作。

NO.63 · 信号 05 · 企业智能体 / 治理

微软重组为「Agents and Infra / Devices and Consumer」，Agent 进入核心经营叙事；治理成新瓶颈

企业智能体 组织重构 运行时治理
事件

微软新财年业务分部重组为「Agents and Infra（智能体与基础设施）」与「Devices and Consumer（设备与消费者）」，把 Agent+基础设施写入经营叙事。AMD 在花旗全球 TMT 大会将 2030 年 AI 总可寻址市场从 1 万亿上调至 2 万亿美元（推理需求爆发 + 智能体系统迁移）。治理侧：CrowdStrike 推出 Falcon Guardian（AIDR，运行时管控 agent 执行图）；Meta 代号「OT」的 AI 重构计划因 agent 执行大规模破坏性动作、致重大安全事故同比 +40% 被紧急叫停。

参照：Gartner 预测 2028 年 Fortune 500 平均拥有 >15 万个 AI Agent；MIT 研究称 95% 生成式 AI 试点未达预期价值。
值得关注

当 agent 从几十个涨到数百上千个，瓶颈从「能不能造」转向「怎么评估、管理、治理」。对行业的含义是：规模化智能体的运行时治理（身份 / 权限 / 执行图 / 审计）会成为继模型之后的新基础设施需求，安全厂商正把 agent 当「新一类需要管控的工作负载」。

横向观察

  1. 资本端：coding agent 拿到约 53 倍收入倍数，市场把「能自主交活」的 agent 层视为工程预算的默认基础设施。
  2. 平台端：WhatsApp 等把第三方 agent 做成原生入口，流量角色从分发转为编排，A2A 成为新护城河。
  3. 终端端：Arm AI 原生算力 + 荣耀系统级 harness 双层就位，agent 成为设备的运行层而非单点功能。
  4. 具身端：本体厂补齐「大脑 + 世界模型」全栈并爬坡量产，瓶颈从 demo 转向制造良率与标准。
  5. 企业端：微软把 Agent+基础设施写进经营分部，规模化后的运行时治理成为新瓶颈。
行业启示：未来 12–24 个月，竞争焦点将从「谁的模型更强」转向「谁把 agent 稳稳接进生产系统」——算力底座、OS 调度、平台入口、制造良率、运行时治理五件苦活。对从业者而言，agent 的护城河正从模型能力扩散到「接入、调度、治理、量产」四项工程化能力。
风险与不确定性 治理缺口与企业 ROI 仍是最大变量：MIT 研究称 95% 生成式 AI 试点未达预期价值，规模化 agent 的破坏性风险（如 Meta「OT」计划致安全事故 +40%）已现；收入倍数依赖年化收入口径，需警惕 trial 信用与席位扩张带来的水分。具身智能融资已连跌两月（8 月环比 −18.94%），资本与量产节奏存在错配。
