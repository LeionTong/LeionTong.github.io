01AI Agent · 平台化

美团 CatPaw 全场景 Agent 平台上线：3 万 Agent 已嵌进 9 万人的生产流程

// event

7/27 美团正式对外发布全场景 AI Agent 平台 CatPaw，提供移动 App + PC 客户端及企业级开发托管。官方披露：已覆盖 9 万员工、累计 3 万个 Agent，日处理超 2.4 亿次真实业务请求。

形态：双端协同（移动发起/远程确认，PC 本地深度执行）、云端 7×24 长程任务、专家广场+技能库（对话式封装工作流、录屏成技能）、跨会话长期记忆；安全上运行环境严格隔离、凭证集中托管（Agent 零接触敏感资产）、分级权限与私有化部署。

值得关注 ▸ 目前国内「Agent 平台化、组织级落地」最完整公开样本。它把早班「Agent 从工具走向可信实体」主线，从「安全/可控」补到「规模化/可治理」——当 Agent 成为日活 9 万人的生产资料，权限分级、凭证托管、可审计已是上线前提，而非加分项。
信源：美团官方 + IT之家/腾讯新闻/三言科技（一级·厂商披露）
02终端 · 端侧 Multi-Agent

OPPO 小布 Next 开放内测：行业首个端侧 Multi-Agent 协同，主打「主动智能」

// event

7/27 OPPO 启动「小布 Next 计划」，开放行业首个 端侧 Multi-Agent 协同系统：端侧全域记忆、上下文理解/规划/调度本地完成；基于「全时意图感知引擎」主动判断何时提醒/提前准备（运动时收紧急邮件→主动草拟回复，用户只需确认）。

多 Agent 独立记忆/技能/上下文，兼容第三方 Agent/Skill/MCP（瑞幸、印象笔记、飞猪、美团 MCP）；关键操作「只做准备、不替用户决定」，必要时经 PCC 安全链路调云端。同场还有 腾讯 WorkBuddy 鸿蒙 PC 版上线（鸿蒙首个桌面办公智能体，全终端+碰一碰）。

值得关注 ▸ 把早班「终端 Agent 越过提示词工程」的战线从桌面/CLI 拉到手机端侧：端侧＝数据不出本机更私密，但模型要在更小算力上跑 Multi-Agent 编排。其「主动智能」与 Anthropic「更强模型更少手把手」异曲同工——Agent 该主动，关键决策权必须留人。
信源：OPPO 官方 + 网易智能/腾讯新闻（一级·厂商披露，内测阶段）
03具身 · 中试与量产

人民日报头条：机器人迎中试「考场」；小鹏进量产联调、特斯拉 Optimus 推迟但炮轰「剧本式演示」

// event

国家级中试基地（7/27 人民日报第 08 版）：杭州高新区国家人工智能应用中试基地（具身智能）5 月挂牌，算力+数据+模型+场景一体化公共服务平台，近 30 家企业入驻，并引入机器人保险（本体险+第三者责任险）。痛点直指：单台人形机器人需 1–2 名采集员，一个动作需成千上万真实动作投喂，数据有效率不足 50%。

小鹏（7/27）：人形机器人广州工厂小批量生产、量产产线最后联调，量产倒计时。特斯拉 Optimus（7/27 财报会）：马斯克称量产「史上最难」，产线改建推迟至年底，并炮轰行业「剧本式演示」，强调端到端+纯视觉 FSD 复用。

值得关注 ▸ 这几条拼出「具身卡在中试→量产前夜」：人民日报点出最硬骨头——数据飞轮/场景验证/风险兜底工程化；小鹏（抢窗口）与特斯拉（示警难度）呈两端张力。与早班「世界模型＝物理直觉」互补：共识在脑子，落地在产线与中试线。
信源：人民日报（权威一手）、网易科技/新浪（媒体转述·厂商口径）
04AI Agent · 基础设施安全

MCP 新规范明日（7/28）企业级化发布：协议层堵洞，但安全责任彻底甩给开发者

// event

MCP 2026-07-28 规范将正式发布，最大架构演进：有状态→无状态企业级，引入应用托管状态、富交互 UI、长时异步任务，OAuth 2.1 升一等公民。协议层消除会话劫持/主动推送/弱认证三大风险——但安全边界构建责任 100% 转移给开发者。

同期警报密集：NSA 已发 MCP 硬化指南；Amazon Q VS Code 扩展 CVSS 8.5 自动执行漏洞（开恶意仓库即远程执行、窃 AWS 凭证）；ShareLock 阈值投毒（拆分指令避检测，成功率>90%）；Agentjacking 伪造 Sentry 事件诱使编码 Agent 执行命令（~85%）。

值得关注 ▸ 早班锁「OpenCode 可远程删机」「OpenAI×HF 失控」单点失控；本条拉到协议层——MCP 已成 Agent 连工具/数据事实标准，但「工具表面」正成最易被武器化攻击面。7/28 是企业级部署分水岭：协议不再兜底，零信任/输出校验/显式授权成必答题。
信源：Akamai 安全研究 + Adversa.ai 月度汇总 + NSA 指南（一级·安全研究）
05终端 · 模型底座

Kimi K3 全量开源：2.8 万亿参数 / 百万上下文，把终端 CLI Agent 成本打到地板

// event

7/27 月之暗面将旗舰模型 Kimi K3 完整权重全量开源：2.8 万亿参数、100 万 token 上下文、综合评测全球第三，API 定价约海外高端模型 1/3。已与 Kimi Code CLI（7/18 开源、MIT、免费）形成「模型+终端 Agent」组合拳——支持屏幕录制拖入对话当输入、/coder /explore /plan 子代理并行、对话式配置 MCP。

值得关注 ▸ 终端 Agent 护城河早班已指出从「提示词」移向「接口/交互」；本条第补一层——底座开源与降价正把本地跑强 Agent 的经济门槛砍到极低。当 2.8 万亿可免费自部署、百万上下文成默认，竞争将转向「谁把模型编排成好用的本地工作流」。与 ② 端侧、④ MCP 安全恰成「强底座+本地编排+安全协议」拼图。
信源：月之暗面官方 + GitHub AI 日报（一级·厂商披露）
