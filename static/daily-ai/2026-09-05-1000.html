信号 01 / AI Coding · 降本（tokenomics）

Claude Fable 5.1 缓存读取价 -75%、Muse Spark 1.3 工具调用 -20%、Gemini 3.8 Flash 发布：长时域 coding agent 的成本从「烧钱」变「可规模」

AI Coding降本tokenomicsFable 5.1

事件

9/3 各家密集把 coding agent 的单位成本往下推，核心是把长时域、多轮、高缓存场景的价格打下来：

  • Anthropic：发 Claude Fable 5.1，输入输出价不变，缓存读取价从每百万 token $1 降至 $0.25（-75%），典型任务整体成本降约 25%、高度 Agent 化任务最高降 45%；同期基准翻倍并在生产级安全护栏开启下评测。同模型拆出 Mythos 5.1，仅向可信网络安全/生命科学伙伴开放——"能力—护栏"解耦。
  • Meta：发 Muse Spark 1.3 编程智能体，同等任务工具调用次数 -20%、输出 Token -25%，面向企业级批量代码开发。
  • Google：发 Gemini 3.8 Flash + Gemini 3.8 Flash Cyber，保持 3.7 Flash 促销价（输入/输出 $0.75/$3.75 每百万 token），强化软件工程/Agent/多步推理；Flash Cyber 内部漏洞发现成功率 >70%、CWE-Bench Pass@1 47.2%。
为什么值得关注

长时域 agent（常驻、跨会话、反复读上下文）的最大瓶颈不是能力，是token 账单。缓存读取 -75% 直接把"agent 跑一整天"从烧钱变可负担，tokenomics 成为 coding agent 能否真正铺开的决定性工程题。Mythos 把前沿能力走可信伙伴白名单，预示"能力解锁"将与"安全可信"挂钩。

AI Agent组网底座WorkBuddy

事件

9/2 两件事把 agent 的竞争位从「单个好用的工具」抬到「能组网的平台」：

  • 腾讯 WorkBuddy 开放平台（open.WorkBuddy.cn）正式上线，首批引入超百家生态伙伴，打通硬件/应用/开发者三层生态，开放 Skill/Expert/Connector 能力；Connector 支持 MCP 与 CLI 双方案双向接入，定位"Aget 底座"，统一管理上下文、记忆与任务状态，解决单点/场景/供给/产业四类割裂。
  • 阿里云「万有无界」开启公测：企业/个人可注册，调用最新 Qwen3.8-Max；定位多角色 Agent 协作工作台——把复杂任务拆解给不同职责的 Agent，在「项目空间」组织成员与资产，通过群聊让多位 Agent 围绕同一任务接力推进，产出沉淀到资产库成为企业可复用数字资产。
为什么值得关注

生态位从「工具」转向「底座/平台」：谁能统一管上下文、记忆、任务状态、连接器，谁就占据 agent 经济的入口。MCP+CLI 双向接入意味着"模型无关 + 既有系统可接"，直接对标 NO.59 信号 02 的「多 Agent 工作台 + 私有化」控制面。

agent 不再只活在软件：开始有专属硬件形态（Codex Micro）与跨企业交易网络（NextB2B 的 A2A/ATP）。"终端原生可执行体 + agent 经济协议"初成，呼应 NO.59 信号 04 的「端侧闭环」但更进一步——不只是一台手机，而是一台专用 agent 终端 + 企业间自动交易。
