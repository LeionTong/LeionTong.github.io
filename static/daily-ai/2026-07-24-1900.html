AI 领域每日动态 Daily AI Brief — 智能体走向"可信商业实体"的一天

AI AGENT终端·端侧具身智能

今日摘要 / TL;DR

今天的三条 Agent 主线在回答同一个问题：当智能体开始"以企业名义花钱、管流程、对外签约"，靠什么让人相信它、管得住它、追得了责？ 国标给身份、Visa 给支付信任协议、OpenAI 给企业级护栏与人工复核——三件事从不同层面补"可信"这块短板。与此同时，DeepSeek V4 稳定版今日上线、旧接口今日强制停用，把"百万上下文 + Agent 专项优化 + 国产算力适配 + 约闭源 1/8 价格"推向可规模部署，直接压低 Agent 与端侧推理的成本底线。需要清醒：标准与支付跑通的是"单笔/单场景"，距离承接复杂企业采购、跨国多智能体协作仍有距离；开源≠好用，价格低≠总拥有成本低。

01AI Agent

国内首套 AI 智能体互联国家标准 GB/Z185-2026 发布

据同花顺 7/24 综叙、中关村发布，中关村发布 GB/Z185-2026 七项智能体互联指导性国家标准，被报道为"全球首个系统性智能体互联标准体系"。核心设计：为每一个 AI 智能体分配唯一数字身份码，打通不同厂商智能体"孤岛"，实现跨平台可信协同；现场完成 2000 余个行业智能体身份首批发放，标准外文版本同步推进对外输出。

为什么值得关注
  • 把"智能体互操作"从企业私有协议（如各家 MCP/A2A）抬升到国家指导性标准层面，给跨厂商、跨平台协作提供身份与协议底座。
  • 未来"可信智能体身份"可能成为招投标与集成的硬门槛。
客观提示
  • 该信息目前主要来自财经媒体综叙，"全球首个"为信源表述；GB/Z 为指导性国家标准（非强制），实际约束力、落地节奏与跨厂商采纳度仍待观察，不宜高估短期产业影响。
02AI Agent

Visa×连连完成大中华区首笔 B2B 智能体真实交易

据腾讯新闻 7/24，Visa 与连连数字宣布，由连连 AI 智能体 LoopXPay 执行的首笔真实 B2B 智能体交易完成，系大中华区公开披露的首笔。流程上，LoopXPay 在单一工作流内完成供应商寻源、方案比较、下单与支付，全程运行在企业预设的支出控制与审批参数内。LoopXPay 已注册进入 Visa 可信智能体名录（Agentic Directory），并配合 Visa 可信智能体协议（Trusted Agent Protocol） 提供身份、透明度与支出控制机制。

为什么值得关注
  • 这是 Agentic Commerce 从"推荐/比价"走到"真正付款"的硬证据——智能体开始以企业名义调动资金，支付关注点转向"它是谁、能花多少、谁负责"。
  • 与 7/22 关注的"蚂蚁 Agentar 区块链补信任"同源：行业正用身份登记 + 协议约束 + 名录审计三件套解决自主交易的"信任/确责"难题。
客观提示
  • 公开信息未披露交易金额、品类、支付工具及人工确认节点；单笔跑通不等于能承接含合同、验收、发票、跨境合规的复杂 B2B 采购，机制仍处早期，复制成本暂无法判断。
03AI Agent

OpenAI 发布 Presence 企业级智能体管理平台

据 OpenAI 官方 7/22、环球网/钛媒体 7/23 发酵，OpenAI 推出 Presence——将 AI 智能体与企业内部数据、现有软件和工作流连接的企业级平台，覆盖客服、销售、IT 工单、理赔等场景，支持语音与聊天。提供政策管控（Guardrails）、人工审核、模拟测试与自动评分；Codex 驱动的持续改进会就生产信号提出更新建议，经版本对比后由人工批准受控上线。已在 BBVA、SoftBank 等试点，OpenAI 自身客服验证 75% 诉求由 AI 独立闭环。部署不走自助开通，须由 OpenAI 工程团队或授权集成商实施（有限 GA）。

为什么值得关注
  • 标志 OpenAI 从"卖模型 API"向"卖企业软件/高触达工程服务"战略转身，直接对标 Salesforce/Oracle；在模型商品化背景下，是其抢"Agent 落地最后一公里"的关键拼图（呼应 5 月 ODC 与 1.5 亿伙伴网络）。
  • "护栏先行 + 人工复核 + 受控灰度"的工程范式，是规模化部署 Agent 的稳妥样板，对国内企业级 Agent 产品有方法论借鉴价值。
客观提示
  • Presence 目前非自助产品、交付重度依赖 OpenAI 工程团队，服务能力与生态规模是短板；"75% 独立闭环"为 OpenAI 自身客服场景数字，跨行业泛化性不可直接外推。
04终端·边缘算力

力箭一号一箭五星，多颗星载 AI 试验卫星入轨

据同花顺 7/24 早间综叙，力箭一号遥十五一箭五星发射成功，多颗卫星搭载国产 GPU 与在轨 AI 推理系统，开展空间碎片 AI 识别、太空算力验证、高光谱影像星上实时解译，推进"算力上天、在轨跑模型"技术路线落地。

为什么值得关注
  • 把"端侧/边缘 AI"的边界推到太空——在轨实时推理意味着模型不必回传地面、星上即可完成识别与解译，是极端边缘"感知-决策本地化"的极致形态，与面壁 MiniCPM-Robot 的"纯无网部署"思路一脉相通。
  • 推理载荷轻量化、低功耗、抗辐照的共性技术，会反哺地面机器人/车载端侧的本地智能。
客观提示
  • 属试验验证性质，距离业务化遥感/在轨训练尚有距离；对民用 Agent/具身的直接拉动短期有限，更多是技术储备与路线信号。
05基础设施·模型

DeepSeek V4 稳定版今日上线，旧接口今日强制停用

据 DeepSeek 官方及多家媒体 7/24，DeepSeek-V4 稳定版（含 V4-Pro 1.6T 参数、V4-Flash 2840 亿参数两档）于 7/24 上线；旧 API 名 deepseek-chat、deepseek-reasoner 于 7/24 15:59 UTC 永久停用，无宽限期。两档均原生 1M（百万 token）上下文、支持思考模式；V4 对 Claude Code、OpenClaw、OpenCode、CodeBuddy 等主流 Agent 产品做专项适配，并适配华为昇腾（脱离 CUDA）。定价约闭源 1/8（V4-Flash 输出 $0.28/百万 token、V4-Pro $0.87/百万 token，据 theneuralfeed / freeai.help 整理）。

为什么值得关注
  • 长上下文 + Agent 专项优化 + 国产算力适配 + 低价叠加，直接压低"多轮长程 Agent 工作流"与"端侧/本地部署"的成本与门槛——对做 Agent 产品。
  • "开源超级周"（DeepSeek V4 7/24、Kimi K3 7/27 开源权重）被多家分析称为史上最密集开源周，国产开源模型在成本与性能上快速逼近闭源前沿。
客观提示
  • 迁移有"隐性降档"陷阱——deepseek-reasoner 当前指向 V4-Flash 思考模式而非 V4-Pro，直接改名会导致推理质量静默下降，须显式切到 V4-Pro 并改用 thinking 参数；价格低≠总拥有成本低，企业需重估路由策略与 Pro/Flash 配比。
