L1AI Agent · 产业定调 一级信源 · 观点判断

腾讯研究院：「智联网」轮廓显现——网络主体从人扩展到 Agent，价值尺度从流量转向任务完成率

事件

7 月 30 日时代财经·未来趋势大会上，腾讯研究院前沿科技研究中心主任王强系统提出：①网络行动主体正从「人」扩展到「人 + Agent」——Agent 可搜索、调 API、与其他 Agent 通信、获授权后完成交易；②衡量网络价值的尺度从流量转向任务完成率；③平台核心能力从页面/商品分发转向模型、工具、服务与 Agent 的调度；④互联网从「注意力经济」走向「意图经济」。一个以 Agent 为新主体的「智联网」正显露轮廓。

为何值得关注

这是国内大厂研究机构对「Agent 之后的互联网」最系统的一次公开定调——当任务完成率取代流量，SEO、推荐位、开屏广告的商业地基都要重估。需冷静处：这是研究判断而非已发生事实，衍生传播的「8 亿 Agent 活跃」等数字未经核实、已剔除；但「分发 → 调度」的平台迁移，已被本周三大厂办公 Agent 收口所印证。

L2终端与端侧 · 算力底座 官方一级 · 高

高通今日完成收购 Modular：39 亿美元买下「跨芯片 AI 软件栈」，Lattner 出任 AI 软件 EVP

事件

高通 7 月 30 日官宣完成对 Modular 的收购（6/24 签约，约 39.2 亿美元全股票）。Modular 由 LLVM/Swift 之父 Chris Lattner 与 TensorFlow Lite 联合创造者 Tim Davis 创立，统一平台让 AI 负载跨 CPU/GPU/NPU/定制 ASIC 运行、无需为每种芯片重写代码；约 150 人团队全部并入，Mojo/MAX/Modular Cloud 延续，Lattner 就任高级 AI 软件与平台执行副总裁，定位「从边缘到云」的生成式与智能体 AI。

为何值得关注

端侧 Agent 算力格局的结构性补课：高通硬件强、软件生态弱是老短板，CUDA 锁定是全行业的痛；买下「中立软件层」后，端侧/边缘开发者第一次有机会「一次开发、跨芯片部署」。与本日午班此芯 P1 对照——中美同日在「端侧 AI 算力底座」各落一子。签约是 6 月旧闻，今日交割完成、组织到位才是新事实：软件栈整合从承诺变成执行。

L3AI Agent 工程 · 可恢复性 二级聚合 · 中高

斯坦福开源 Shepherd：「意图」与「执行」分离，Agent 出错可优雅回滚不必重跑

事件

斯坦福 7 月 30 日开源 Shepherd 框架：元 Agent 在执行动作前先记录意图，将「意图」与「执行」分离，出错时按意图记录回滚、无需清空环境重跑。同日工程信号共振：生产级 Agent 的重试状态随容器回收丢失——带副作用的工具调用必须持久化到对话循环之外；Andrew Ng 发 12 页多智能体设计笔记（四模式）；Claude Cowork 实测自主运行 2 小时、调度约 70 个子 Agent 交付完整 MCP server。

为何值得关注

Agent 工程的下一个关键词是可恢复性（recoverability）。午后班已证明「写在文档里的规则不是控制」（HANDBOOK.md 最佳 36.2%），Shepherd 给出结构性答案：不求 Agent 不犯错，而是让系统在犯错后可撤销——意图日志之于 Agent，恰如 WAL 之于数据库。当一次自主跑 2 小时、70 个子任务成为常态，「错一步毁全局」的框架将被有回滚能力的框架淘汰。数据库四十年前解决过同款问题，Agent 工程正在重新发明事务与回滚——这次带着自然语言的模糊性。

L4具身智能 · 仿真底座 一级发布 + 二级转述 · 中高

NVIDIA SIGGRAPH 双发：Cosmos 3 世界模型（含端侧实时推理）+ Isaac Sim 6.0 支持 3DGS；李飞飞同日强调「仿真补数据」

事件

NVIDIA 于 SIGGRAPH 发布 Cosmos 3 世界模型家族，Cosmos 3 Edge 支持设备端实时推理并配套 Dreams 模拟；Isaac Sim 6.0+ 新增 3D Gaussian Splatting（单 prim 上限 1677 万点），真实场景扫描可直接变仿真训练场。李飞飞同日访谈强调：具身真实数据远远不足，仿真是必经之路。另有 Anthropic 实测：让 Claude 直接驱动机器人关节失败，但作为「监督者」调用简单工具则可完成任务。

为何值得关注

Cosmos 3 Edge 把世界模型从云端训练推向端侧实时推理——恰是 7/30 早班七部门路标「端侧世界模型工具链」的美方镜像，中美在「把物理直觉装进机器人本体」上罕见同向。3DGS 入 Isaac Sim 把「扫描现实 → 生成训练场」的成本打下来，与「仿真补数据」互为因果。Anthropic 的失败实验同样有价值：划清 LLM 在具身栈里的边界（规划可以、控制不行）——知道自己不能干什么，是具身 Agent 落地的前提。

L4+具身 / Robotaxi · 出海与信任 二级聚合 · 中高

萝卜快跑在中国香港机场岛启动全球首个「右舵左行」全无人测试；Waymo 停摆两月后恢复高速运营

事件

百度萝卜快跑 7 月 30 日在中国香港机场岛启动全无人（无安全员）测试——全球 Robotaxi 首次在「右舵左行」交通体系下全无人运营测试，并与 Uber、Freenow 推进伦敦布局。同日 Waymo 因施工车道事故停摆两个月后恢复高速公路运营（60 mph），预测市场对其坦帕/拉斯维加斯扩张预期高企。

为何值得关注

Robotaxi 是具身智能中唯一已规模化商业运营的形态。中国系统首次攻克「右舵左行」出海硬门槛——右舵市场约占全球汽车保有量三成，中国香港正是通往英国、日本、东南亚的试验场；Waymo「停摆两月再恢复」则演示了自动驾驶的真实节奏——一次事故足以冻结所有扩张，恢复靠审查而非公关。与早班 FCC 禁令同理：技术出海的门槛从来不只是技术，还有交规、监管与信任的本地化。

横向观察 · 今日三句话
