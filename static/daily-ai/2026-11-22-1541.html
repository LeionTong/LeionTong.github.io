NO.01 · 前沿模型 · 编程与电脑操作

OpenAI 发布 GPT-6.2 Astra 与 Sol，Astra 的输入输出价格降两成

高难度专业任务较上一代提升 5.2 个百分点，成本不到三分之一Sol 在 FrontierCode 2.0 上距 Astra 0.5 分，成本约五分之一缓存输入价格下调六成，两款均进入 Codex 与 ChatGPT Work
事件简述

11 月 22 日，OpenAI 发布 GPT-6.2 Astra 与 GPT-6.2 Sol。Astra 面向高难度项目，在 Agents' Last Exam 上比 GPT-6 Astra 高 5.2 个百分点、成本不到三分之一，比 Claude Fable 5.2 高 5.5 个百分点、成本为对方的 5%；Terminal-Bench-Science 0.1 提升 9 个百分点，Vals Science Index 刷新纪录，Artificial Analysis 综合智能指数 62 分，较前代提升 5 分。API 价格为输入每百万 token 8 美元、缓存输入 0.40 美元、输出 40 美元，比上一代低两成，缓存部分降六成。Sol 维持 GPT-6.1 Sol 的价格（输入 2 美元、输出 10 美元），在 Cognition 的 FrontierCode 2.0 上距 Astra 仅 0.5 分、成本约五分之一，OpenAI 称内部许多员工已把它当作默认模型。两款已在 ChatGPT Work、Codex 与 API 上线。Hacker News 同日的讨论帖称两款模型在 SimpleBench 上的得分不及前代。

关注理由

定价下移改变的是高难度任务的成本结构，长程编程与电脑操作的单位成本随之下降，团队在 Codex、Claude Code 与第三方智能体之间分配预算时需要重新算一遍。

Sol 与旗舰的差距压到半分，模型选型从取最强一款变成按任务分层路由，智能体运行时把模型路由当常规配置会更普遍。

官方公布的成绩集中在专业任务与科研工作流，社区在常识推理基准上的复测没有同步改善，两类评测的分歧提示能力提升并不均匀。

NO.02 · 开放权重 · 私有部署

腾讯开放 Hy4 全部权重，770B 多模态模型可放进自有环境部署

770B 总参数、49B 激活，上下文 1Minstruct、FP8 与预训练三个版本一并放出，附系统卡同系列 Hy4-flash 为 220B 总参数、12B 激活
事件简述

11 月 20 日，腾讯混元在 GitHub、Hugging Face、ModelScope 与 GitCode 开放 Hy4 全量权重，此前 11 月 4 日只提供 API。Hy4 是原生多模态的混合专家模型，总参数 770B、每 token 激活 49B，上下文 1M，支持文本、图像与视频理解；开放版本包含 instruct、FP8 量化与预训练三个版本，随权重一同发布系统卡，写明安全评测方法、结果与已知风险。定位低成本部署的 Hy4-flash 权重更早开放，总参数 220B（其中 64B 为 Engram 参数）、每 token 激活 12B，采用稀疏注意力与滑动窗口交替、LatentMoE 与 n-gram 嵌入，许可为腾讯 Hy 许可。至此混元 Hy 系列各代模型均已有开放权重，团队同期在 r/LocalLLaMA 做问答。

关注理由

旗舰多模态模型可下载之后，对数据出域敏感的金融、政务与制造场景能自建推理与微调，智能体在私有云与端侧多了一个 1M 上下文的底座选项。

开源阵营的比拼从榜单分数转向部署深度，推理框架适配、量化版本与系统卡是否齐备，决定模型被真正接入工作流的比例。

权重开放也把安全评测交给使用方复核，系统卡给出的结论需要与实际部署环境对照，尤其在企业内网的长上下文检索场景。

NO.03 · 模型自我改进 · 研究

27B 模型不用梯度改写自身权重，未见过题目上提升 6.6 个百分点

以自身权重、评分结果与自运行能力定位失败并编辑矩阵连续八次会话只提交自身测试支持的编辑，准确率只升不降损坏副本在未见过的图像任务上恢复到完好模型的八成以上
事件简述

11 月 16 日提交、18 日修订的论文《Language Models Can Rewrite Their Own Weights》（arXiv 2611.21885，作者来自 UIUC、CMU、Rutgers、普林斯顿与斯坦福）提出 self-rewriting：给一个 27B 开放模型它的权重、带评分的练习题和运行自身的能力，模型自行诊断失败原因（大量回答耗尽 token 或陷入循环），用推理定位并改写对应矩阵，全程不使用梯度、不做训练。一次编辑使 490 道未见过题目的准确率提升 6.6 个百分点；它只在自身测试支持时才提交编辑，每次替换上一版，前八次连续会话准确率单调上升。修复实验中，模型在不读取原始权重的情况下把损坏副本在六个未见过的图像基准上从 7% 恢复到 70%，约为完好模型的 83%。同一模型家族的较小尺寸要么不作编辑，要么把自己改坏。整个过程只需单卡数小时。

关注理由

改进写进权重、不增加每次回答的成本，这条路绕开了推理时扩展的算力开销，对长期在线的智能体是一种可保存的自我校正机制。

能力只在最大尺寸上出现，规模门槛决定短期适用范围；权重可被模型自行修改，版本追溯、回滚与评测回归会成为工程上的新问题。

论文把训练与推理的边界当作工具限制来处理，若方法在更大模型与代码任务上成立，模型迭代的周期会从训练集群转移到单机运行时。

NO.04 · 芯片 · 世界模型

AMD 完成 82 亿美元收购 World Labs，李飞飞出任执行副总裁兼首席科学家

1,497.8 万股全股票交割，11 月 13 日完成，规模居 AMD 并购史第二Atlas 世界模型在交割前一日向公众与开发者开放团队作为独立前沿研究组织参与 Instinct 与 ROCm 的架构设计
事件简述

11 月 16 日 AMD 向美国证券交易委员会提交的 8-K/A 显示，对 World Labs 的收购已于 11 月 13 日完成交割，以约 1,497.8 万股普通股支付，估值约 82 亿美元，规模仅次于 2022 年完成的赛灵思收购；从 9 月 28 日签约到交割共 46 天。World Labs 联合创始人李飞飞出任 AMD 执行副总裁兼首席科学家，直接向苏姿丰汇报，Justin Johnson 与 Ben Mildenhall 留任，团队在 AMD 内部作为独立的前沿研究组织继续做基础模型。World Labs 的 Atlas 以相机位姿为条件预测下一个视角，在同一套自回归扩散 Transformer 下切换稠密重建、稀疏重建与纯文本生成，交割前一日向所有公众与开发者开放；该公司今年收购的 Scenix 负责实景转仿真与仿真迁现实，演示中机器人在 Atlas 生成的仿真环境完成训练后零样本部署到真机。

关注理由

芯片厂把世界模型团队放进架构设计环节，模型与硬件的联合优化从采购关系变成同一条研发链路，机器人负载可以在芯片与软件栈定型前参与压测。

可规模化获取的训练环境与真机迁移管线被并入算力供应商，这条链路的开放程度会影响中小团队能否以同样方式训练机器人模型。

全股票交割与当日股价回调同时出现，说明市场对软硬协同的预期还没有落到估值上，后续要看 Atlas 在 AMD 硬件上的训练与推理成本。

NO.05 · 科研智能体 · 开源

中关村两院开源材料科研智能体 MatOS，材料软件调用成功率 97.96%

3,135 个数据集、386 项技能、104 个工作流、51 个专家角色从 3,036 万个候选结构中筛出 97 个固态电解质以 DeepSeek-V4-Pro 为底座时，完整问题成功率高过 Codex CLI 与 Claude Code
事件简述

量子位 11 月 17 日报道，中关村学院与中关村人工智能研究院开源 MatOS，把数据、知识、工具、技能、角色与工作流组织成六类科学资产，用有状态的执行图调度任务，执行图快照、节点状态与结果独立于模型会话保存，耗时数天的计算交由后台执行并在完成或需要输入时通知。失败的工具调用与用户纠正作为证据进入资产修订，通过结构检查与语义审查后写回工作流或技能，基础模型参数保持不变，同一套资产可换用不同底座模型。资产库含 3,135 个数据集、386 项技能、104 个工作流、51 个专家角色，集成 48 款材料计算软件。在材料软件使用基准 MatTools 上完整问题成功率 97.96%，高于 Codex CLI 的 95.92% 与 Claude Code 的 89.80%；ResearchClawBench 平均分较 Codex CLI 高 33.6%。研究案例中，分层筛选从 30,364,908 个初始结构收窄到 97 个固态电解质候选，主动学习流程把合金熔点预测模型的平均绝对误差降到 3.18°C。

关注理由

经验放在模型之外的资产里、经检查后版本化，这条路线与把能力写进权重互补，长周期科研任务的状态与证据能够保存并复用。

有状态工作流只把方法选择、计划调整与异常解释交给模型，多步执行偏离目标的风险下降，工业与研究场景接入智能体时可以参照这套结构。

同一套资产换底座模型后成绩仍成立，说明科研智能体的可迁移性更多取决于工具与流程的组织方式，而非单一模型的强弱。
