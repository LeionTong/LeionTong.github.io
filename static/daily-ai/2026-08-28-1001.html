信号 01 / AI Coding · 大厂工作台化

阿里发布 Qoder：以 Coding 为核心的 AI Agent 工作台，自然语言驱动开发，内置 Qwen3.8-Max、2 万+ 技能

AI Coding工作台Qwen3.8-Max2万+技能

事件

8 月 27 日阿里云发布全新 AI 智能体 Qoder，定位「以 Coding 为核心能力、面向所有人的智能体工作台」：

  • 自然语言驱动：用户不必从代码开始，用自然语言描述目标，Qoder 即调用 Coding 与工具能力完成开发、原型制作、数据处理等任务。
  • 底座与调度：内置 Qwen3.8-Max 等多款模型 + Auto 智能调度；支持 40+ 连接器、70+ 插件、2 万+ 技能，提供编程 / 通用两种模式。
  • 同台竞速：与腾讯 WorkBuddy / 百度搭子 / 金山灵犀等同台，国内大厂集体把「AI 编程」从 IDE 插件升级为「工作台级入口」，背后是给大幅扩张的算力投入找可信变现路径。
为什么值得关注

AI coding 从「补全 / 对话」进入「产品化为可交付工作台」阶段——工具形态从插件跃迁到操作系统级入口，开发者工作台成为大厂争夺开发者生态的关键战场。

信号 02 / AI Coding · 开源模型逼近 frontier

智谱 GLM-5.3-Flash（Ox Alpha）开源：320B(18B active) MoE、原生多模态、1M 上下文、MIT 许可，编码逼近 Opus 4.8 而价格约 1/10

开源MIT1M 上下文接近 Opus 4.8

事件

智谱 Z.ai 发布 GLM-5.3-Flash（此前预告为 "Ox Alpha"）：

  • 架构：320B 参数、18B 激活的 MoE，原生多模态（文本 + 视觉早期融合），1,048,576 token 上下文。
  • 开放与定价：MIT 许可，权重已上 Hugging Face；API 定价 $0.075 / $0.25 每百万输入 / 输出 token。
  • 能力声称：智谱称其内部编码基准接近 Claude Opus 4.8（半个百分点内），整体较 GLM-5.2 提升、价格约 1/10。
  • 社区反响：登 Hacker News 头条（972 分），r/LocalLLaMA 多帖热议；社区对其缓存效率声称有分歧。
为什么值得关注

开源权重在「编码 + 多模态」上逼近闭源 frontier、且价格约 1/10，等于把「高能力 coding agent 的底座成本」再砍一刀——与 DeepSeek Harness / 开源路线合流，持续压缩闭源模型的溢价空间。

可核验数据点 · 320B(18B active) MoE · 原生多模态 · 1M ctx · MIT · HF 权重 · API $0.075/$0.25 per M · 内部编码接近 Opus 4.8 · HN #1 (972) | 冷静点：编码对比为智谱自测基准；real-world token 成本与缓存效率社区有争议；「逼近 frontier」指编码单点，非全能力对齐
信号 03 / AI Agent · 标准化与可信评测

Agent 基础设施成熟：A2A 协议进入 150+ 机构生产部署，Tricentis 把 Agent 当测试对象给出 AgentScore

A2A150+ 机构AgentScore互操作

事件
  • A2A 进入生产部署：Agent-to-Agent 协议已有 150+ 机构支持并落地生产（与 MCP 同栈中立治理），agent 间互操作从标准讨论走向实际调用。
  • Tricentis 把 agent 当测试对象：Aida 自主探索 web / Windows 桌面应用找缺陷、无需现成测试脚本；AgentScore 按真实工作流概率评估 agent 行为；Release Risk Intelligence 标注发布级覆盖缺口。
  • 配套底座：AWS Bedrock AgentCore Payments GA（agent 自主付费）+ 持久运行时实例；Cloudflare WriteGuard 私测（细粒度写权限控制，不止读权限）。
为什么值得关注

这是「agent 从聊天机器人 + 脚本」走向「分布式系统平台」的关键补件：互操作（A2A 生产部署）解决「能不能一起干活」，可信评测（AgentScore）解决「敢不敢让它上岗」，支付 / 持久运行时 / 写护栏解决「能不能长期、可控地跑」。

信号 04 / 终端智能 · 主动化与新形态

终端 Agent 主动化落地：Gemini Live 学会自主规划多步任务 + 网易 OpenPods 把 Agent 塞进耳机

终端 Agent主动执行去屏幕化耳机形态

事件
  • Google Gemini Live 大升级：① Agentic Tasks——对话中自主规划并执行多步任务（跨应用查日历 / 邮件 / 建提醒 / 搜索），无需逐条指令；② Voice Inbox Control——语音批量管收件箱（「把未读广告邮件标已读归档」）；③ Personal Intelligence——本地设备学用户习惯后给个性化建议。
  • 网易有道 OpenPods（HICOOL 2026）：首款 AI Agent 耳机（iPhone 专属、MFi 认证），支持通话录音、实时翻译、自动生成会议纪要 / 待办；首发补贴价 1499 元，9/10 发售。
为什么值得关注

终端 Agent 从「被动问答」走向「主动执行 + 常驻感知 + 新硬件形态」：Gemini Live 让助手自己规划多步任务、语音管信息流；OpenPods 把 Agent 入口从手机屏扩散到最贴身的耳机。呼应 08-27 面壁「三重跃迁 / 去屏幕化」，且给出更具体的产品落点。
