旧手机被改成桌面副屏，具身与语音模型一起往小算力压

本期七条：旧安卓手机配桌面代理当电脑副屏，自建 homelab 面板兼做墙面平板与墨水屏看板；具身侧是自演进世界模型、异构触觉表征与 4GB 显卡上从零训练的 VLA；服务端侧是全双工语音模型与 4.5M 参数的离线 TTS。

本期扇区智能屏显示 · 具身 · 服务端配套
入选7 个仓库
检出口径30 天内有推送 · 非 fork 非归档

屏幕这一档的动作是把已经报废的显示硬件重新算进成本里。旧安卓手机配一个桌面代理就能当副屏，不 root、不要账号、不连云，126 个控件自己拼；homelab 那一头把一堆监控数字压成「哪台机器出问题」，推给墙面平板或墨水屏。两边的共同点在于屏幕可以很旧，值钱的是驱动它的那套东西。

具身这一档开始往小算力压。Motus2 把策略、模拟器、评估器塞进一套共享权重，用预测出来的画面给候选动作打分；LingBot-Touch 把不同厂家、稀疏的触觉信号压进同一个潜空间，零样本迁到没见过的灵巧手上；microVLA 更极端，10M 参数在 4GB 显存的笔记本卡上从零训练，同一张卡还能跑 4-bit 的 3B 模型。

语音这一档分两头走。一头拼能力，32B 的全双工模型边听边说、能分辨语气，单卡起服务或在 Mac 上离线跑；另一头拼体积，4.5M 参数、18MB 的 TTS 在四线程 CPU 上跑到七十倍实时，还能塞进浏览器。陪伴类终端要在这两头之间选位置，选哪头决定了机内要不要留一颗能推理的芯片。

02 — 具身世界模型压到笔记本显卡
3

Motus2 shengshu-ai/Motus2

⭐ 575具身部署: 源码（训练与推理）商业化: 弱无正式发版 · 2026-11-17

定位自演进的世界模型，一套共享权重同时充当策略、模拟器与评估器，用预测出来的画面给候选动作打分，形成闭环。

亮点策略提出候选动作块，模拟器预测这些动作的视觉后果，评估器判断结果好坏，失败与次优交互被拿回去训动力学与价值模型。数据从大规模单目自我中心视频扩到同步立体，再做机器人域适配。Stage 1 权重与视频预训练、视频-动作预训练、监督微调、记忆训练的代码已放出，另有触觉反馈与一台带立体视觉、双臂、双手的仿生平台。

商业化弱：依赖自建仿生平台与大规模训练，短期是可引用的方法底座，不构成可直接售卖的产品。

风险与坑训练与推理算力需求高，单卡复现不现实；效果只在作者自建平台上验证，换硬件要重新适配；无 release，接口随论文走；1 个未关闭 issue。最近推送 2026-11-17。
4

LingBot-Touch Robbyant/lingbot-touch

⭐ 785具身部署: 源码（模型与推理）商业化: 中无正式发版 · 2026-11-11

定位触觉表征基础模型，走 JEPA 路线，把不同厂家、稀疏的触觉信号映射进同一个潜空间，让触觉经验跨硬件迁移。

亮点同一个 Transformer 从时空触觉上下文预测潜表示，多种传感模态的数据互相增强；最小的 ViT 骨干也能支持高频推理。在完全不同的触觉传感器上预训练后，零样本迁到下游传感器与真实灵巧手，不必补训练。权重在 Hugging Face 与 ModelScope 同步放出，下游接操作策略与强化学习都可。Apache-2.0，论文 arXiv 2611.12806。

商业化中：触觉传感器厂与灵巧手厂可以把它当预训练底座，卖硬件时附一套可迁移的触觉表征，客户换传感器不用重训。

风险与坑需要自备多模态触觉采集数据，公开数据仍靠各家自采；触觉硬件接口碎片化，接新传感器要自己写适配层；无 release，也还没有第三方复现记录。最近推送 2026-11-11。

microVLA KhushiJ2911/microVLA

⭐ 24具身部署: 源码商业化: 中无正式发版 · 2026-11-15

定位在 4GB 显存的 RTX 3050 上从零训练一个 10M 参数的 pi0.5 风格 VLA，同一张卡还能跑 4-bit 的 3B pi0.5。

亮点纯 PyTorch 实现，LIBERO-Spatial 演示上 8k 步约 25 分钟训完；先用 SigLIP 做蒸馏教师，再走 flow matching。README 逐条列出让 3B 模型挤进 4GB 的每项改动，以及改动后每 50 个动作块的中位耗时，还在同一个 episode 上给出 10M 小模型与 4-bit pi0.5 的对照。

商业化中：端侧与低成本样机的操作策略验证可以在笔记本上完成，省掉租卡与排队，适合做早期可行性判断。

风险与坑只在 LIBERO 仿真基准上验证，没有真机结果；要求 Linux 与 CUDA，EGL 渲染要单独指到集显，否则显存被渲染吃掉；24 星、单作者、无发版。最近推送 2026-11-15。

⭐ 501服务端配套部署: 源码（模型 + 服务）商业化: 中v1.5.0 · 2026-11-18

定位开源全双工语音模型家族，边听边说，能分辨对方怎么说，并用带笑声、叹息与呼吸的语音回应。

亮点VoiceBench 82.8、Big Bench Audio 81.8%，作者称在开源全双工模型里两项都排第一，VoiceBench 上与 GPT-4o-mini-Audio 持平；副语言理解 48.6，也是同类第一。三种体积共用一个大脑，单卡用 vLLM-Omni 起服务，或在 Mac 上用 MLX 全离线跑；支持零样本音色克隆，接口兼容 OpenAI Realtime 与 GPT-Live。Apache-2.0，v1.5.0 于 2026-11-18 发布。

tiny-voca n4ze3m/tiny-voca

⭐ 792服务端配套部署: 源码（PyTorch / ONNX）商业化: 中无正式发版 · 2026-11-20

定位4.5M 参数、18MB 的英文 TTS，带两个音色，四线程 CPU 上约 70 倍实时，也能跑在浏览器里。

亮点代码、权重、训练配方与数据集全开，模型从零训练；PyTorch、ONNX Runtime、ONNX Runtime Web 三条路都通，波形生成器自带。长文本按句合成再拼接，句末缺标点会自动补，输出峰值压在 0.99 以下不削波，还提供语速与音高参数。

商业化中：玩具、家电提示音、离线播报这类只要「能说话」的场景，18MB 可以塞进设备固件或网页，不需要联网。
