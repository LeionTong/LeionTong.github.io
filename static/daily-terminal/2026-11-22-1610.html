旧屏与旧音箱改做语音入口，腕上与桌面的小设备各接自托管后台

本期五条：联想会议屏刷成带角色的桌面语音伴侣，Wear OS 手表直连自托管网关并把回答念出来，ESP32 圆表靠自写界面库跑到 60 帧；桌面一侧是四足桌宠框架背后的新品众筹，以及一块显示编码会话状态的棱镜小屏。

本期扇区语音终端 · 穿戴 · 桌面机器人
入选5 个仓库
检出口径30 天内有推送 · 非 fork 非归档

语音终端这一档能动的只有存量设备。企业会议屏、旧音箱、报废平板在二手市场上按斤卖，硬件缺陷都在，缺的是把屏、麦克风、喇叭接起来的那层软件。这一期入选的会议屏方案把唤醒词、计时器、闹钟留在设备本地，模型调用走 Home Assistant 里已经配好的那套，设备上不存 API key。整机的成本因此压到二手屏的价格，卖点从芯片换成体验。

穿戴这一档出现两种做法。一种把整套自托管后台搬到腕上：手表直接连自己机器上的网关，会话、审批、工具调用都能在表上操作，回答用克隆出来的本人声音念出来。另一种从显示驱动重写：一块 466×466 的圆表，界面库、触摸、绘制全部自己写，静止时不画帧，靠这套把功耗压下来。前者证明手表可以当 agent 的入口，后者说明小屏的刷新与省电能做到什么程度。

桌面这一档两条路都在出货。四足桌宠的框架仓库还在维护老主板，同时把新一款桌面机器人套件推到众筹并成功；另一头是几十美元的棱镜小屏摆件，把屏幕上编码会话的状态搬到桌面，人可以不盯着显示器。桌宠拼的是机械与续航，摆件拼的是帧动画与状态接口，两边的供应链完全不同。

home-companion m0s4ik/home-companion

定位把联想 ThinkSmart View 会议屏刷成桌面语音助手：设备本地听唤醒词，屏幕上有个角色出镜，思考交给 Home Assistant 里已配好的 Gemini、OpenAI 或 Anthropic 集成。

风险与坑要求 Home Assistant 2026.11 与 arm64；2GB 内存的骁龙跑角色动画、AirPlay 并发要实测，卡顿会直接毁掉体验；单作者，4 个未关闭 issue，v0.3.x 阶段接口还会变；角色美术只有一位老管家，换形象要自己画。最近推送 2026-11-21。

Hermes Wear OS borealBytes/hermes-wearos

⭐ 37穿戴部署: 源码（Wear OS 应用 + 网关插件）商业化: 弱v0.10.12 · 2026-11-12

定位Wear OS 手表直连自己机器上的 Hermes 网关，抬腕点一下说一句话，回答在表上出声播报，中间不经手机伴侣、不经云中转。

亮点网关侧装一个插件生成配对码，表端输码即完成配对，不用账号体系；表上能选网关上的每个 agent 与每个会话，权限审批、工具调用结果、cron 任务都在腕上处理；播报音色用 3 秒音频在网关 CPU 上克隆本人声音，逐字高亮跟读；媒体文件与动图在表上渲染。表盘一侧是八格环的球体读数与配对码页面，语音入口一个按钮。MIT，Kotlin 写成，v0.10.12 于 2026-11-12 发布，CI 在跑。

商业化弱：绑定单一自托管网关生态，没有可售硬件，价值在于给自有终端验证「手表当 agent 入口」这一形态的交互与延迟。

风险与坑要求网关版本 ≥0.23.0，网关升级会牵连表端；部分 Wear OS 机型限制侧载，分发要过商店或内测通道；声音克隆属敏感能力，面向消费者必须有授权与声明；37 星、单作者。最近推送 2026-11-12。

定位给 Waveshare ESP32-S3-Touch-AMOLED-1.75C 圆表写的表盘固件，外观与动效照着 Wear OS 做，界面层从零自写。

风险与坑只对一块板子做过适配，换屏或换主控要重写驱动；没有心率、血氧、GPS 传感器栈，做不了健康类功能；20 星、单作者，10-31 之后没有新推送；外壳与表带要另外解决。最近推送 2026-10-31。

本期取舍

扇区按游标走到语音终端、穿戴、桌面机器人。语音终端这一档的新货最少：热度榜上的 willow、EchoMuse、LANovo、echo-dot-assist、techo5、Nest Mini 替换板、小爱音箱 patch 都已在日志里，30 天内新建的仓库大多只有二十几颗星且停更，最后只留下 home-companion 一条，它比同类的差别在于角色与本地计时器这一层。

穿戴这一档收过 neurband、LibreWrist、PopkaStudio、scouter_kit 与 MentraOS，这期换到两条此前未收录的：腕上直接连自托管网关的 Wear OS 客户端，和一块从驱动层重写的圆表固件。前者验证形态，后者验证工程，都是整机厂真正会碰的问题。

桌面机器人这一档 PAROL6、desk-emoji、tiny-engineer、groki-bot、Flashduck、stack-chan、SO-ARM 系列都收过，热度榜上的新机械臂没有够得上门槛的，最后选了 Petoi 的框架仓库与棱镜小屏摆件：一条是出货路径，一条是低成本桌面形态。下一期游标回到智能屏显示、具身与服务端配套。
