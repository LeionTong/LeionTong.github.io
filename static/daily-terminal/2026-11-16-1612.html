Kobo 阅读器被装上应用商店，人形原型机连训练代码一起开源

本期八个仓库：Kobo 墨水屏的第三方商店与 Rust SDK、横跨四家硬件的墨水屏相框固件、可照图纸自行装配的手搓人形、Apple 的 G1 感知运动数据链，以及两条设备侧服务端。

本期扇区智能屏显示 · 具身 · 服务端配套
入选8 个仓库
检出口径30 天内有推送 · 非 fork 非归档

值得先看的两件事。墨水屏生态在往上长：Kobo 的阅读器被第三方做成了有应用商店、有 SDK、有进程隔离的平台，相框固件则把画质校准和配套图片服务做成了跨厂商的通用件。具身这边，一家上海公司把跑跳原型机的结构、电子、训练与部署全量公开，Apple 则把「仿真造数据 → 训练追踪策略 → 语言编排闭环」整条链放出，两者都在压缩队伍从零到实机的时间。

服务端配套选了设备机群会用到的两类东西：能横向扩的 broker 和几乎没有成本的上线哨兵。

01 — 智能屏显示墨水屏上的平台化
1

Cobalt BandarLabs/Cobalt

⭐ 435智能屏显示部署: 源码 + 固件刷入商业化: 中v0.3.37 · 2026-11-12

定位给 Kobo 墨水屏阅读器加一套应用启动器、应用商店、Rust SDK，以及让每个应用跑在独立受限进程里的运行时。

亮点一次 USB 安装，之后应用全程走 WiFi 装卸与升级，原厂阅读器不受影响；自带模拟器，没有机器也能开发。实测机型覆盖 Clara BW 与 Clara Colour、Elipsa 2E、Libra 2/Colour/H2O，装机清单外的设备会先列明未测项再让用户确认；下载内容按签名清单校验，安装脚本还顺带开了只认本机密钥的 SSH。

商业化商店形态本身就是渠道，SDK 加模拟器把第三方开发门槛压到几乎为零，作者已把安装器、应用目录与开发者文档做成站点。

风险与坑AGPL-3.0，闭源分发要过传染性这一关；Kobo 固件 5.x 不支持；仓库压着 36 个未结 issue，早期版本仍有兼容性长尾。最近推送 2026-11-14。
2

esp32-photoframe aitjcize/esp32-photoframe

⭐ 275智能屏显示部署: 固件商业化: 强v2.20.1 · 2026-11-14

定位替换墨水屏相框原厂固件的开源件，覆盖 Waveshare PhotoPainter、Seeed XIAO EE02/EE03/EE04 与 reTerminal E1002/E1003/E1004、M5Stack M5Paper。

亮点不按理论 RGB 配抖动，而是先实测这块屏的真实墨色再做 Floyd-Steinberg，画质与原厂差距肉眼可见，还带一键校准；REST 接口与网页拖拽上传齐备，深睡模式默认开、待机按周计。配套图片服务端能接 Immich、Google Photos、Synology Photos、Unsplash 与 Telegram 机器人，并叠时间天气；另有 Home Assistant 集成。

商业化同一份固件横跨四家硬件，配套 iOS 应用已在 App Store 收 2.99 美元补贴开发者账号，服务端可作 HA 插件跑，硬件加软件加服务的关系已经成形。

风险与坑机型与屏批次绑定紧，换批不重新校准颜色就失真；服务端、手机应用、HA 集成分散在另外三个仓库，维护面比表面看到的大。最近推送 2026-11-14。
02 — 具身把实机门槛拆掉

ROBOTO_ORIGIN Roboparty/roboto_origin

⭐ 2846具身部署: 源码 + 图纸商业化: 中无 release

定位一家上海公司四个月做出的跑跳人形原型机，结构、电子、训练、部署全量开源，仓库是八个子仓的每日快照聚合。

亮点作者写明靠淘宝采购加嘉立创打样就能自行装出来，BOM 表在仓库里；子仓分别是硬件图纸与 PCB、ROS2 部署框架、IsaacLab 训练与 Sim2Sim、URDF 描述、固件与 XR 遥操作，训练链可一直走到真机跑跳。研发全过程另有文档站点。

商业化图纸、固件、训练环境都齐，缺的只是供应链，套件商、教学实验室和做二次开发的团队都能直接据此出整机。

风险与坑GPL-3.0；仓库只是快照，模块级 issue 与 PR 要提到子仓；外壳壳体仅静态展示、不建议直接打印；未结 issue 为 0 也意味着外部踩坑记录还少。最近推送 2026-11-15。

HALO apple-aiml-research/ml-halo

⭐ 407具身部署: 源码商业化: 弱无 release

定位Apple 放出的 G1 感知式全身运动链路，Infinigen 合成场景造数据，运动生成器出片段，追踪策略学动作，编排器把语言指令和自视角图像拆成子任务闭环。

亮点训练数据全在仿真里生成，不需要动捕棚；追踪器提供 Python 与实时 C++ 两条部署路径，训练分特权专家、多教师蒸馏、多评论家微调三段；编排器用本地模型与生成器同机共服务，跑在自家的调度引擎上；仿真与真机两套启动脚本都在。

商业化整条数据到部署的链一次给全，研究团队能省掉最贵的数据采集环节，作为方法基线可直接引。

风险与坑权重不随仓库发布，学生模型要自己训；许可是 Apple 自家的「Other」，允许源码与二进制再分发但须保留声明、不得借 Apple 商标；只在 G1 上验过。最近推送 2026-11-05。

PEAR mit-han-lab/pear

⭐ 416具身部署: 源码商业化: 弱无 release

定位韩松实验室的机器人推理模型后训练引擎，用仿真里的强化学习把通用模型教成能直接操作真机。

亮点veRL 上的全异步 RL、GRPO 加动态采样与分数归中；FSDP 与序列并行撑长上下文，LMCache 把 KV 缓存卸到内存；针对 H100、H200、GB300 写了算子；MuJoCo 跑在 CPU、Isaac Sim 跑在 GPU，同一个 Ray 集群里一并调度。27B 开放推理模型零示教学会驱 YAM 与 SO-101，部署侧只要一张 5090 起 vLLM 服务端。

商业化训练、评测、部署三段贯通，硬件门槛压到单卡，做机器人 Agent 的团队拿它当现成训练底座即可。

风险与坑Apache-2.0 但依赖 veRL 与两套仿真器，装环境很重；评测集中在 LIBERO 系列，真机泛化仍待验证；仓库上线三天。最近推送 2026-11-16。

Project SuperDex facebookresearch/project_superdex

⭐ 842具身部署: 源码商业化: 中v1.0.1 · 2026-10-22

定位Meta 的灵巧操作研究平台，四件套为接触优先的物理引擎、机器人 SDK、桌面资产编辑器、策略训练编排层。

亮点物理引擎是照着触觉操作重写的，软海绵、果袋、绳结、拼图这类接触密集场景能实时演示，接触力可视化直接内置；Studio 把原始 CAD 与机器人描述转成场景资产；配置聚合、传感器与执行器抽象都放进 SDK。VR 遥操作排在本季度。

商业化引擎加编辑器加训练层合起来正对商业仿真软件软肋的接触精度，教学与算法团队有付费空间。

风险与坑Apache-2.0，但 Lab 仍是早期预览、VR 遥操作尚未放出；离开自家引擎就搬不动，迁移成本高；只在官方站点与仓库给样例，第三方生态还没起来。最近推送 2026-11-16。
03 — 服务端配套机群侧的两块砖

RMQTT rmqtt/rmqtt

⭐ 1065服务端配套部署: 容器 + 源码商业化: 中0.24.0 · 2026-09-19

定位纯 Rust 写的分布式 MQTT broker，宣称单节点扛百万并发客户端。

亮点MQTT 3.1/3.1.1/5.0 全协议与三级 QoS、Raft 集群、内置与 JWT/HTTP 两路鉴权、Kafka/Pulsar/NATS 双向桥、共享订阅与延迟发布、WebSocket 与 TLS 都在。代码全异步，构建在 tokio 之上，会话与未过期消息可分库持久化。

商业化MIT 且能力档位对齐商业 broker，设备机群自托管可以只用一份二进制，不必被授权条款绑住。

风险与坑文档厚度与生态远不如 Mosquitto、EMQX，集群与桥接的坑要自己趟；0.24 意味着配置与 API 还会变；压着 23 个未结 issue。最近推送 2026-11-16。

ESP-Watchtower prasadabhishek/esp-watchtower

⭐ 29服务端配套部署: 固件商业化: 弱无 release

定位三美元的 ESP8266 常年在线当网络哨兵，把内网 Wi-Fi 和出口线路分开测，放假摄像头与假路由后台当绊线，把断网记成有据的时间戳。

亮点半瓦功耗，无订阅无云帐号；只在本地路由正常而出口死掉时才记一笔，拔路由重启不会误报，账单申诉可以导出凭证；新设备上线、家人到离都能推手机，还能唤醒休眠的主机、给智能家居当本地校时源。一条 PlatformIO 命令刷入，接 Home Assistant，告警走 Discord。

商业化物料成本极低、功能对家用运维是刚需，固件现成可当小盒产品卖，也适合塞进排障套件。

风险与坑29 星、单人维护、无 release 打包；ESP8266 只有单频段，对 5GHz 网络只能靠 2.4G 探路；绊线是固定端口监听，换个端口就绕。最近推送 2026-10-29。

本期取舍

扇区按游标走到智能屏显示、具身、服务端配套。墨水屏这一档，已有整机与固件类项目近期推送过，把位置让给了能长平台的 Cobalt 与把画质做深、横跨四家硬件的相框固件。

具身档收了三条能直接压缩队伍上手时间的：可自行装配的整机、仿真造数据的运动链路、单卡起跑的推理模型训练引擎，另加一套面向接触操作的仿真平台。服务端只留两条与设备机群直接相关的，broker 与哨兵。

三个条目标着「商业化 弱」，它们的共同点是研究产出、作者不打算卖东西；拿来做产品的底座可以，指望作者提供支持不行。
