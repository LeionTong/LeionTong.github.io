EchoMuse wilbowes/EchoMuse

⭐ 1408 语音终端 固件 + 容器 商业化 强

定位把 2016 年那代 Echo Dot 二代刷成 Home Assistant 的本地语音卫星，Amazon 的软件一点不留。

亮点控制端以 HA 插件或 Docker 容器跑在自有网络里，负责唤醒判定、设备管理与网页面板；音箱端默认装 emOS，只保留 Dot 的原厂内核，换掉整个 Android 用户空间，3.5 毫米音频口正常工作，向导会备份原始启动镜像，还原约十秒，也留有保留 FireOS 5 的 root 路线。麦克风、扬声器、LED 环、按键全部沿用。唤醒词默认在音箱本地跑，没听到就不外传，也可以改成由控制端统一判定。首次解锁走 USB，用 firebreak 一条命令完成，底层是 amonet-biscuit 的引导漏洞。

商业化二手 Dot 单价已经很低，把改装做成预刷整机或一次性服务，是能直接收费的形态；MIT 允许闭源出货，真正要处理的是解锁环节依赖 Amazon 引导漏洞带来的合规与变砖售后。

风险与坑只支持 Echo Dot 二代，Dot 3、Echo 2、Echo Show 8 的移植还在社区手里；158 个未关闭 issue；必须已有能跑通的 HA Assist 管线，识别、理解与合成都不在本仓库。

豆梨 Syfyivan/douli-esp32

⭐ 199 语音终端 固件 商业化 中

定位在微雪 ESP32-S3-AUDIO-Board 上做个人语音陪伴端，桌面端、安卓端、服务端与板端固件放在同一仓库。

亮点固件基于 xiaozhi-esp32 v2.5.2 打补丁，上游提交号写死，补丁单独留档；新增局域网优先加公网加密备用两条连接路径，后台每 30 秒收发一次保活消息，待机不传音频，唤醒才开流。板端启用硬件回声消除后支持播报中插话，判定门槛是 16 千赫采样上累计 140 毫秒超阈值，随后立即停掉旧合成、清空播放队列并继续收音。「再见豆梨」这类结束口令在语音识别出结果后直接进待机，不调用回答模型，同时兼容同音转写与名字前后换位。服务端带记忆检索与生活记录，语义索引按内容哈希增量更新。

商业化陪伴类终端要的固件、后台、手机端三件套都在，能按整机或按后台订阅收费；仓库根目录没有统一许可证文件，固件补丁沿用上游 MIT，商用前要把各目录的许可逐项确认。

风险与坑绑死微雪这一块板，换板要重做分区与引脚；文档写明部分指标只是板端计数，真人听感、插话质量与跨网流畅度没验收；上游还有 11 项 Windows 环境测试未过。

版本未发 release（固件号 2.5.2.11）｜ 最近推送 2026-11-04

ESP32 AirPlay 2 Surround Kristian8606/esp32-airplay2-surround

⭐ 179 语音终端 固件 商业化 中

定位一块 ESP32-S3 当网关、每只音箱一块板，把 Apple TV 的 5.1 与 7.1 环绕声无线分到最多八只音箱。

亮点Apple TV 只看见一个 AirPlay 2 目标，网关收完整路流后原样转发，每块板只解自己那个声道，接任意功放与音箱。多只音箱的时钟靠无线路由器的信标计时同步，误差在微秒级，不加线也不加时钟硬件。支持 AAC 5.1/7.1、ALAC 44.1/16 与 48/24 无损、AAC 立体声，换曲时立体声与环绕可以无缝切换。网关可选装 INMP441 麦克风做房间校准，量出每只音箱的距离、延迟与电平；改过的 FDK AAC 解码器只合成单声道，7.1 下每只音箱约占三分之一 CPU 核。声道、增益、延迟与 EQ 都在一个网页里配。

商业化家庭影院布线是实打实的成本，这套等于把 AV 功放拆成几十元的板子加上家里已有的音箱，可做套件、校准服务或整机；仓库没有许可证文件，正式出货前必须先谈授权。

风险与坑作者写明仍在开发中，目前只验证到一网关加两只音箱放 7.1；功能、默认值与接线还会改；没有 release，也没有 LICENSE。

Bangle.js App Loader espruino/BangleApps

⭐ 581 穿戴 源码 商业化 中

定位Bangle.js 开源手表的应用目录与网页加载器，手表端跑 JavaScript，浏览器用 Web Bluetooth 把应用直接推进手表存储。

亮点应用清单一律由各应用目录下的 metadata.json 汇总成 apps.json，加载器启动时与手表上的文件比对后增量上传；文件名限 28 个字符，按 .app.js、.wid.js、.img、.info 的约定区分应用、小部件、图片与描述。正式版定期手动刷新，开发版随每次提交更新，两套入口都在网页上。1351 个 fork 说明这套目录已经成为社区改表盘、改固件的分发口径，全部代码 MIT。

商业化硬件由 Espruino 官方在售，软件侧的钱在表盘定制、企业批量预置与二次分发；MIT 之下闭源改版可以直接出货，不需要额外授权。

风险与坑没有 release 概念，分发完全靠网页加载器与仓库提交；108 个未关闭 issue，单个应用的质量取决于投稿者；Web Bluetooth 只在 Chrome 系浏览器可用，Firefox 与 Safari 推不了应用。

OpenStrap Edge OpenStrap/edge

⭐ 870 穿戴 源码 商业化 弱

定位给 WHOOP 手环做免订阅的本地健康客户端，安卓装 APK，iOS 走 TestFlight。

亮点支持 WHOOP 4.0、5.0 与 MG 三代，把训练、睡眠、恢复、心率、压力这些原本锁在订阅后面的数据读出来存在本机。Oura 戒指、Garmin、Pebble、Colmi、Ultrahuman、小米手环在开发列表里。项目没有公司、没有订阅、没有付费墙，靠捐赠维持，官网 openstrap.site，被 Hackaday 与 Adafruit 报道过；156 个 fork 说明有人真的在改它。

商业化本身不收费，价值在于证明「硬件已经卖出、数据被订阅锁住」这条缝可以撬开；对做穿戴配套的团队，现成的协议解析与数据模型可以拿来当起点，延展成整机厂的多设备聚合入口。AGPL-3.0 要求派生的服务端也开源。

风险与坑只覆盖 WHOOP 一个品牌，其余设备都在路上；45 个未关闭 issue；逆向出来的协议随时可能被厂商固件更新打断；没有商业模式，长期维护压在个人身上。

SO-ARM100 / SO-101 TheRobotStudio/SO-ARM100

⭐ 7998 桌面机器人 图纸 + 物料清单 商业化 强

定位Hugging Face LeRobot 生态里的标准开源桌面机械臂，SO-101 是 SO-100 的改进版：走线重做、装配不必拆齿轮、主臂换用新电机。

亮点一条主臂加一条从臂成对使用，人手拖动主臂示教、从臂复现，动作直接进 LeRobot 的数据采集与训练流程。零件清单公开，结构件可自己打印也可直接买打印件，仓库另附抬高主臂底座与多种相机支架等可选件。Seeed、WowRobo、RobotEd、Robonine、PartaBot 等多家套件商在卖整机、打印件与电子件，淘宝也有对应链接，这套图纸已经是事实标准。Apache-2.0，商用没有额外限制。

商业化套件、打印件、装配服务三条线都有人在做且能收到钱，需求已经被验证；做配套的相机、夹爪、底盘与教学课程，都还留着位置。

风险与坑仓库本身只有图纸与清单，软件在 LeRobot 那边，版本要对齐；91 个未关闭 issue；负载与精度受舵机限制，做不了工业级任务；最近推送停在 2026-10-06。

Faze4 Source-Robotics/Faze4-Robotic-arm

⭐ 916 桌面机器人 图纸 商业化 中

定位全 3D 打印的六轴桌面机械臂，用打印出来的摆线减速箱换低背隙，线全部走臂内。

亮点961 个零件，其中 197 个打印件、764 个采购件；整机约 14 到 15 公斤，打印体积需要 250×210×200 毫米，材料与采购件合计约 1000 到 1500 美元。结构按工业机器人的做法来：摆线减速箱低背隙、走线内藏、关节外壳承力，六个轴全用步进电机。仓库给 STL、STEP、装配说明 PDF 与在线文档，STEP 文件包另售。

商业化把工业臂的机械做法压到桌面尺寸与千元美金档，可卖打印件、装配套件与配套控制软件；CERN-OHL-S-2.0 属强著佐权，改动后分发必须开源，做闭源整机要另做授权安排。

风险与坑近千个零件的装配与调试，普通玩家很难一次做成；1000 到 1500 美元只是材料与采购件，不含打印工时与报废件；没有 release，版本靠仓库提交推进；未关闭 issue 为零，说明反馈量还没起来。
