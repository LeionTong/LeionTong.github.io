墨水屏一头扎进家居画框与整机固件，机器人侧补上七轴臂与同场物理引擎

鸟鸣识别驱动的墨水屏画框、TRMNL 整机固件、越狱 Kindle 上的 Android 容器，三条都在用现成硬件做显示终端；七轴开源机械臂、多材料物理引擎、自托管推理集群与 Mac 本地推理服务补上设备侧与后端的缺口。

本期扇区智能屏显示 · 具身 · 服务端配套
入选7 个仓库
检出口径30 天内有推送 · 非 fork 非归档

智能屏显示这一格今天的三条都在做「显示之外」的事。鸟鸣画框把本地识别与内容策展绑在一块，屏幕只负责最后一步呈现；TRMNL 的固件把唤醒到深睡的一整个周期写成状态机，含配网、对时、升级与按键手势，是一条完整的低功耗显示设备流程；Kindle 上的 Android 容器把闲置阅读器改成通用终端，靠局部刷新与可回退来绕开墨水屏与刷机的坑。三条里只有 TRMNL 是整机厂的官方产物，另外两条是个人把存量硬件拉满。

具身这一格的两条都不做整机。七轴臂把闭环放到 STM32H743 上，1 kHz 关节环、重力补偿、阻抗与导纳全在板载跑，主机只发目标位置，图纸、BOM、板卡源文件与 URDF 一起放开；物理引擎把刚体、布料、液体、颗粒放进同一个场景并行步进，给抓取与可变形物操作合成训练数据。这一格的公开项目正在从「整机展示」转向「能拼起来的零件」。

服务端配套的两条都在拆掉专用硬件的门槛。推理引擎用一个 OpenAI 兼容接口盖住检索、结构化输出、内容安全与音视频转写，模型按需加载；Mac 上的推理服务用 Zig 后端同时说 OpenAI、Anthropic、Ollama 三套协议。一台 Mac mini 接上就能当部门节点，配不配 GPU 服务器成了可选项。

⭐ 4114智能屏显示部署: 源码（树莓派）商业化: 中v0.33.0 · 2026-11-21

定位在树莓派上跑本地鸟鸣识别，把窗前听诊到的鸟种逐一对上 1800 年代手绘插画，拼成一页刷在墨水屏画框里。

亮点识别交给 BirdNET-Go 的本地 API，项目轮询结果、按物种匹配插画、排版成拼贴，只在鸟种变化时重绘，静止期间屏幕不耗电；输出目标可以是 Inky Impression 墨水屏，也可以是电视或任意屏幕，管理页面用来选哪些鸟、怎么排。代码 MIT，插画单独 CC BY-SA 4.0，作者在挪威卑尔根的花园挂了一台并在网上放实时演示，另有全球展示页。发版节奏稳定，最近一版 2026-11-21。

风险与坑识别依赖第三方 BirdNET-Go 服务与常开麦克风，鸟种覆盖跟模型走，本地别的声音容易误判；插画是 CC BY-SA，商用要署名并以相同方式共享这批图；大尺寸 Inky 面板加上树莓派，硬件成本比普通相框高一个档；最近推送 2026-11-26。

亮点唤醒周期被写成一张完整流程图并公开：按钮长按 15 秒清凭证重启、5 到 15 秒忘记 Wi-Fi、双击跑特殊功能、短按正常上线；没有凭证就开强制门户配网，联网失败按退避策略睡眠并在第 12 次失败时把错误显示出来；对时走 NTP，取屏走自有接口，每次唤醒都查一遍固件更新。仓库明确 main 分支带破坏性改动，正式固件看 tag。

InfraBot YaolinDong/infrabot

⭐ 25具身部署: 源码 + 硬件图纸商业化: 中无 GitHub 发版 · 主干推送

定位七轴开源机械臂，达妙 CAN FD 关节配 STM32H743 控制板，关节环 1 kHz 在板载 MCU 上闭环，主机只发目标。

亮点重力补偿、关节与笛卡尔两个层面的阻抗与导纳控制都在控制器上运行，PC 掉线时这几种模式照旧工作；主机可以流 1 kHz 目标，也可以只提交 movej、movep 让控制器自己插值。4.3 寸触摸屏中英双语显示驱动状态与合规参数，带机械臂三维视图，每页都有停止键；固件签名走 A/B 分区，试启动失败自动回退，另有 SWD 救砖。整臂 4.63 公斤，STEP 装配图、每个加工件的 STEP、BOM、板卡 EasyEDA 源文件与 Gerber、外壳 STL、带惯量摩擦辨识的 URDF 全部公开，C++ 与 Python SDK、ROS 2 驱动齐备。

商业化中：图纸与固件完整度已经够做教学臂或轻负载协作臂的底子，关节是成品件，散件成本可控；卖点在「能自己造」，适合当验证平台。

风险与坑单人维护的首个公开版本，行程、负载、重复精度都还没测、作者自己也没列；流丢失、反馈超时、驱动故障只做到受控停止，硬接线急停仍必须另配；无发版，SDK 与协议还在动；最近推送 2026-11-26。

Alloy argonrobotics-ai/alloy

⭐ 80具身部署: 源码（Python 包）商业化: 中v0.1.11 · 2026-11-27

定位面向机器人学习的多材料并行物理引擎，刚体、布料、软体、液体、颗粒、线缆在同一个场景里一起步进。

亮点建在 Newton、MuJoCo Warp 与 Warp 之上，刚体走 MuJoCo Warp，布料与软体走 Newton 的 VBD，沙与膏体走 MPM，液体走自研的 DFSPH；物体用 YAML 卡片描述形状与材料参数并附来源，路由器按材料挑求解器。单张 L4 上机械臂场景并行 512 到 4096 个世界（Franka 加桌面加方块最优点在 2048），免费刚体可到数千；没有 GPU 也能全 CPU 跑。论文在 arXiv 2611.16312，已知限制逐条列在一页里并给规避办法。

商业化中：抓取、可变形物操作这类任务的数据合成要靠它，可以当 sim2real 流水线的底；Apache-2.0，商业公司在后面维护。

风险与坑需要 NVIDIA GPU 与 Python 3.11 或 3.12，CPU 上慢到只能调试；0.1.x 版本接口会变，v0.1.11 与上次发版同日；多求解器同场的稳定性还靠各材料参数自己调；最近推送 2026-11-27。

  1. 低功耗显示设备的分水岭在唤醒周期的状态机，不在屏幕本身；TRMNL 那份固件把配网、退避、升级、故障恢复写全了，是现成的对照。
